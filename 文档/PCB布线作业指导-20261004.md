## 一、开工前先定死（画下去就不好改）

| # | 项 | 值 |
|---|---|---|
| 1 | **板框** | **66 × 88mm**（**实际建议做 87**，每侧留 0.5mm 磨量 —— 88 是两轮内侧面的理论线，零间隙会磨轮子）；厚 **2.0mm**。**后缘与框架后缘平齐**，超长的 11.5mm 全部堆在车头 |
| 2 | **安装孔** | **5 个**（对应框架那一排孔）。**Y（距板前缘）= 14.5 / 23.5 / 40.5 / 49.5 / 63.5**；孔径 **φ2.2~2.4**；配 **M2×8~10** + 六面螺母；**X = 框架孔的横向位置（⏳待实测）** |
| 3 | **元件全部朝上装** | 板下方是夹层（里面躺着 **15mm 厚电池**）→ **下面不能有任何元件**；朝下的排针**焊后剪平** |
| 4 | **电路板垫高 6~8mm** | 用垫柱架在上排孔上方 → 夹层变 **17~18mm**（装下电池），同时让开灰度模块本体（顶到 16~18mm）|
| 5 | **铺铜策略** | **VM 用大块铺铜**（不用走线 —— 6A 用走线要 6mm，不现实）+ **开窗加锡**；**地双面铺铜** |
| 6 | **丝印** | 板名 + 队伍名 + **`2026 机器车循迹`**（规则硬要求）；**每个接插件旁边标名称**；★ **电机端子标「左 / 右 / 风机」**；降压模块标 IN / OUT |
| 7 | **舌板** | 从**板前缘往前 ≥21.5mm**（探头连线在板前缘前 21.5），宽 **92~95mm**（在轮子之前，不受 88 限制）；**开窗**给模块本体穿过；两条长槽做 35~55 前瞻可调 |

## 二、布局顺序（照这个来最省事）

```
1. 板框 + 5 个安装孔
2. 板边固定件：XT30 / 电机端子 ×3（KF301）/ 灰度 10P / 编码器 6P×2 / IMU 8P / SWD 4P / 串口 4P
3. 功率区（板的一端）：F2(10A 慢熔) → 3×AT8236 + 各自 470µF/25V + 100nF
4. 逻辑区（另一端，离电机最远）：MCU + 晶振 + ME6211C33 + 降压模块(12V→5V)
5. 模拟区（靠车头）：灰度 10P + 8 组（1k / 1.5k / 100nF）
6. 收尾：按键 ×2 / LED ×3(470Ω) / 蜂鸣(PB10→1kΩ→SS8050) / 板边 4 个测试盘
```

---

## 三、三条最要命的（布错要重画）

**① 地 —— 星形单点**
```
功率地 / 逻辑地 / 模拟地 → 在【输出电容负极】汇成一点
⚠ 绝不让电机电流从 MCU 脚下流过 ✗  ←「板子玄学」的头号来源
```

**② 灰度的 8 路模拟线**
```
不许穿功率区 ✗     不许和 VM 铺铜并行 ✗
→ 走板子靠车头那一侧
→ 8 组分压（1k/1.5k + 100nF）贴在【接口旁边】，不是贴 MCU
```

**③ AT8236 的散热**
```
ESOP-8 裸焊盘 → 大块铜皮 + 打散热过孔（手册原话"芯片应直接紧贴散热片"）
每颗的 470µF/25V 就近贴它的 VM 脚
```

## 四、几条小但会咬人的

- **晶振**：贴 MCU、下方**包地**、**禁走任何信号线**
- **IMU 那块位置**离风机 ≥40mm（风机还没装，位置先留出来）
- **第 5 孔距板后缘只有 2.5mm** → 加一片 M2 平垫，拧的时候别崩边
- **灰度模块供 5V**（发射管更亮）→ 8 路输出都是 5V ⇒ **8 组分压一个都不能少**
- **蜂鸣器在 5V**（有源）、其余逻辑都在 3.3V（见引脚图那张供电总表）
- **X 还没量**：框架孔中心 → 轮子内侧面的距离。**<3mm 就把 5 个孔改成"从板边开口的槽"**

## 五、出 Gerber 前自检

```
□ DRC 跑一遍，只剩"器件属性与供应商编号不匹配"那条提示
□ 5 个安装孔位 / 对角线复核（对上框架实测）
□ 丝印有「2026 机器车循迹 + 队伍名」
□ 下表面零元件、朝下的针已剪平
□ 板边 4 个测试盘：3.3V / VM / GND / 空闲 ADC
□ 灰度 8 组分压全在（1k / 1.5k / 100nF ×8）
□ AT8236 ×3：R_ISEN = 0.11Ω / 2512 / ≥1W；裸焊盘大铜皮 + 散热过孔
□ 接插件齐：XT30 / 电机端子×3 / 灰度 10P / 编码器 6P×2 / IMU 8P / SWD 4P / 串口 4P / 按键×2 / 蜂鸣
□ 板框 87（不是 88）；后缘与框架后缘平齐
□ 电路板垫高 6~8mm 的垫柱孔位留好
```
