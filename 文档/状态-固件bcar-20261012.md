## 四、串口命令（115200 8N1，PB6=TX / PB7=RX）

| 命令 | 作用 |
|---|---|
| `HELP` | 命令列表 |
| `PING` | 应答 `PONG` |
| `STATUS` | 状态/节拍/电机/按键/蜂鸣器/MAPR |
| `MAPR` | 打印 AFIO->MAPR |
| `HELLO 0\|1` | 关/开每秒心跳（调参时关掉）|
| `BEEP [ms]` | 蜂鸣 |
| `MODE <IDLE\|TEST\|RUN\|ESTOP>` | 切模式（切换时强制刹车）|
| `MOTOR <FWD\|REV\|BRAKE\|COAST> <0~1000>` | 两侧同设（运行中禁 COAST）|
| `MOTOR L\|R <dir> <mag>` | 只设一侧 |
| `KEY` | 读两个按键电平 |
| **`ENC`** | **编码器累计/增量 —— 推车 1m 标定就看这行** |
| **`ODOM`** | **里程位姿 x/y/yaw/s/v（定点一位小数）** |
| **`ZERO`** | **编码器与位姿清零（标定起点）** |
| **`IMU`** | **陀螺/加速度原始值与 dps（查 SPI 接线用）** |
| **`GYROZERO`** | **陀螺零偏标定（车静止约 1 秒）** |
| **`HEAD`** | **当前航向、零偏、死区** |
| **`IR`** | **8 路原始值 + 归一化值 + err/sum_p/visible** |
| **`IRBLACK` / `IRWHITE`** | **现场把当前读数教成"全黑"/"白线"基准** |
| **`IRPOS <间距mm*100>`** | **改探头间距（如 IRPOS 600 = 6.00mm）** |
| `LOOPBACK [ms]` | TX-RX 短接时的回环自检 |

## 五、★施工中发现的 4 个真问题（都已绕开/修掉）

1. **Windows 不区分大小写**：`drivers/` 与 CubeMX 的 `Drivers/`（HAL）是同一个目录 ⇒ 自写源码统一放 **`bcar/src/`**，否则 CubeMX 重新生成时会把驱动删掉。**框架文档 §1.2 的目录树按此修正。**
2. **CubeMX 命令行不肯生成"USART1 走 PB6/PB7 重映射"**（`IP not ready`）⇒ USART1、TIM1、编码器 TIM2/TIM3 **全部手写寄存器版**。好处：AFIO 重映射、MOE、编码器重映射这些"错了极难查"的点都写在明面上。
3. **中文源码必须补 UTF-8 BOM**：中文 Windows 下 ARMCC 按 GBK 解析 UTF-8 → 一堆 `#870-D` warning，破坏"0 warning"判据。已写 `Tools\fix_bom.py`（二进制里仍是 UTF-8，串口显示中文正常，已验证）。
4. **命令解析 bug（被单测抓到）**：`MOTOR FWD 500` 曾永远解析失败（先截断命令词导致后面参数取不到）；`MOTOR L FWD 500` 又因拿整串比 `"L"` 而失败。解析已抽成纯模块 `str_util.c` + 78 条单测，**改完在电脑上跑，不用上板**。
