## 0. 一句话选型结论

| 项 | 值 | 对我们的意义 |
|---|---|---|
| **VM 5.5~36V**（绝对最大 **40V**） | — | 3S 满电 12.6V **余量巨大**（对比 TB6612 的 13.5V 上限——那就是它的死因） |
| 连续 **3A** / 峰值 **6A**（推荐工作条件 IOUT≤3A、IPEAK≤4.5A） | — | 两个 N30 + 反向冲击都够；TB6612 只有 1.2A |
| RDS(on) **200mΩ**（HS+LS）、同步整流 | — | 发热小，**不需要散热片**，但要贴铜皮 |
| 单通道 | — | 两个电机要 **2 颗**，风机再 1 颗（共 3 颗，与你购物车一致）|

## 1. 管脚定义（ESOP-8）

| 脚 | 名称 | 说明 |
|---|---|---|
| 1 | **GND** | 芯片地；**裸露焊盘(PPAD) 也接电源地** |
| 2 / 3 | **IN1 / IN2** | 逻辑输入，控制 H 桥；**内置下拉电阻**（悬空=低）；VIN 最大 5.25V |
| 4 | **VREF**（AT8236） | 外部参考电压，设定峰值电流，**0.5~4V** |
| 4 | **nFAULT**（AT8236**N**） | 开漏故障输出，**需外接上拉**；过流/过温/欠压时拉低 |
| 5 | **VM** | 芯片电源兼电机电源，**做好电源滤波** |
| 6 / 8 | **OUT1 / OUT2** | H 桥输出；**正向电流定义为 OUT1 → OUT2** |
| 7 | **ISEN** | H 桥检流端，**接检流电阻到地**；不需要限流就**直接接地** |

> **脚 4 是复用的**：AT8236 = VREF；AT8236**N** = nFAULT（内部固定 VREF=3.3V）。

## 2. 真值表（固件照这个写）

| IN1 | IN2 | OUT1 | OUT2 | 功能 |
|---|---|---|---|---|
| 0 | 0 | Z | Z | **滑行（高阻）+ 休眠** |
| 1 | 0 | H | L | **正向** |
| 0 | 1 | L | H | **反向** |
| 1 | 1 | L | L | **刹车**（低端双导通） |

### ⚠ 两个真坑（固件必须知道）

**① `00` 不只是"滑行"，它还会"休眠"**（手册原文）：IN1=IN2=0 持续 **>1ms** → 进休眠（H 桥禁止、电荷泵停）；再要动，**需翻高维持 ≥5µs，约 1ms 后**才恢复正常。

⇒ **控制环里要"停"，用 `11`（刹车），别用 `00`**。否则每次"停→走"都吃 **~1ms 唤醒延迟**——你 5ms 周期里占 20%，会让减速/找线动作发糊。

**② 消隐时间 2.2µs**（手册原文）：H 桥使能那一刻 ISEN 上的电压被忽略 2.2µs → **最小 PWM 导通时间 ≈2.2µs**（20kHz 下 = 占空比 **>4.4%**）。占空比再低，限流就不工作。

## 3. 限流公式（手册原文，第 6 页）

```
ITRIP (A) = VREF(V) / (AV × RISEN(Ω)) = VREF(V) / (10 × RISEN(Ω))
```

- **AT8236（非 N）**：VREF 外部输入（0.5~4V）
- **AT8236N：内部固定 VREF = 3.3V** —— 不用外部分压，还白得一个 nFAULT ✓

**公式自检**（手册第 7 页"典型应用示例"给的条件）：`VIN 24V / IOUT 2A / VREF 3.0V`
→ `R = 3.0 / (10 × 2) = 0.15Ω` ✓ 对得上。

### 我们要 3A

| 选型 | R_ISEN | ISEN 电压 @3A | 功耗 @3A | 备注 |
|---|---|---|---|---|
| **AT8236N（推荐）** | **0.10Ω → 3.3A**；0.11Ω → 3.0A | 0.30~0.33V | ≈1W | 不用外部分压 + 有 nFAULT |
| AT8236 + VREF 0.5V | 0.017Ω → 2.94A | 0.05V | 0.05W | 省电，但要多一路分压、无 nFAULT |

### ⚠ 两条硬约束（会让你买错料）

1. **ISEN 引脚电压绝对最大只有 0.5V**（手册第 3 页"电路工作极限"）→ 必须满足 `I_trip × R_ISEN ≤ 0.5V`。
   按 3A 算 → **R_ISEN ≤ 0.167Ω**（所以 **0.2Ω 不行**）
2. **采样电阻不是"mΩ 级"** —— 是 **0.1Ω 量级**。（原稿写"mΩ 级 2512"是错的，已改到购物车。）
   功耗：常规工作 1A 时 0.1W；**只有堵转那一下到 ~1W** → 选 **2512 / ≥1W** 即可。

## 4. 应用电路（照这个画）

```
                       ┌── 47µF/25V 电解 + 100nF ──┐   （手册要求 VM 就近 ≥47µF）
                       │        （紧贴 pin5）        │
VM ────────────────────┴───── AT8236N                 │
                               pin5 VM ───────────────┘
MCU PA8 ─────── 22~47Ω ─────── pin2 IN1
MCU PA9 ─────── 22~47Ω ─────── pin3 IN2
3V3 ── 10k ─┬───────────────── pin4 nFAULT   （开漏，必须上拉；可接 MCU 读故障）
            └─(可选) 到 MCU
                               pin7 ISEN ──── R_ISEN 0.11Ω/2512 ──── GND
                               pin6 OUT1 ─┬── 电机 A
                               pin8 OUT2 ─┴── 电机 B   （OUT 端子间并 100nF + 磁珠）
                               pin1 GND ── GND
                               PPAD  ── 大块铜皮 + 散热过孔 ── GND
```

**外围元件就这些**：一个滤波电容（47µF 电解，钽更好）+ 一个检流电阻 + nFAULT 上拉。
（立创开源那个"AT8236 4 路驱动"工程的原话也是："**外部的器件也非常少，只需要一个滤波电容，一个限流电阻**"。）

## 5. PCB 版图建议（手册第 6 页原文）

1. **PCB 上应覆设大块的散热片**，地线的连接应有很宽的地线覆线；**芯片应该直接紧贴在散热片上** → ESOP-8 的裸露焊盘焊到大铜皮，**并打散热过孔**
2. **对电源 VM，应连接不小于 47µF 的电解电容对地耦合，电容尽可能靠近器件**（你有 470µF/25V ← 够）
3. **输出端覆线应远离逻辑控制输入端覆线**（避免高速 dv/dt 耦合）
4. 逻辑控制端引线用**低阻抗走线**（降低噪声）

## 6. 保护行为（固件要心里有数）

| 保护 | 行为 |
|---|---|
| **过流 OCP** | 输出关断 → **3ms 后自动尝试重启**（堵塞时自恢复 ✓ 不用你干预） |
| **过温 TSD** | 结温超限 → 禁 H 桥 → 降温后自动恢复 |
| **欠压 UVLO** | VM 低于阈值 → 输出禁 + **内部逻辑复位** → VM 恢复后正常工作（⚠ 电池压降大时会触发 → 这就是"车突然不动了"的一种） |
| **nFAULT**（仅 8236N） | 过流/过温/欠压 → 开漏拉低；**接 MCU 就能报故障** |

## 7. 落到我们的板子

```
两个电机 → AT8236N ×2
风机（预留）→ AT8236N ×1（焊盘留着不贴件）
每颗：R_ISEN = 0.11Ω/2512 ≥1W；VM 就近 470µF/25V + 100nF；PPAD 到大铜皮 + 散热过孔
nFAULT（2 颗可线与后）→ 一路到 MCU（可选，但白得的故障指示）
IN1/IN2 从上板过来串 22~47Ω；走线远离 OUT 与电机线束
```
