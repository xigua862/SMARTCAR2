## 4. 明确**不买**

| 划掉的 | 原因 |
|---|---|
| STC32G + 第二片 MCU | 平台定 C8T6 |
| DRV8701E + 分立 MOS | 手焊风险高，被 AT8236 全集成替代 |
| ICM-42688 LGA 手焊 | 已有现成陀螺模块 |
| **碳板** | **导电**（旁边就是模拟线/5V）；且校赛**不称重** ⇒ "轻"这个优势等于零。结构件改用 **PCB** |
| **3D 打印做底板/结构件** | 蠕变、刚性不足；开源作者原话"能用碳板用碳板，不要用 3d 打印"→ 他并列推荐 PCB |
| **船型开关** | 插件件、朝下会刮/误动作；**优先取消**，用"发车时插 XT30"当总开关 |
| TB6612 / DRV8833 / MX1508 / L298N | 耐压或电流不合规 |
| SMT 贴片工程费 | 全手焊 |

## 5. 下单前必须确认的 5 件事

1. **学长件齐不齐**：N30×2、轮+框架×2、编码器 Pro×2、风机+扇叶+支架、IMU660RC、3S 电池 —— **充电器不在其中，要买**。
2. **灰度模块先问客服 8 条**（框架定稿 §2.4）：路数 / 档距（要板框图+标尺）/ **最小检测高度** / 输出电平 / 波长 / **地址切换 settling** / 板框尺寸 / 供电。**最关键两条：最小检测高度（6mm 能不能认线）、settling（≤20µs）**。
3. **5V 降压模块**：输出必须 **5V**（不是 4.7V）；输入耐压吃 12.6V；连续 **≥400mA**（灰度模块 170 + LDO 输入 120 ≈ 290mA）；纹波靠 220µF + LDO 压住（纹波直进陀螺仪 = Z 零偏漂）。
4. **AT8236 采样电阻阻值**：手册公式 `ITRIP = VREF / (10·R_ISEN)`。**用 AT8236N**（内部 VREF=3.3V）→ 要 3A 就 **R = 0.11Ω**；⚠ ISEN 绝对最大 0.5V ⇒ **R ≤ 0.167Ω**（0.2Ω 不行）。详见 `文档/AT8236-照这个画-20261003.md`。
5. **PCB 打样规格**：结构底板写 **2.0mm 板厚 + 双面铺铜 + 哑黑阻焊**（哑黑=遮光，绿油在近红外下会透光）。

## 6. 花钱优先级

```
① 灰度模块 + 5V 模块 + 主芯片   ← 车能不能跑
② 胎皮                        ← 唯一买得到的物理上限
③ 充电器                      ← 没它一天只能跑一趟
④ 结构 PCB / 电路板打样        ← 打样券常免
⑤ 负压整套（第 3 颗 AT8236）    ← 可 0 元先留焊盘、暂不装
⑥ 备用芯片/备用板              ← 最可砍，但砍了出事就没法比赛
```
