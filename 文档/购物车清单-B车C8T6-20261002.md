## 5. 下单前必须确认的 5 件事

1. **学长件到底齐不齐**：电机×2、轮+框架×2、编码器 Pro×2、风机+扇叶+支架×1、IMU660R×1 —— 已确认全部在手，**这几项 0 元**。
2. ~~IMU660R 怎么切 SPI~~ → ✅ **已核实（逐飞 Gitee 资料 + 逐飞 TC264 开源库）**：模块根本没有 UART，只有 I2C/SPI；逐飞例程默认就是硬件 SPI → **风险解除，不用改方案**。主板 IMU 座留 8P：3V3/GND/CS/SCK/MISO/MOSI/INT1/INT2（SPI 跑 9MHz，INT1 做 DRDY）。
3. **5V 仍压得住吗 + 学长那只能不能改**（v1.5 重算）：① 输入耐压要吃到 **12.6V**（3S 满电）；② 输出能**连续**给 **≥500mA** —— 发射管 **8×20mA = 160mA**（v1.5 按 ITR9909 手册的 IF=20mA 测试条件定，原写 90mA 作废）+ LDO 输入 ~120mA ≈ **280~300mA / 1.5W**；③ 现有模块是固定 4.7V 还是可调？调不到 5V 就补买一只 5V 固定输出。
4. ~~车架开源件孔位~~ → **已作废**：底板你自己设计，尺寸约束见框架定稿 §1.1（轮距 75~85、灰度前伸 ≤45、轴到车尾 ≤50、总长 ≤130）。
5. **AT8236 采样电阻阻值** → 拿到手册按 I_LIMIT 公式算，别照抄任何人的数（N30 堵转标称 <15A，必须限流保护）。

## 6. 花钱优先级（如果预算还要砍）

```
① 胎皮 + 电池/充        ← 不打折，这是物理上限和续航
② 主板 PCB + 电子       ← 不打折，这是车能不能跑
③ 灰度子板              ← 不打折，眼睛
④ 负压整套              ← 可以 0 元先打印、暂不装（框架定稿 §6）
⑤ 备用板 / 备用芯片      ← 最可砍的一项，但砍了出事就没法比赛
```

**再砍的底线**：芯片各买 1、PCB 只打 2 片 → 能压到 **≈ 280**，但校赛当天没有备件。
