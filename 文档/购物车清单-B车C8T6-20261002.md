## 5. 下单前必须确认的 5 件事

1. **学长件到底齐不齐**：电机×2、轮+框架×2、编码器 Pro×2、风机×1 —— 少一样才需要补买。
2. **陀螺仪模块手上有没有**：有 → 省 25~45；没有 → 加进第 3 节（**买 SPI 输出的**，别买 I2C 款）。
3. **DCDC 模块耐压**：12V→4.7V 那个，输入要能吃到 **12.6V**（3S 满电）。
4. **车架开源件的安装孔距/板槽尺寸** → 这个不拿到，PCB 板框定不了（见框架定稿 §1）。
5. **AT8236 采样电阻阻值** → 拿到手册按 I_LIMIT 公式算，别照抄任何人的数。

## 6. 花钱优先级（如果预算还要砍）

```
① 胎皮 + 电池/充        ← 不打折，这是物理上限和续航
② 主板 PCB + 电子       ← 不打折，这是车能不能跑
③ 灰度子板              ← 不打折，眼睛
④ 负压整套              ← 可以 0 元先打印、暂不装（框架定稿 §6）
⑤ 备用板 / 备用芯片      ← 最可砍的一项，但砍了出事就没法比赛
```

**再砍的底线**：芯片各买 1、PCB 只打 2 片 → 能压到 **≈ 280**，但校赛当天没有备件。
