## A. 现场能改的（串口命令，立即生效；掉电丢失）

| 命令 | 作用 | 上电默认 | 怎么调 |
|---|---|---|---|
| `PD <kp×100> <kd×100>` | **循迹转向 PD** | `1000 100`（kp=10.0 kd=1.0） | 画龙/甩头 → 往小调（`PD 600 60`→`PD 400 40`）；拐不动弯 → 往大调（`PD 1500 150`）|
| `LSDIR <1\|2>` | **循迹转向方向** | `1` | 车朝**远离线**的方向拐 → 敲 `LSDIR 2` |
| `SPD <mm/s>` | **速度环目标速度**；`SPD 0` = 关速度环 | `300` | 慢一点 `SPD 200`；想退回手动速度就 `SPD 0` |
| `BASE <mag>` | **手动基础速度**（只在速度环关掉时生效） | `350` | 这车静摩擦大，**低于 ~500 常常推不动**，建议 `BASE 550~650` |
| `GYRO <0\|1>` | **陀螺直行开关**（丢线时用陀螺保航向） | `0`（关） | 先把普通循迹调顺；想开就 `GYRO 1` |
| `SGAIN <kp×100> <kd×100>` | 陀螺直行增益 | `1200 150` | 只在 `GYRO 1` 时有意义 |
| `SDIR <1\|2>` | 陀螺直行方向 | `1` | 同上 |
| `TLM <0\|1>` | **实时行**（每 100ms 一行，走 DMA） | `0` | 调参必开：`TLM 1` → 看 `err= v= st=` |
| `HELLO <0\|1>` | 每秒心跳 | `1` | 调参时 `HELLO 0` 免得刷屏 |
| `IR` | 8 路灰度 raw/p/偏差/visible | — | 查"看不看得见线" |
| `IRBLACK` / `IRWHITE` | 现场教黑白基准 | 已写死实测值 | 只在**换布/改探头高度**后才需要重教 |
| `IRPOS <间距mm×100>` | 探头间距 | `1100`（11.0mm，实测） | 一般不用动 |
| `MOTOR [L\|R] <FWD\|REV\|BRAKE\|COAST> <0..1000>` | 直接点动电机 | — | 查接线/方向用；RUN 里禁 COAST |
| `ENC` / `ZERO` / `ODOM` | 编码器/里程读数与清零 | — | 推车标定用 |
| `KEY` | 两个按键电平 + **按住时长** | — | 验长按 200ms 发车 |
| `MODE <IDLE\|TEST\|COUNTDOWN\|RUN\|ESTOP>` | 切状态 | `IDLE` | 台上试读秒用 `MODE COUNTDOWN`（⚠ 3 秒后真起步）|
| `FAN <0\|1\|2>` | 风机（**坏件，已停用**） | `0` | 换好风机后再用 |

**推荐"最稳组合"**（变量最少，先跑通）：
```
SPD 0
BASE 550
PD 600 60
```

## B. 写死在源码里的（改完要 `python Tools\build.py` 重编 + 重烧）

文件：**`bcar\Core\Inc\bcar_config.h`**

| 常量 | 默认 | 含义 |
|---|---|---|
| `BCAR_CTRL_KP` / `BCAR_CTRL_KD` | 10.0 / 1.0 | 循迹转向 PD（与 `PD` 命令同名同义） |
| `BCAR_CTRL_SLEW` | 40 | **转向变化率限幅**（mag/拍）：0→满舵约 75ms，治猛甩 |
| `BCAR_CTRL_STEER_BASE_P` | 0.9 | **转向量 ≤ 0.9×基础占空比**（内侧轮不许反转） |
| `BCAR_CTRL_STEER_MAX` | 600 | 转向量绝对上限 |
| `BCAR_VEL_KP` / `KI` / `MIN_MAG` / `MAX_MAG` | 0.15 / 0.4 / 380 / 700 | 速度环 PI（慢环，只补摩擦） |
| `BCAR_VEL_HOLD_FRAC` | 0.25 | **大转向时冻结速度环**的门限（治"两个环打架"） |
| `BCAR_V_TARGET_MS` / `BCAR_V_RAMP_MS` | 300 / 600 | 巡航目标速度 / 起步目标速度斜坡 |
| `BCAR_VEL_ON` | 1 | 速度环总开关（0 = 退回手动 `BASE`） |
| `BCAR_STR_ON` | 0 | 陀螺直行总开关（0 = 纯灰度循迹） |
| `BCAR_STR_KP` / `KD` / `STEER_MAX` / `SIGN` / `LOST_MS` | 12 / 1.5 / 600 / 1 / 2500 | 陀螺直行（开着时才有用） |
| `BCAR_IR_BLACK_ARR` / `WHITE_ARR` | 实测 8 对 | **逐路黑白基准**（真赛道材料实测） |
| `BCAR_IR_PITCH_MM` | 11.0 | 探头间距（用户实测） |
| `BCAR_MM_PER_COUNT` | 1000/201330 | 里程标定（推车 1m 实测） |
| `BCAR_MOTOR_DIR_FLIP` | 1 | 电机方向（实测：原来是反的） |
| `BCAR_CTRL_KICK_MAG` / `KICK_MS` | 800 / 400 | 起步斜坡（速度环关掉时才用） |
| `BCAR_FAN_DIR` / `FAN_DUTY` | 0 / 800 | 风机（0 = 停用，坏件） |
| `BCAR_LAP`… `BCAR_FINISH_*` | 见源码 | 过 S / 到 G 停车的判据与里程兜底 |
