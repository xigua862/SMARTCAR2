# test16 循迹小车使用手册

> STM32F103C8T6 + HAL 库 · 双电机三轮循迹小车
> 本文件夹是从 `Desktop\F103C8T6\test16` 复制出来的调车工作副本，以后调车、调参都改这里的代码。

---

## 1. 项目功能总览

| 功能 | 实现方式 |
|------|----------|
| 电机驱动 ×2 | TIM2 双通道 PWM 调速（CH3/CH4，10kHz）+ 4 路 GPIO 控制方向 |
| 循迹 ×5 | 红外循迹模块数字输入，加权误差算法 |
| 测速 ×2 | 霍尔模块，EXTI 上升沿中断计数，算 RPM |
| 串口调试 | USART1 @ 115200，打印传感器状态和转速 |

控制流程：主循环每 20ms 读一次 5 路传感器 → 算加权误差 → P 控制差速驱动左右轮；每 500ms 算一次转速并打印。

## 2. 引脚分配总表（接线就按这个）

### 电机（TIM2 + GPIO）

| 引脚 | 功能 | 接线对象 |
|------|------|----------|
| PA2 | TIM2_CH3 PWM | 电机1 PWM（驱动板 ENA/IN 对应脚） |
| PA3 | TIM2_CH4 PWM | 电机2 PWM |
| PA4 | DIR1 | 电机1 方向A |
| PA5 | DIR2 | 电机1 方向B |
| PB3 | DIR3 | 电机2 方向A |
| PB4 | DIR4 | 电机2 方向B |

### 循迹传感器（5路，从左到右）

| 引脚 | 宏名 | 位置 |
|------|------|------|
| PA8 | IR_L | 最左 |
| PA15 | IR_LM | 左二 |
| PB5 | IR_C | 中间 |
| PB6 | IR_RM | 右二 |
| PB7 | IR_R | 最右 |

### 霍尔测速（EXTI 中断）

| 引脚 | 宏名 | 接线对象 |
|------|------|----------|
| PA11 | HALL1 | 电机1 霍尔模块 OUT |
| PA12 | HALL2 | 电机2 霍尔模块 OUT |

### 串口（调试用）

| 引脚 | 功能 |
|------|------|
| PA9 | USART1_TX → USB转TTL 的 RX |
| PA10 | USART1_RX → USB转TTL 的 TX |

### 其他占用

| 引脚 | 用途 |
|------|------|
| PA13/PA14 | SWD 下载调试（ST-Link） |
| PD0/PD1 | 外部 8MHz 晶振（HSE） |

**重要**：以上引脚全部是 5V 容忍（FT）引脚，循迹/霍尔模块输出 5V 可直接接。**千万不要**把模块信号接到 PA0~PA7、PB0/PB1 这些非容忍引脚上，会损坏单片机。模块供电另接 5V，但**所有模块的 GND 必须和单片机共地**。

## 3. 代码结构说明

### Core/Src/main.c —— 全部逻辑都在这里

| 位置 | 内容 |
|------|------|
| 顶部 `#define` | **调参就在这里**：`BASE_SPEED`、`KP`、`PULSES_PER_REV`、`LINE_ACTIVE_LEVEL` |
| `read_sensors()` | 读 5 路传感器，加权算误差：偏左为负、偏右为正、居中为 0；丢线时沿上次方向加强修正 |
| `line_follow()` | P 控制：`修正 = KP × 误差`，左轮 = 基础速度 − 修正，右轮 = 基础速度 + 修正，限幅 ±99 |
| `speed_report()` | 每 500ms：清计数器 → 算 RPM（计数×120÷每转脉冲数）→ 串口打印 |
| `change1/change2()` | 电机驱动：正数正转、负数反转、0 停止（含方向引脚控制） |
| `HAL_GPIO_EXTI_Callback()` | 霍尔脉冲中断回调：PA11/PA12 上升沿各计一次数 |
| 主循环 | `HAL_GetTick()` 非阻塞定时：20ms 循迹控制 + 500ms 测速打印 |

### 其他文件（一般不用动）

- `tim.c`：TIM2 初始化，PWM 10kHz（预分频 72-1，周期 100-1）
- `usart.c`：串口 115200 初始化
- `gpio.c`：所有引脚初始化 + EXTI 配置 + 中断使能
- `stm32f1xx_it.c`：`EXTI15_10_IRQHandler` 中断入口
- `test16.ioc`：CubeMX 工程文件，引脚配置和代码是同步的

## 4. 参数调节（main.c 顶部）

| 参数 | 默认值 | 作用 | 调节建议 |
|------|--------|------|----------|
| `BASE_SPEED` | 60 | 基础速度(0~99) | 太快冲出线就调小；太慢爬不动就调大（可在线发 `S 80`，见 §5.1） |
| `KP` | 10 | 循迹比例系数 | 车左右摆头→调小；跟不上弯道→调大（可在线发 `P 15`，见 §5.1） |
| `PULSES_PER_REV` | 1 | 轮上磁铁数 | 改成你轮子上实际磁铁个数，转速才准 |
| `LINE_ACTIVE_LEVEL` | `GPIO_PIN_RESET` | 传感器触发电平 | 若你的模块检测到黑线输出**高**电平，改成 `GPIO_PIN_SET` |

## 5. 串口打印格式（115200, 8N1）

```
IR:10101 RPM1=120 RPM2=118 KP=10.0 SP=60
```

- `IR` 后 5 位 = 5 路传感器状态（1=检测到线），从左到右依次是 IR_L / IR_LM / IR_C / IR_RM / IR_R
- 传感器装好后先用这个验证接线和触发逻辑（对着黑线/白纸分别看）
- RPM 用手拨轮子可以验证
- `KP=` 当前循迹比例系数、`SP=` 当前基础速度——**都可以在线改，见 §5.1**

### 5.1 串口在线调参（不用重烧）

在串口助手里直接发命令（末尾回车即可，大小写都行）：

| 命令 | 作用 | 示例 |
|------|------|------|
| `P <KP>` | 改循迹比例系数（0.5~50，支持小数） | `P 15`、`P 12.5` |
| `S <速度>` | 改基础速度（0~99） | `S 80` |
| `T <1\|2> <速度>` | 单电机测试（暂停循迹，只转指定电机） | `T 1 30`、`T 0 0` 停止 |
| 其他任意 | 打印命令格式帮助 | `?` |

- 修改**立即生效**，串口回 `OK KP=15.0` / `OK SP=80`，下一条 `IR:...` 里的 KP=/SP= 同步更新
- 配合调车：直线摆头→降 KP；弯道跟不上→升 KP；太快冲出线→降 S
- 掉电重启恢复默认值（`BASE_SPEED=60`、`KP=10`，改 `main.c` 顶部即可换默认）

## 7. 循迹 P 控制调参指南

当前是 P 控制（`修正 = KP × 误差`），对循迹小车来说一般 P 就够了：

1. **先调基础速度**：`BASE_SPEED` 从 40 开始（或直接发 `S 40` 在线改，见 §5.1），车能稳定走直线再慢慢加
2. **再调 KP**：直线段摆头（S 形抖动）→ **降 KP**；过弯反应迟钝、冲出线 → **升 KP**（发 `P xx` 在线改）
3. 误差最大 ±4，`KP×误差` 最大 ±40，KP 一般取 5~20 之间
4. 丢线时程序会沿上次偏差方向加强修正去找线，如果每次丢线都跑飞，把 `last_error * 2` 改成 `last_error`（或相反）

**以后要加 PID 的扩展点**：`line_follow()` 里把误差积分/微分项加进 `corr` 即可；积分项可以消除直线段恒偏差，微分项抑制摆头（但循迹车一般用不上）。

## 8. 常见问题排查

| 现象 | 排查方向 |
|------|----------|
| 串口没数据 | ① 板子没晶振/程序卡死（看 HSE）② TX/RX 接反 ③ 波特率不对 ④ 没共地 |
| 电机不转 | ① 驱动板没上电 ② PWM/方向引脚接错 ③ 检查 `change1/change2` 里的方向电平 |
| 传感器数值全 0 或全 1 | ① `LINE_ACTIVE_LEVEL` 反了 ② 模块灵敏度电位器没调 ③ 没共地 |
| 转速显示为 0 | ① 霍尔接线 ② 磁铁离模块太远 ③ `PULSES_PER_REV` 不对 |
| 车走不了直线 | 先确认两个电机空载转速一致（看串口 RPM），不一致查机械或 PWM 占空比 |
