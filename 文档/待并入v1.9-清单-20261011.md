## 3. 【提案】§3.1-B 串口协议（115200 · USART1 重映射 PB6/PB7 · TX 走 DMA）

```
SET <键> <值>   → OK            （值：整数不带小数点，浮点 %.8g；键不在白名单 → ERR KEY）
GET <键>        → OK <值>
RUN <n>         → ACK           （随后跑 n 圈，每圈结束打一行 LAP）
非法命令/解析失败 → ERR <原因>
行尾 \n；命令应答超时 = 调参器侧 serial_timeout_s；固件侧不阻塞控制周期（TX DMA）
```

- 与两键语义的关系（§3）：**PB0 测试键** 进测试模式时，电机滑行休眠、**串口纯做取数/调参**（正是调参器接入的窗口）；**PC13 发车键** 走正式流程。
- `autorun` 与 `RUN n`：上电按 `autorun` 自跑；`RUN n` 为在线覆盖。

## 4. 【提案】§3.1-C 每圈 LAP 遥测行（字段顺序固定，脚本按行解析）

```
LAP,<圈号>,<跑完0/1>,<耗时ms>,<里程mm>,<线RMS>,<线P95>,<线MAX>,<惯导RMS>,<惯导P95>,<补偿角均值deg>,<脱线次数>,<结束原因>
例：LAP,3,1,8420,13720,1.8,3.9,6.4,2.1,4.8,0.7,0,OK
```

**口径（已按错位 3 修正到 v1.8）**：

| 字段 | v1.8 口径 | 出处 |
|---|---|---|
| 线偏差 RMS/P95/MAX | `line_pos` 归一化加权质心 err 的绝对值统计 | §2.5 `err=Σ(IR_POS·p)/Σp` |
| 惯导横向偏差 RMS/P95 | `odom` 位置相对**已知 CAD 中心线**的横向偏差 | §3 惯导为主·已知几何 |
| 补偿角均值 deg | `ins_corr` 环输出的航向补偿均值（**左正**，与 §2.5 符号标定一致） | D2 新建环 |
| 脱线次数 | 本圈 `Σp==0` 丢线分支命中次数 | §2.5 丢线分支 |
| 结束原因 | 枚举 `OK/LOST/TIMEOUT/OFFTRACK/SPIN/ABORT/INCOMPLETE` | 本提案 |
| 结算点 | **过起点**（里程窗 ∧ 圈数达标，与 `finish` 判据同源、元素互斥） | §3 判据纪律 |
| 采样口径 | 每 **5ms** 控制拍采一次；P95 = 排序取 95 分位（或近似分位） | §3 5ms 周期 |

⚠ 若 D2 的 `ins_corr` 环最终未建，则"补偿角均值"列恒填 0 并在固件注明（不删列，保脚本兼容）。
