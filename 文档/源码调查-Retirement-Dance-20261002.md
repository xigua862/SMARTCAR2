## 1. 网页里扒到的**规则原文**（比板子更重要，先看这条）

> 1. 车辆**依靠电磁传感器识别载流导线**自主循迹，需通过直角、环岛、十字、跷跷板、垂直墙面等全部赛道元素。
> 2. 车模需搭载**负压吸附**结构，实现跷跷板、墙面以及圆桶等立体赛道的通行。
> 3. **整车重量（含电池）100g 以内不罚时，超出 100g 按每 20g 罚时 1s**。沿赛道**连续行驶完整两圈**完成比赛，最终成绩 = 循迹时长 + 重量罚时。

**三条直接推论：**

| # | 推论 | 对我们的影响 |
|---|---|---|
| ① | 这个组别的赛道是**地下埋通电导线**，表面**没有可见引导线** | ⚠️ **红外地在这条赛道上看不见线**。除非你们跑的赛道另有白/黑标线（校赛/省赛微缩赛道常见），否则**"改红外"这个前提本身不成立** → **今天必须确认：赛道上有没有可见线？还是只有埋线？** |
| ② | 100g 是**罚时线**，不是硬上限（超 20g 才罚 1s） | 电池/结构不必为省 5g 玩命；他们 108.15g = 罚 1s 以内 |
| ③ | 要**连续两圈** | 电量必须撑住两圈 + 中途不能过热；电池容量不能只按一圈选 |

> 注：如果确认赛道是**埋线**，那红外的替代方案只有两条：**(a) 照抄他们的 4 路电感 + 运放**（一行板子都不用改，最省事）；**(b) 自己画电磁板**（要信号发生器/工频电流源，现场条件麻烦）。**这个决定比改板清单里的任何一条都大。**

### → 红外 8 路接哪里：**P1 整组 8 个脚全空**

`P1.0 ~ P1.7` 在代码里**一个都没用到** → 直接接 8 路红外，而且 8051 可以**一条指令读整个 P1 口**：

```c
#define IR_PORT   P1
ir_bits = (uint8)(~IR_PORT);      // 一次读 8 路，比 8 次 gpio_get_level 快一个量级
```

⚠️ 两个让位条件：`P1.0 = RxD2`、`P1.1 = TxD2`。**如果要用第二路串口接蓝牙/上位机遥测**，就让出 P1.0/P1.1，红外改用 `P1.2~P1.7 + P2.0 + P2.1`（P2 组也基本空着，但 LQFP64 只有 P2.0~P2.3，**下单前对着原理图数一遍**）。

## 4. 控制链路（2ms 一拍，500Hz）

```
TIM1 中断(2ms) ──> get_encoder_vle()  读编码器→轮速、累计里程
              └─> electro_magnetic_collect()  4路ADC→归一化→ERR→状态机
              └─> xunji_flag = 1
主循环 ──> 角度环 PD(ERR) ──> 角速度环 PD(gyro_z, 0.7*误差+0.3*上一级输出) ──> 速度环 增量PI(左右轮) ──> motor_control()
```

**误差公式（差比和，`adc.c:118`）**
\[
ERR=\frac{A(L_X-R_X)+B(L_Y-R_Y)}{A(L_X+R_X)+C|L_Y-R_Y|+1}\times 100,\quad A=C=1,\;B=K_b=1.2
\]
→ 换红外后，`L_X/R_X` 用**左右横向两对**、`L_Y/R_Y` 用**前后纵向两对**去凑，或者直接换成 8 路**加权重心**：
\[
ERR=\frac{\sum_{i=0}^{7}w_i s_i}{\sum w_i s_i}\;,\; w=[-7,-5,-3,-1,1,3,5,7]
\]

**默认参数（`pid.c` / `adc.c`，可直接当起点）**

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| 角度环 `kp/kd` | **55 / 50** | 圆环专用 `kp/kd` | 70 / 50 |
| 角速度环 `kp/ki/kd` | **1.3 / 0 / 0.1** | 速度环 `kp/ki/kd` | 10 / 1.2 / 0 |
| 目标车速 `car_speed` | **650**（计数/2ms） | 负压占空比 `power` | **888**（满 10000） |
| 角度环限幅 | ±5000 | 角速度环限幅 | ±600 |
| 速度环限幅 | 0~10000 | 积分限幅（gyro） | ±30 |
| 电感满量程标定 | 925/925/928/926 | 入环阈值 | 1300（横）+400（纵） |
| 差速系数 | 内侧 ×1.2 / 外侧 ×0.9 | PWM | **17kHz**，占空比标度 10000 |

**两个坑（代码里能直接看出来）**
1. `speed_control()` 里 **失线就 `while(1){motor_control(0,0);}` 死循环停车**（`adc.c:200`）——赛道上一瞬间全 0 就会**当场停死**，这是他们的"终点检测"逻辑，**我们改红外必须重写这段**（红外抖一下很正常）。
2. `flyboard()` / `ring_judge()` 两个状态机（圆环 5 态、飞坡 4 态、12 个环编号、2/6/10 小环 3/7/11 大环）是**飞檐走壁赛道专用**，B 车如果不跑同样的赛道 → **整块删掉，代码量立刻少一半**。

## 5. 电源需求（你要的：电池、电压、电流）

### 5.1 电压 —— **只能用 3S，严禁 4S**

| 项 | 值 | 依据 |
|---|---|---|
| 电池标称 | **3S 锂聚 11.1V**（满电 **12.6V**，截止 **9.6V** 建议停跑） | 作者原文"电源部分采用 3S 锂电池供电" |
| **硬上限** | **16V** —— 入口 TVS = **SMAJ16CA**（双向 16V） | 4S 满电 16.8V 会让 TVS 长期导通 → 发烫/炸管/起火 |
| 输入电容耐压 | 25V（原理图里 25V 料 16 处） | 3S 安全 |
| 防反接 | **SS54F 肖特基**，压降 0.3~0.5V（**别省，A 车烧板教训**） | |
| 5V 母线 | TPS62933 同步降压 | 供驱动逻辑/预驱/屏 |
| 3.3V | RT9013 LDO → 主控 + ICM42688 + **红外** | |
| VCCCOP | 另一路 LDO → 运放 | **删电感前端后这路可以一起删** |

### 5.2 电流预算（按 100g 微缩车的实际负载）

| 负载 | 平均 | **峰值** | 说明 |
|---|---|---|---|
| 左轮有刷（030/8520 级） | 0.3~0.6 A | **2~3 A**（堵转） | 待你报电机型号后收窄 |
| 右轮有刷 | 0.3~0.6 A | **2~3 A** | |
| 负压风机（有刷 8520，≈7W） | 0.6~0.9 A | **2~3 A 启动浪涌** | `Micro_car`：7W 吸 1.2kg |
| 全部电子（5V+3.3V） | 0.15~0.3 A | 0.4 A | 主控 30 + IMU 2 + **8路红外 40~80** + 屏 40 + 蓝牙 100 mA |
| **合计** | **≈1.5~2.5 A** | **≈6~8 A** | 峰值 = 双轮堵转 + 风机启动同拍 |

> 驱动能力**完全不是瓶颈**：`DRV8701E` + `TPN2R703NL`（7mΩ 级）按 20~30A 设计，跑 3A 电机是杀鸡用牛刀——好处是**发热极小、不用散热片**。

### 5.3 买什么电池（照这个规格买）

| 项 | 要求 | 为什么 |
|---|---|---|
| 类型 | **3S 动力软包锂聚**（FPV/无人机那种高倍率） | 18650 组太重 |
| 容量 | **300~450mAh** | 规则要**连续两圈**；3.3~5Wh 绰绰有余 |
| 放电 | **持续 ≥10A / 瞬时 ≥20A / ≥20C**（例：450mAh 45C ≈ 20A） | 峰值 6~8A，要留 2 倍余量 |
| 内阻 | **≤30mΩ** | 内阻大 → 启动压降 → 5V 掉 → 复位/重启（最常见"板子玄学"） |
| 重量 | **≤15g**（含线） | 每 20g 罚 1s |
| 放电端子 | **XT30**（或至少 XT20） | ⚠️ **原板电池入口是 `ZX-PZ2.0` 2.0mm 座/焊盘，额定只有 2~3A 级，扛不住 6~8A 峰值 → 必改！** |
| 平衡头 | 保留 3S 平衡头 | 必须用**平衡充电器**（B6/AC6 类） |
| **不要**带保护板的成品 3S | — | 保护板限流 3~8A，电机一启动就触发断电；保护交给板上的 SS54F+TVS |
| 数量 | **3 块 + 1 个平衡充** | 调车一天十几轮充放 |

### 5.4 报电机型号时顺便告诉我这几项（我才能把电流表算准）

`电机型号` · `标称电压` · `空载电流` · `额定/负载电流` · `堵转电流`（或产品页截图）· 负压风机型号 · 车轮直径和齿轮比（决定所需扭矩）。
