## 0. 先回答你两个问题（重要，关系到工具链）

### 能不能用 ST-Link 烧录？——**不能，绝对不行**

- STC32G12K128 是**宏晶 8051 内核**，不是 STM32 的 ARM Cortex-M，**没有 SWD 口**。
- ST-Link / J-Link / DAP-Link / STC-Link 这类**一个都用不上**。
- 唯一烧录方式：**串口 ISP** —— USB转TTL（CH340/CP2102/FT232 都行）+ 官方 **STC-ISP** 软件。
- **好消息：这块板已经把下载电路画好了**（你截图左下「下载电路」）：
  - 4P 下载座 `PZ127V-11-04-0720`：`GND / TXD / RXD / VCC3V3`
  - `R6 10kΩ` 上拉 RST + `C46 100nF` + `SW1` 复位按键 → **冷启动下载**（点一下复位就能进 ISP）
  - → 你只需要一根 **3.3V 电平的 USB 转 TTL**，插上去、STC-ISP 里选型号、按复位，就能烧。
- 芯片本身**带 USB**（原理图引脚名 `P3.0/RxD/D-`、`P3.1/TxD/D+`，USB 与串口复用），但**本板没把 USB 引出来**；剩十多天，**别改 USB，走串口**。

### 串口能用吗？——**能用，而且不止一路**

- 从符号引脚名看，这芯片至少 **4 路独立 UART**：
  | 串口 | 引脚 | 建议用途 |
  |---|---|---|
  | SCI1 | `P3.0/RxD` `P3.1/TxD` | **烧录 + 下载专用**（已接下载座，别再挂别的） |
  | SCI2 | `P1.0/RxD2` `P1.1/TxD2` | **接蓝牙 / 上位机遥测**（调参口） |
  | SCI3 | `P5.0/RXD3` `P5.1/TXD3` | 备用（屏幕 / GPS / 第二外设） |
  | SCI4 | `P5.2/LIN_RX_2` `P5.3/TXD4` | 备用 |
  | 另有 | `P4.3/RxD_4` `P4.4/TxD_4`、`P3.6/RxD_2` `P3.7/TxD_2` | 复用脚，被 SPI/CAN 抢，先别当串口用 |
- **铁律：下载口和调试口必须分开**。STC 下载靠 RXD 检测冷启动帧，**如果下载口上还挂着蓝牙/屏幕，会抢线导致时好时坏烧不进去**（这是 STC 平台最常见的"板子坏了"假象）。
- ⚠️ **STC 不能在线单步调试**（没有 ARM 那种调试器）。所有排查只能靠**串口打印**。
  → A 车那套**遥测 + `tune.ps1` 串口调参**的工作流**必须移植**，这是唯一能撑住 7 天调车的办法。

## 2. 必须加上的（红外循迹）

| 加什么 | 具体接法 | 为什么 |
|---|---|---|
| **1 个红外接口座** | 1×9 或 1×10（**2.54mm 带定位**，或直接用现成的 `SM10B-GHS-TB` 防呆座）：`VCC / GND / IR0..IR7` | 别用排针裸插——A 车烧板连环案就是悬空+错插 |
| **8 路串阻** | 每路信号 **100Ω~1kΩ** 串电阻（0402） | 错插/热插拔时保护 GPIO；顺带抑制振铃 |
| **本地去耦** | 红外座旁 `10µF`（或 100µF 钽/MLCC）+ `100nF`×2 | 红外发射管是脉冲负载，纹波会打 ADC 和陀螺 |
| **供电 = 3.3V** | 红外模块 VCC 接 **U4 出来的 3.3V**，**不要接 5V** | STC32G 3.3V 供电，**GPIO 不耐 5V**；数字红外模块 3.3V 也能正常工作，输出电平=3.3V，直接进 MCU 最省事 |
| **8 个 GPIO** | 优先用**删掉电感后空出来的 ADC 脚**（`P1.x/P0.x` 那批带 ADC 复用的），做纯输入 | 少动布线、少改网络标号 |
| **（可选）1 路发射管使能** | 找一个 GPIO 经三极管控红外 VCC | 能**主动关发射管省电/减热**，也能做"上电自检" |

> **前瞻距离**：按 A 车已验证结论，**传感中心→驱动轴 110~120mm**（A 车 213mm 太长，弦切偏差 66mm）。红外条装他们**原前瞻板的位置**（那块独立小板，尼龙螺丝+502 固定），结构不用重新设计。

## 3. ★ 最大的省时间决定：负压走**有刷**，把第二套驱动整个删掉

现在板子上有**两条独立驱动链**：

| 链 | 器件 | 干什么 |
|---|---|---|
| A：**U13 + U16** | 2× `DRV8701E` + **8× `TPN2R703NL`**（16 MOS） | 左右两轮 **两个 H 桥**（有刷） |
| B：**U21 + Q1~Q6** | `EG2134` + **6× `100N03DF`** 三相全桥 + 反电势换向检测 | **无刷负压风机** |
| C：**U20** | 第 2 片 `STC32G12K128-35I-LQFP48` | 专职跑无刷驱动算法 |

**建议：删掉 B + C，负压改用有刷风机（8520/8523 + 打印扇叶，`Micro_car` 那套）。**

理由（都是"一个人、十多天"的约束）：
1. **DRV8701 天生是三相预驱 = 每片 3 个半桥**，两片共 **6 个半桥 = 3 个 H 桥** → **左轮 + 右轮 + 负压风机**，**现成的 A 链就够三路**，只要把第 3 个半桥接出来；
2. 无感反电势换向（`VS1/VS2/VS3` + 比较器 + 那 4 个电位器调阈值）是**最容易调不完的东西**，国一队伍也是拿一整年磨的；
3. 删掉 = **少 1 颗 MCU + 1 颗预驱 + 6 个大电流 MOS + 一整套换向检测**，**重量、焊接量、代码量同时砍**；
4. 负压风机**不需要精确控制**，PWM 调速就够（`Micro_car` 作者 7W 吸 1.2kg 就是有刷方案）。

**代价**：有刷风机寿命短、噪音大 → 备 2 个电机（几十块钱）。
**如果规则/性能必须无刷** → 那就**原封不动抄他们的 B+C 链**，别自己改，并且**必须拿到他们的源码**（无感换向没源码基本做不出来）。

## 5. 现实提醒（打样 / 贴片 / 时间）

1. **DRV8701E 是 VQFN-24（0.5mm 间距，底部散热盘）**、**ICM-42688-P 是 LGA**、**TPN2R703NL 是大功率模块** → **手焊风险高**。
   → **直接下嘉立创 SMT 贴片**（BOM 已导出：`开源整车情报-BOM-飞檐走壁.csv`，383 行带位号+型号+封装），别自己焊。
2. 打样 + SMT 一般 **3~5 天**到手 → **板子必须今天/明天定稿**，否则 7 天里没车可调。
3. 功率级注意：**VM 走线 ≥40mil**、**大电容紧贴 DRV8701 的 VM**、**开铜/散热窗**、**信号线远离晶振和电机线**（A 车《CSDN-B6》里记的）。
4. **丝印留队伍名**（A 车文档记录检查看板子要有"年份+赛项+队伍名"丝印，缺了可能被卡）——B 车按自己组规则核。
5. `.epro2` 是**别人 4.1.60 版本的工程**，你本地编辑器版本要 ≥ 它，否则可能打不开/丢东西 → **先打开确认能看能改，再动手**（这一步做完再告诉我）。
