## 0. 一句话框架

**主板（控制+驱动一体）＋ 灰度子板（可单独换）＋ 现成陀螺仪模块立装**；
电机 12V 直给、逻辑走 **12V→5V→3.3V**（v1.7 恢复双轨：**子板 5V + 3.3V**，见 §2.2/§2.4）；
软件 10ms 一个控制周期，**每种赛道元素只允许一套判据**。

## 1. 结构路线（v1.1 定稿：底板自己设计，不用开源车架）

你说得对：框架（电气 + 软件）定死后，底板只是一块带孔的板。原 v1 那条
"先定车架再画板"的警告**自动解除**，改成一次做完这三步：

```
① 底板：先画（安装孔位、电机座、铜柱位置、灰度板前伸量、负压圆孔）
② 主板板框 + 接插件位置：对着底板的孔位画，接插件全部走板边
③ 灰度子板：最后画（离地 3~8mm、遮光、阈值要实测改版）
```

### 1.1 底板设计约束（一次给全，照着摆）

| 项 | 定稿值 | 依据 |
|---|---|---|
| 轮距 | **75~85mm**（以两个轮框架中心距为准） | 差速转向几何 |
| 灰度板前缘→驱动轴 | **45mm（取上限，别留余量）** | 差速车绕驱动轴转，装在轴后读到的是"已经转过去的线"→必滞后。R200 上提前偏移 d²/(2R)=5.1mm≈半档，换算成 **37.5ms ≈ 3.7 拍** |
| 驱动轴→车尾 | **≤50mm** | 同上：50mm→6.3mm ✅；70mm→12.3mm ❌ |
| 整车总长 | **≤130mm** | 上两条 + 电机长度 |
| 电池位置 | **尽量靠后、贴低** | 平衡灰度板前伸力矩，也是"不加球脚"的第一优先手段 |
| 底板开圆孔 | **✓ 现在就开 + 留 4 个螺丝孔 + 密封圈压边平** | 负压退路（§6），风机/扇叶/支架你都有 |
| 主板与底板 | 主板用铜柱**架在底板上方** | 爬壁开源作者原话：框式架构、PCB 架在上面刚性足；同时当负压腔上盖/支撑 |
| 底板加强 | 四周立边 ≥5mm 或 1.5mm 加强筋 | 防"开负压后底板变形、轮子外八"（作者踩过） |
| 陀螺仪位 | 四角减震柱，**离风机 ≥40mm**，板面印方向箭头 | 扇叶共振→螺丝松→陀螺漂；方向错则角度符号反 |
| 球脚 | **先不加**，按 §1.2 判据实测后再定 | 打印免费，加个可调支撑座 20 分钟 |

### 1.2 前球脚判据（30 秒测完，别提前设计）

```
车放平，松手 → 看车头是否下沉、灰度板前缘压到线
  压到 → 先只做两件事：① 电池后移 ② 灰度板前伸减到 35mm
         仍压头 → 才加支撑，且用【小滚轮】不用万向球（滚轮摩擦小、不啃喷绘布）
         第三触点必须落在驱动轴中线上，偏了会把车"顶"着跑偏
```

## 1.3 编码器装轮轴 → 标定大幅简化（v1.1 确认）

装在**轮轴**意味着：**减速比彻底不需要知道，连推车标定都能省**。

```
1 轮转 = 1024 脉冲 = 4096 计数（4 倍频）
每计数位移 = π·D / 4096
  D=32mm → 0.0245 mm/count      D=40mm → 0.0306 mm/count

频率与溢出（D=32mm 为例）
  v=1.2m/s → 轮 716rpm → 12.2kHz → 4× 后 48.9k count/s
  16 位溢出周期 = 65536/48.9k ≈ 1.34s   ← 极宽松，不会绕圈
  10ms 窗口 = 489 count → 分辨率 0.2%    ← 够用
  起步 0.1m/s → 41 count/10ms → ±2.4%    ← 可接受（嫌糙再上 M/T 法）
```

→ **控制周期仍定死 10ms**，但理由变了：不再是被编码器溢出逼的，而是被响应性与遥测刷新率定的。
→ 唯一必做的标定：**量轮径 D**（软尺绕轮胎一圈 ÷ π 比卡尺准；胎皮会磨，一场比赛后复量）。
→ "推车 1m 数脉冲"降级为**校验**：算出的 mm/pulse 与实测差 >2% → 轮径量错或编码器丢脉冲。
→ ⚠ 轮轴编码器的固有代价：**轮子打滑时里程虚高** → 圆环/终点判据不能只靠里程，必须叠陀螺角度积分兜底。

## 2. 硬件框架（画板的直接输入）

### 2.1 分板策略（为什么不做成一块板）

| 板 | 内容 | 为什么分开 |
|---|---|---|
| **主板** | C8T6 + 2×AT8236（+1 预留）+ LDO + 全部接插件 | 撞坏概率低，但改一版代价高 |
| **灰度子板** | 8×ITR9909 + **4×LM393**（双路，一片只管 2 路）+ **11P 排针（8DO/GND/3V3/5V）** + 8 只逐路电位器 | **离地高度/遮光/阈值要反复调**，分板 = 迭代最便宜；撞了只换子板 |
| 陀螺仪 | 现成模块，排针立装 | 可拆 + 加减震柱 |

### 2.2 电源树

```
3S 锂电 11.1~12.6V
 └ XT30 ─ 船型开关(≥10A) ─ 保险/PTC 10A
    ├─【功率轨 VM = 12.6V 直给】→ AT8236 ×2(+1) → 电机 / 风机
    │     就近：470µF/25V ×1 + 0.1µF ×3；OUT→端子间 100nF + 磁珠
    └─【逻辑轨】→ 12V→**5V** 降压模块（v1.7：补买/换一只 **5V 输出**，别用 4.7V，见下）
          │
          ├ 灰度子板**功率侧**：8×发射管（180Ω/只）+ **4×LM393 的 VCC** → 排针送 5V
          │
          └ AMS1117-3.3（≥300mA）→ **3.3V —— 子板的信号侧 + 全车逻辑电平**
                ├ C8T6 + 晶振 + SWD
                ├ 灰度子板**信号侧**：接收管上拉 / 阈值电位器 / 输出上拉 / 指示灯
                ├ 陀螺仪模块 IMU660RC（已核实 3.3~5V 自适应、自带 LDO → 给 **3.3V**）
                └ 蜂鸣 / LED / 上拉
   地：功率地与逻辑地单点相连（0Ω 或磁珠）；灰度子板地走独立回线，不穿过功率区
```

**三条硬约束（违反必翻车）**

1. **两条轨的预算（v1.7 按双轨重算）**
   - **5V = 165 + 6 + 120 ≈ 290mA** → 发射管 8×21mA = **165** + LM393 4 片 ≈6 + LDO 输入 ≈120
     → **降压模块要能连续 ≥400mA**；⚠ **别用学长那只 4.7V**：4.7V 时 LM393 共模上限 3.2V，
     而黑态节点就是 3.3V —— **超限 0.1V**，表现为"阈值拧到上半段没反应"。5V 时上限 3.5V，余量 0.2V ✅
   - **3.3V ≈ 90~120mA**（MCU/IMU 60 + 上拉与杂 30~50）→ **AMS1117-3.3（≥300mA 即可）**（`RT9013 只 250mA`，不推荐）。
     LDO 耗 `(5−3.3)×0.12 = 0.2W` ✅
   - ⚠ 严禁让 LDO 直吃 12.6V —— `(12.6−3.3)×0.12 = 1.1W` → SOT-223 进热保护。**降压那一级不能省。**
   - LM393 是**双路** → 8 路要 **4 片**（2 片的方案是 LM339 四路）。
2. **N30 堵转标称"<15A"，超 AT8236 峰值 6A** → 每颗 AT8236 **必须按手册算采样电阻把限流设到 3A**。
   这一条同时是你那类"卡死烧板/震动断电"的保险丝。
3. **严禁 4S**（逻辑轨模块与 AT8236 都够，但灰度/LDO 压热余量没算过，不值得赌）。

### 2.3 信号框架（引脚分配，锁死 5V 容忍）

| 功能 | 引脚 | 方向 | 5V 容忍 | 备注 |
|---|---|---|---|---|
| **灰度 8 路** | **PA0~PA7** | IN | ❌ **非 FT** | v1.7：子板**信号侧全 3.3V**（含比较器输出上拉），5V 只给发射管和 LM393 的 VCC → 上拉一旦错接 5V，内部 ESD 二极管会把该脚钳住并倒灌；一次读 `GPIOA->IDR & 0xFF`；**兼 ADC1_IN0~IN7**，但子板送来的是 LM393 **之后**的 0/1，直读没意义 → 要升级模拟差比和必须把比较器**之前**的节点引出来（排针改 2×10，第二列 AO）+ 加运放跟随 |
| 电机 左 IN1/IN2 | PA8 / PA9 | OUT | ✅ | TIM1_CH1/CH2，四路独立 PWM |
| 电机 右 IN3/IN4 | PA10 / PA11 | OUT | ✅ | TIM1_CH3/CH4 |
| 风机(预留) | PB1 / PB2 | OUT | — | **留焊盘不贴件**，见 §6 |
| 左编码器 A/B | **PA15 + PB3** | IN | ✅ | TIM2 **部分重映射** CH1/CH2 |
| 右编码器 A/B | **PB4 + PB5** | IN | ✅ | TIM3 **部分重映射** CH1/CH2 |
| 陀螺仪 SPI2 | PB13 SCK / PB14 MISO / PB15 MOSI / PB12 CS | — | ✅ | **不用 I2C**：会抢唯一遥测串口，且震动易掉线 |
| 遥测 USART1 | PB6 TX / PB7 RX | — | ✅ | 115200，上位机波形 + 串口调参 |
| 蜂鸣 | PB10 | OUT | ✅ | 上电自检发声（遮光没做好立刻知道） |
| 按键 ×2 | PB0 / PC13 | IN | PB0 非 FT | 按键接 GND + 内部上拉 → 安全 |
| 状态 LED | PC14 | OUT | — | |
| **SWD** | PA13 / PA14 | — | — | **必须留 4P 座**（A 车吃过没座的亏） |
| BOOT0 | 10k 下拉 + 跳线 | — | — | 想走串口下载时用 |

**三个必踩的软件坑，先写在这，画板时不用管但固件必须做：**

1. `PA15 / PB3 / PB4` 默认是 JTAG 脚 → 固件初始化第一件事**禁 JTAG 保留 SWD**
   （`AFIO->MAPR` 的 SWJ_CFG=100），否则两个编码器直接没读数。
2. **TIM1 是高级定时器，必须手动开 MOE**（`__HAL_TIM_MOE_ENABLE`）→ 忘了就是"程序在跑、电机不转"，
   这种问题能白耗半天。
3. 编码器 1024 P/R 装在**轮轴**上：v=1.2m/s、D=32mm → 12.2kHz、4× 后 48.9k count/s，
   16 位 **1.34s 才溢出** → 控制周期定 10ms 是为响应性与遥测刷新，**不再是为溢出**
   （v1.4 更正：v1.1 只改了 §1.3/§7.1，这条漏了。装电机轴才是 563kHz/29ms）。

### 2.4 灰度子板单路定稿（**v1.7：回到 5V + 3.3V 双轨，按实际画出的原理图定稿**）

**v1.7 撤销 v1.6 的单轨方案。** 实际画出的原理图是双轨（发射管与 LM393 的 VCC 从 5V 取、信号侧从 3.3V 取），
已复制成 8 路 + 4 片 LM393 + 11P 排针，**原理图定稿、已开画 PCB**。
v1.6 的"20k+20k 钳到 1.65V"技术上成立，但代价是每路多一只电阻 + 电位器改跨中点；
而双轨在 5V 下共模上限 3.5V、黑态节点 3.3V，**余量 0.2V 够用** → 不必再改。
前提只有一条：**模块必须是 5V，不能是 4.7V**（§2.2 硬约束 1）。

| 元件 | 值 | 接法 | 为什么是这个值 |
|---|---|---|---|
| R1 发射管限流 | **180Ω / 0805** ×8 | **+5V** → R1 → LED（2 脚）→ GND（1 脚） | (5−1.3)/180 ≈ **21mA** = 手册测试条件。★ **0603 不行**：自耗 **76mW**，已到 0603（1/10W）额定的 76%。⚠ 330Ω 时只 11mA → 可用行程只剩 56%（已改）|
| R2 接收管上拉 | **10k** ×8 | **+3V3** → R2 → 集电极（4 脚 = `n+`） | 发射极（3 脚）→ GND。黑态节点 = 3.3V，共模上限 3.5V，余量 0.2V ✅ |
| R3 阈值 | **10k 电位器（逐路 8 只）** + 下端 **10kΩ** → GND | 上端 **+3V3** → 电位器 → 10k → GND，抽头 = `n−` | 行程 **1.65~3.3V**。★v1.7 定稿：**保留逐路 8 只**（撤销我"共用一只"的建议）—— 弧上侧倾会让左右两侧离地差 2~3mm、节点跟着漂，逐路调能吸收掉。调好点螺纹胶 |
| R4 输出上拉 | **4.7k** ×8 | **+3V3** → R4 → OUT → MCU | ⚠ **严禁接 5V**：PA0~PA7 非 FT，绝对上限 VDD+0.3 = 3.6V |
| R5 指示灯 | **470Ω** ×8 | **+3V3** → R5 → LED → OUT | 10k 时只 0.2mA 看不见 → 会误判"没工作"继续瞎调 |
| C 每片去耦 | **100nF** ×4（已画 = U13~U16） | LM393 的 8 脚 → 4 脚 | ★ PCB 上必须**贴脚 <2mm**，放远了等于没放 |
| R6 迟滞 | **470k**（本版未画） | OUT ↔ `n+` 节点 | **每路在 PCB 上留一个空的 0603 焊盘不焊**：弧上侧倾→离地 5~8mm→阈值漂，实测抖再焊上，比改板便宜十倍 |
| 子板入口 | **5V 与 3V3 各 10µF + 100nF** | 排在 11P 旁边 | 4 只，别省 |

**不需要的**：节点 100pF —— 10k×100p 延迟 1µs，对 tr=tf=15µs 的这颗管毫无意义，省 8 个焊盘。
**严禁**：输出侧挂 100nF（会把边沿和过采样一起拖死，现成模块就栽在这）。

**8 路的组织**：LM393 双路 → **4 片**（U5/U6/U9/U12），每片 A 通道做奇数路、B 通道做偶数路，
**无悬空输入** ✅（未用输入悬空会自振荡，是这类板子最常见的"莫名乱翻"来源）。

**极性**：白线 → 反射强 → 光电流大 → 集电极被拉低 → `IN+ < IN−` → 输出管关断 → **OUT = 高**
⇒ **白 = 1、黑 = 0**（`IR_WHITE_IS = 1`）；指示灯在**黑底**时亮。30 秒验证：万用表量 OUT，白线上读 3.3V、黑布上读 0.1V。

**排针 11P（U17，已画）**：`OUT1 … OUT8 / GND / 3V3 / 5V` —— **5V 在最外端**，
错位一格是短路（PTC 跳），不是把 5V 灌进 3.3V 网络。
⚠ **主板那只排针的针序与缺角方向必须与 U17 完全一致**，开主板 layout 前先对一遍。

**上电与软件**：LM393 无 EN 脚，上电上升期间输出未定 → **固件前 100ms 丢弃灰度**；
自检：全黑应读 `0x00`、8 路跨白线应读 `0xFF`，不对就蜂鸣报警。

**ITR9909 手册已核实（v1.5，亿光/兼容型号规格书）**

| 参数 | 值 | 对本次设计的直接结论 |
|---|---|---|
| IC(ON) | ≥200µA @ VCE=5V、**IF=20mA、反光面距离 6mm** | ① **离地高度定 6mm±1**（不是"3~8mm 随便"）② IF 必须给到 20mA → **5V 轨下 R1=180Ω** |
| tr / tf | **15µs** @ VCE=5V、IC=1mA、RL=1kΩ | ★ **一拍内 1µs 间隔的突发过采样对这颗管完全无意义** → 子采样间隔要 **≥50µs**，否则放弃这条路。这也解释了 A 车"OS 恒为 0"的悬案 |
| VF | 1.2V typ / 1.5V max @20mA | R1 按 1.3V 算 → **5V 轨下 180Ω**（v1.7）|
| VCE(sat) | ≤0.4V @ IC=2mA | 白色时节点最低 ≈0.4V，不会到 0 |
| ICEO | ≤100nA | 在 10k 上只产生 1mV，忽略 |
| 极限值 | IF 50mA / IC 50mA / LED PD 75mW | 20mA 时 LED 耗 26mW ✅ |
| 封装 | DIP-4 **通孔**，8.7×4.5×5.9mm，视角 60° | 子板要留通孔；6mm 高度处光斑 ≈7mm → **间距 ≥10mm 才不串光** |

**对比度核算（v1.7：IF=21mA、10k 上拉到 3.3V、6mm）**：
白线：按手册**下限**算 IC = 200µA → 节点 = 3.3 − 200µA×10k = **1.3V**（最坏值）；实际 CTR 远高于下限 → 深度饱和到 **0.2~0.4V**。设计按 1.3V 取值。
黑布：按 10~20% 反射（估算值）→ IC 20~40µA → 节点 **3.1~3.3V**。
摆幅 **≥1.8V**，对数字比较器绰绰有余。可用阈值区 1.3~3.3V，而电位器行程 1.65~3.3V → **整段全部有效** ✅（5V 下共模上限 3.5V > 黑态 3.3V，余量 0.2V）。
→ 这就是 R1 从 330Ω 改 180Ω 换来的：330Ω 时 IF 只 11mA → IC≈110µA → 白态只降到 2.2V，
可用窗口 2.2~3.1V = 摆幅仅 0.9V、电位器只有 **56%** 行程有用。
→ **调阈值拧到 2.2~2.6V 那一带**（白/黑中点附近），别用行程端点 —— 端点最抗不了离地高度漂移。

⚠ **双轨付的账**：5V 上多了 165mA 发射管 → 降压模块要 **≥400mA**（不是一只电阻能解决的，是整只模块）。
好处是发射管与 MCU/IMU **不共轨**：电机拉跌 3.3V 时 LED 电流不受影响（单轨时会掉 17%）。

**脚序（30 秒验，别信我也别信博主）**：按 ITR 系列惯例 1=A、2=K、3=E、4=C，**与你图上一致**；但这是同系列惯例、不是这颗的 datasheet。
验法：4 脚串 **10k** 到 3.3V、3 脚接地，白纸凑近 6mm，量 4 脚应从 ≈3.3V 掉到 **<1.3V**（最好 <0.5V）；
几乎不变 → 3/4 接反（倒置模式增益极低，症状与"阈值坏了"完全一样）。

### 2.5 灰度排布坐标与循迹几何（**v1.7 定稿：轻度收腰**）

**中心一对的间距必须明显小于线宽** —— 这是本次定稿里唯一会"直接失能"的几何约束。
25mm 线、若中心两只管放在 ±13mm（间距 26mm）：车正压线中心时线覆盖 [-12.5, +12.5]，
**两只中心管都差 0.5mm 落在线外 → 8 位全 0 → 误判丢线**，而"正压线中心"恰恰是最常待的状态。
叠上 6mm 处约 7mm 的光斑，这个"瞎区"会糊成 ±3mm。→ **中心对取 10mm（±5）**，留 2.5 倍余量。

**定稿坐标（单位 mm，从左到右 = OUT1…OUT8）**：

```
pos  = { -40, -27.5, -15, -5, +5, +15, +27.5, +40 }
间距 =    12.5   12.5   10   10   10   12.5   12.5      总宽 80mm
```

| 项 | 值 | 依据 |
|---|---|---|
| 中心对 | ±5（10mm） | 必须 < 线宽 25mm，见上 |
| 全档 | ≥10mm | 6mm 处光斑 ≈7mm + 封装宽 4.5mm → 相邻净空 5.5mm 放隔墙，**不串光的下限** |
| 总宽 | 80mm → **板宽 ≈88mm** | ⚠ **比轮距 75~85 略宽**，见下方"量一个数" |
| 捕获范围 | ±52.5mm | = 半线宽的 4.2 倍；跑到这个量级已经是抢救区 |
| 封装朝向 | **8.7mm 那一边朝车头-车尾，4.5mm 朝横向**，8 只同向 | ① 横向只需让开 4.5mm，10mm 档才成立；反过来 8.7mm 朝横向只剩 1.3mm，隔墙塞不下 ② 线沿行进方向延伸，若 LED/PT 左右横放，线边缘落在两管之间时会在约 4mm 宽的区域里持续骑阈值抖动 |
| 板子形状 | **直排，不弯** | 弓高 = L²/8R = 612/R：R200→3.1mm、R100→6.1mm、R50→12.3mm（临界）。竞赛弧 R≥100 → 直排成立，弯板零收益 |
| 离地 | **6mm±1**（探头底面） | 管子贴板顶装 → **板顶面离地 6mm**；DIP 引脚会穿出板底约 3mm，**焊完剪平**，铜柱高度按这个反推 |

**代码侧两条硬要求**（非均匀间距的代价，v1.7 起生效）：

```c
/* 单位 0.1mm，与 PCB 坐标一一对应 —— 改板必须同步改这张表 */
static const int16_t IR_POS[8] = { -400, -275, -150, -50, 50, 150, 275, 400 };
/* 差比和：必须用真实位置加权 */
err = Σ(IR_POS[i] * bit[i]) / Σ(bit[i]);        /* Σbit == 0 → 丢线分支 */
```

1. `Σ(i-3.5)*bit_i / Σbit_i` 这个写法**只在等间距时成立**，收腰排布用它会得到系统性偏差。
2. **符号标定**：板面印 `FRONT →` 箭头 + `OUT1` 印在左端；固件留一个宏 `IR_SIGN_FLIP`。
   首次上电把线放到车体**右侧**，读到的 err 应为正；为负就翻这个宏。
   装反排线/镜像安装是这类车"越纠越偏"的头号来源，比调 PID 重要。

**精度预期（v1.7 算过，别当成 ±1mm）**：
中心区 |c| ≤ 15mm → 差比和偏差 **±2~3mm**（均匀 10mm 排布是 ±2mm，几乎不亏）；
外区 |c| > 20mm → 偏差 **±4~6mm**。但那是抢救区，本来就要满舵，量化误差被舵机限幅吃掉。
→ **收腰的精度损失集中在你不需要精度的地方，这是它划算的根本原因。**

⚠ **量一个数（现在唯一阻塞子板板框的）**：底板/车壳允许的**最大宽度**。
板宽 88mm 比轮距 75~85 略宽：≥ 92mm → 按上面坐标画；只有 80~90mm → **退回均匀 10mm**
（`pos = ±5/±15/±25/±35`，总宽 70 → 板宽 78mm），捕获范围缩到 ±47.5mm 但肯定装得下。
⚠ 收腰已经贴着"全档 ≥10mm"的下限，**再缩就只能缩外档，而缩了就不是收腰了** —— 二者选一个，不能折中。

## 3. 软件框架（决定 PCB 要留什么口）

```
周期与中断
  TIM1  20kHz      电机 PWM（四输入：方向靠电平、大小靠占空比）
  TIM2/TIM3        编码器硬件正交计数，不开中断
  SysTick 10ms     ★唯一控制周期：读灰度→里程→误差→特征判据→三环→限幅→写PWM
  USART1  TX DMA   遥测，绝不阻塞控制

分层
  drivers/      ir8.c  encoder.c  motor.c  imu.c  uart_dbg.c  buzzer.c  key.c
  middleware/   line_err.c(差比和/加权)  odom.c(里程)  ring.c(圆环5态)
                cross.c(十字)  finish.c(斑马线终点)
  control/      speed_pid.c  angle_pd.c  gyro_damp.c  slowsafe.c(弯道减速)
  app/          fsm.c  param.c(EEPROM/串口调参)  selftest.c

每 10ms 数据流
  ir8_read → line_err.compute → {ring|cross|finish} 判据 → 目标速度(按曲率查表)
    → speed_pid → angle_pd(+gyro_damp) → 限幅 → motor_set

上电自检（蜂鸣 + 串口打印，5 秒内完成）
  ① 8 路灰度逐路读：全黑/全白 → 立刻叫（遮光是黑底白线方案第一翻车点）
  ② 手转两轮验编码器方向（反了在 param.c 里改符号，不改接线）
  ③ IMU WHO_AM_I + 静止零偏 200 次平均
```

**判据纪律（校赛"简单版本"就靠这几条不变成屎山）**

- **每种赛道元素只允许一套判据**，多余的做成默认关闭的编译开关（A 车两套出口触发打出过竞态）。
- **禁止 `while(1){ motor_stop(); }` 死循环停车**，失线一律走状态机超时。
- 里程换算：编码器装**轮轴** → `mm/count = π·D / 4096`（D 用卡尺量，见 §1.3）
  → **减速比彻底不需要知道**，只需一个轮径常数，存 EEPROM 可调。
- 弯道减速：R200 物理上限 1.1~1.4m/s，按 |误差| 或角速度衰减目标速度，**收益大于调 PID**。

### 5.1 IMU 已核实：逐飞 IMU660RC（LSM6DSV16X）—— 风险解除，不用切任何东西

**已查官方资料**（逐飞 Gitee `IMU660RX_Product` README + 逐飞 TC264 开源库 `zf_device_imu660ra.c/h`，本地就有）：

| 核实项 | 结论 |
|---|---|
| 通信方式 | **只支持 I2C 和 SPI，模块根本没有 UART** → v1.1 里"出厂默认 UART、要切 SPI"的担心**是错的，已撤销** |
| 接口怎么选 | 由**接线**决定，不是配置决定：排针上 `SCL/SPC`、`SDA/SDI`、`SA0/SDO`、`CS`，接哪几根就是哪种 |
| 逐飞例程默认 | `IMU660RA_USE_SOFT_IIC = 0` → **官方默认就是硬件 SPI**，注释原话"默认使用硬件 SPI 方式连接" |
| SPI 速率 | 模块标称硬件 SPI 可达 10M；LSM6DSV16X 芯片 SPI 上限 10MHz |
| 供电 | 3.3~5V（模块自带 LDO）→ 我们给 **3.3V**，逻辑电平天然匹配 |
| 量程 | ±16g / ±125~4000dps（**±4000dps 仅 RC 支持**）、重 1.6g |
| 四元数 | RC 支持片内 SFLP 直出四元数，**逐飞例程自带四元数→欧拉角转换代码** |

所以对本项目：

```
✅ SPI2 走 PB12 CS / PB13 SCK / PB14 MISO / PB15 MOSI，遥测独占 USART1(PB6/PB7) → 零冲突
   F103 的 SPI2 挂在 APB1（36MHz），分频 /4 → **9MHz**，正好卡在芯片 10MHz 上限下，别用 /2
⚠ 一个真坑：`SDO` 与 `SA0` 是同一根脚（I2C 模式下选地址、SPI 模式下是 MISO）
   → SPI 接法时这根必须回 MCU，**严禁接地或接 3.3V**（只有 I2C 才需要固定电平）
★ 建议多留两根：INT1 → PB8、INT2 → PB9（都是 FT、目前空闲）
   用 INT1 做 DRDY 外部中断 → 采样时刻由芯片给，陀螺积分抖动远小于软件轮询
```

→ 关于四元数，精确说法：**融合算法在芯片里（SFLP），但四元数→yaw 角的转换公式还是得自己写**——
  好消息是逐飞例程已经给了，抄过来就行。循迹真正要的只有 **Z 轴角速度 + 航向角**，
  `imu.c` 只读这两项，别把六轴全量都拉进 10ms 周期里。

## 7. 电机结论（N30 强磁超高速，学长件）

| 参数 | 值 | 军师判断 |
|---|---|---|
| 额定 11.1V / 空载 33000rpm | — | **必须减速箱**，直驱不可能 |
| 堵转力矩 200gf·cm = 19.6mN·m | — | 经 1:30 后轮上 0.44N·m → 牵引 27.6N；而 350g 车打滑极限只有 2.1N → **扭矩过剩 13 倍** |
| 空载电流 230mA | — | 双电机怠速 0.46A，正常循迹 0.5~1.2A/个 |
| 堵转"<15A" | — | 超芯片峰值 → **必须设限流**（§2.3 约束 2） |

→ **结论：别再找"扭矩大的电机"了，N30 扭矩严重过剩。真正的瓶颈是 ①减速比选错导致转速不够 ②胎皮打滑 ③震动断电。**
花钱优先级：**胎皮 > 电池 > 别的都别买**（抓地是唯一买得到的物理上限）。
