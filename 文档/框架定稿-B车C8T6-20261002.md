## 0. 一句话框架

**主板（控制+驱动一体）＋ 灰度子板（可单独换）＋ 现成陀螺仪模块立装**；
电机 12V 直给、逻辑走 **12V→4.7V→3.3V**（v1.6 起：**子板只用 3.3V，取消双轨**，见 §2.2/§2.4）；
软件 10ms 一个控制周期，**每种赛道元素只允许一套判据**。

## 1. 结构路线（v1.1 定稿：底板自己设计，不用开源车架）

你说得对：框架（电气 + 软件）定死后，底板只是一块带孔的板。原 v1 那条
"先定车架再画板"的警告**自动解除**，改成一次做完这三步：

```
① 底板：先画（安装孔位、电机座、铜柱位置、灰度板前伸量、负压圆孔）
② 主板板框 + 接插件位置：对着底板的孔位画，接插件全部走板边
③ 灰度子板：最后画（离地 3~8mm、遮光、阈值要实测改版）
```

### 1.1 底板设计约束（一次给全，照着摆）

| 项 | 定稿值 | 依据 |
|---|---|---|
| 轮距 | **75~85mm**（以两个轮框架中心距为准） | 差速转向几何 |
| 灰度板前缘→驱动轴 | **≤45mm** | R200 刚体偏移 d²/(2R)：45mm→5.1mm，25mm 线宽容错 ±12.5mm ✅ |
| 驱动轴→车尾 | **≤50mm** | 同上：50mm→6.3mm ✅；70mm→12.3mm ❌ |
| 整车总长 | **≤130mm** | 上两条 + 电机长度 |
| 电池位置 | **尽量靠后、贴低** | 平衡灰度板前伸力矩，也是"不加球脚"的第一优先手段 |
| 底板开圆孔 | **✓ 现在就开 + 留 4 个螺丝孔 + 密封圈压边平** | 负压退路（§6），风机/扇叶/支架你都有 |
| 主板与底板 | 主板用铜柱**架在底板上方** | 爬壁开源作者原话：框式架构、PCB 架在上面刚性足；同时当负压腔上盖/支撑 |
| 底板加强 | 四周立边 ≥5mm 或 1.5mm 加强筋 | 防"开负压后底板变形、轮子外八"（作者踩过） |
| 陀螺仪位 | 四角减震柱，**离风机 ≥40mm**，板面印方向箭头 | 扇叶共振→螺丝松→陀螺漂；方向错则角度符号反 |
| 球脚 | **先不加**，按 §1.2 判据实测后再定 | 打印免费，加个可调支撑座 20 分钟 |

### 1.2 前球脚判据（30 秒测完，别提前设计）

```
车放平，松手 → 看车头是否下沉、灰度板前缘压到线
  压到 → 先只做两件事：① 电池后移 ② 灰度板前伸减到 35mm
         仍压头 → 才加支撑，且用【小滚轮】不用万向球（滚轮摩擦小、不啃喷绘布）
         第三触点必须落在驱动轴中线上，偏了会把车"顶"着跑偏
```

## 1.3 编码器装轮轴 → 标定大幅简化（v1.1 确认）

装在**轮轴**意味着：**减速比彻底不需要知道，连推车标定都能省**。

```
1 轮转 = 1024 脉冲 = 4096 计数（4 倍频）
每计数位移 = π·D / 4096
  D=32mm → 0.0245 mm/count      D=40mm → 0.0306 mm/count

频率与溢出（D=32mm 为例）
  v=1.2m/s → 轮 716rpm → 12.2kHz → 4× 后 48.9k count/s
  16 位溢出周期 = 65536/48.9k ≈ 1.34s   ← 极宽松，不会绕圈
  10ms 窗口 = 489 count → 分辨率 0.2%    ← 够用
  起步 0.1m/s → 41 count/10ms → ±2.4%    ← 可接受（嫌糙再上 M/T 法）
```

→ **控制周期仍定死 10ms**，但理由变了：不再是被编码器溢出逼的，而是被响应性与遥测刷新率定的。
→ 唯一必做的标定：**量轮径 D**（软尺绕轮胎一圈 ÷ π 比卡尺准；胎皮会磨，一场比赛后复量）。
→ "推车 1m 数脉冲"降级为**校验**：算出的 mm/pulse 与实测差 >2% → 轮径量错或编码器丢脉冲。
→ ⚠ 轮轴编码器的固有代价：**轮子打滑时里程虚高** → 圆环/终点判据不能只靠里程，必须叠陀螺角度积分兜底。

## 2. 硬件框架（画板的直接输入）

### 2.1 分板策略（为什么不做成一块板）

| 板 | 内容 | 为什么分开 |
|---|---|---|
| **主板** | C8T6 + 2×AT8236（+1 预留）+ LDO + 全部接插件 | 撞坏概率低，但改一版代价高 |
| **灰度子板** | 8×ITR9909 + **4×LM393**（双路，一片只管 2 路）+ **10P 排针（只 3V3/GND，无 5V）** | **离地高度/遮光/阈值要反复调**，分板 = 迭代最便宜；撞了只换子板 |
| 陀螺仪 | 现成模块，排针立装 | 可拆 + 加减震柱 |

### 2.2 电源树

```
3S 锂电 11.1~12.6V
 └ XT30 ─ 船型开关(≥10A) ─ 保险/PTC 10A
    ├─【功率轨 VM = 12.6V 直给】→ AT8236 ×2(+1) → 电机 / 风机
    │     就近：470µF/25V ×1 + 0.1µF ×3；OUT→端子间 100nF + 磁珠
    └─【逻辑轨】→ 12V→**4.7V** 降压模块（v1.6：学长那只**直接用**，不改反馈电阻、不补买）
          │
          └ AMS1117-3.3（≥600mA）→ **3.3V —— 子板上唯一存在的电压**
                ├ C8T6 + 晶振 + SWD
                ├ 灰度子板**全部**（发射管 + LM393 的 VCC + 信号侧）→ 排针只有 3V3/GND/8×DO，**不送 5V**
                ├ 陀螺仪模块 IMU660RC（已核实 3.3~5V 自适应、自带 LDO → 给 **3.3V**）
                └ 蜂鸣 / LED / 上拉
   地：功率地与逻辑地单点相连（0Ω 或磁珠）；灰度子板地走独立回线，不穿过功率区
```

**三条硬约束（违反必翻车）**

1. **3.3V 预算（v1.6 按单轨重算）**：MCU/IMU 60 + **发射管 8×23mA = 184** + 分压与杂 30 ≈ **270mA**
   → **AMS1117-3.3（≥500mA）**（`RT9013 只 250mA`，依旧不推荐）。LDO 耗 `(4.7−3.3)×0.27 = 0.38W` ✅。
   - ⚠ **“不用 5V” ≠ “少一级”**：严禁让 LDO 直吃 12.6V —— `(12.6−3.3)×0.27 = 2.5W` → SOT-223 直接热保护。
     降压那一级还是要有的，只是它出的电压**不上子板**。
   - 降压模块只需能**连续 ≥300mA**（≈1.3W）—— 比 v1.5 的 ≥500mA 好满足得多，学长那只大概率就够。
   - LM393 共模上限 1.8V 的问题靠 **20k+20k 把节点钳到 1.65V** 解决（§2.4），**不需要换轨到轨比较器、不需要每路分压**。
2. **N30 堵转标称"<15A"，超 AT8236 峰值 6A** → 每颗 AT8236 **必须按手册算采样电阻把限流设到 3A**。
   这一条同时是你那类"卡死烧板/震动断电"的保险丝。
3. **严禁 4S**（逻辑轨模块与 AT8236 都够，但灰度/LDO 压热余量没算过，不值得赌）。

### 2.3 信号框架（引脚分配，锁死 5V 容忍）

| 功能 | 引脚 | 方向 | 5V 容忍 | 备注 |
|---|---|---|---|---|
| **灰度 8 路** | **PA0~PA7** | IN | ❌ **非 FT** | v1.6：子板**全部 3.3V**，不送 5V → 从源头消除超压；一次读 `GPIOA->IDR & 0xFF`；**兼 ADC1_IN0~IN7**，将来升级"模拟差比和"要把比较器**之前**的节点也引出来（排针改 2×10） |
| 电机 左 IN1/IN2 | PA8 / PA9 | OUT | ✅ | TIM1_CH1/CH2，四路独立 PWM |
| 电机 右 IN3/IN4 | PA10 / PA11 | OUT | ✅ | TIM1_CH3/CH4 |
| 风机(预留) | PB1 / PB2 | OUT | — | **留焊盘不贴件**，见 §6 |
| 左编码器 A/B | **PA15 + PB3** | IN | ✅ | TIM2 **部分重映射** CH1/CH2 |
| 右编码器 A/B | **PB4 + PB5** | IN | ✅ | TIM3 **部分重映射** CH1/CH2 |
| 陀螺仪 SPI2 | PB13 SCK / PB14 MISO / PB15 MOSI / PB12 CS | — | ✅ | **不用 I2C**：会抢唯一遥测串口，且震动易掉线 |
| 遥测 USART1 | PB6 TX / PB7 RX | — | ✅ | 115200，上位机波形 + 串口调参 |
| 蜂鸣 | PB10 | OUT | ✅ | 上电自检发声（遮光没做好立刻知道） |
| 按键 ×2 | PB0 / PC13 | IN | PB0 非 FT | 按键接 GND + 内部上拉 → 安全 |
| 状态 LED | PC14 | OUT | — | |
| **SWD** | PA13 / PA14 | — | — | **必须留 4P 座**（A 车吃过没座的亏） |
| BOOT0 | 10k 下拉 + 跳线 | — | — | 想走串口下载时用 |

**三个必踩的软件坑，先写在这，画板时不用管但固件必须做：**

1. `PA15 / PB3 / PB4` 默认是 JTAG 脚 → 固件初始化第一件事**禁 JTAG 保留 SWD**
   （`AFIO->MAPR` 的 SWJ_CFG=100），否则两个编码器直接没读数。
2. **TIM1 是高级定时器，必须手动开 MOE**（`__HAL_TIM_MOE_ENABLE`）→ 忘了就是"程序在跑、电机不转"，
   这种问题能白耗半天。
3. 编码器 1024 P/R 装在**轮轴**上：v=1.2m/s、D=32mm → 12.2kHz、4× 后 48.9k count/s，
   16 位 **1.34s 才溢出** → 控制周期定 10ms 是为响应性与遥测刷新，**不再是为溢出**
   （v1.4 更正：v1.1 只改了 §1.3/§7.1，这条漏了。装电机轴才是 563kHz/29ms）。

### 2.4 灰度子板单路定稿（**v1.6：单 3.3V，子板上不出现 5V**）

**v1.6 推翻 v1.4 的双轨结论**（用户拍板：不画双轨）。单轨的真正好处不是省一只模块，
而是**子板上只有一组 3V3/GND** → 排针 11P→**10P**，物理上不可能把高压灌进 PA0~PA7。
代价只有**每路多一只电阻**：把接收管节点钳到 1.65V，绕开 LM393 的 `VCC−1.5 = 1.8V` 共模上限。

| 元件 | 值 | 接法 | 为什么是这个值 |
|---|---|---|---|
| R1 发射管限流 | **82Ω / 0805** | **+3V3** → R1 → LED → GND | (3.3−1.4)/82 ≈ **23mA**。故意比手册的 20mA 多给一点：单轨下跌 0.3V 电流就掉到 19mA，仍能保证接收管饱和。⚠ 别用 0603（自耗 44mW，已占额定 63mW 的 70%）|
| R2a/R2b 接收管负载 | **20k + 20k**（★v1.6 新增一只） | +3V3 → 20k → 集电极（`1+`）→ 20k → **GND** | **单轨能成立的唯一关键**：节点被钳在 **1.65V**（= 3.3÷2），黑/白全落在 1.8V 共模窗内。等效于 1.65V 电源经 10k 上拉 |
| R3 阈值 | **10k 电位器，跨在 1.65V 中点上** | 2×20k 从 3V3 分出 1.65V（**全板共用一对**）→ 电位器 → GND，抽头 = `1−` | 行程 **0~1.65V**，正好盖住信号摆幅 0.2~1.4V。⚠ **别再把电位器接在 3.3V 上**：上半行程（>1.8V）全在共模区外，就是那个“拧了没反应” |
| R4 输出上拉 | **4.7k** | **+3V3** → R4 → OUT → MCU | 不变。现在全板 3.3V，本来就不可能烧脚；4.7k 仍为压上升沿 |
| R5 指示灯 | **470Ω** | **+3V3** → R5 → LED → OUT | 不变（10k 时只 0.2mA 看不见 → 会误判“没工作”继续瞎调）|
| R6 迟滞 | **470k ~ 1M** | OUT ↔ `1+` 节点 | 节点源阻 10k → 回差 ≈ 3.3×10k/R6 = **70mV(470k) / 33mV(1M)**，占摆幅 6%/3% → 上板实测再定 |
| C1 每片去耦 | 100nF | LM393 VCC-GND，4 片 4 个 | |
| C2 信号节点 | **100pF** | `1+` 节点 → GND（走线短） | ⚠ 输出侧**严禁挂 100nF** |
| 子板入口 | 10µF + 100nF | **只有一组 3.3V** | 发射管 184mA 共轨 → 入口电容比双轨时重要，别省 |

**8 路的组织**：LM393 是**双路** → 4 片/车（备 4）。每片的 B 通道也要接完整，**不留悬空输入**。
阈值建议 **8 路共用一个电位器**（省 7 只、少 7 次调试、通道间不会互漂），代价是要求 R2 同值 + 打印件定高一致；
若担心单路装偏，就保留逐路电位器，但**调好点螺纹胶**。

**极性（v1.4 更正，之前口头说反了）**：白线 → 反射强 → 光电流大 → 集电极被拉低 → `IN+ < IN−` → 输出管关断 → **OUT = 高**
⇒ **白 = 1、黑 = 0**，`IR_WHITE_IS = 1`；指示灯在**黑线**时亮。30 秒验证：万用表量 OUT，白线上读 3.3V、黑布上读 0.1V。

**排针顺序（v1.6 改 10P）**：`DO1 … DO8 / 3V3 / GND` —— **子板上没有 5V 这个网络**。
好处：少一根针，且不可能出现“把 5V 灌进 3.3V 网络”这种错；错位最坏是信号↔3V3 或 ↔GND。

**上电与软件**：LM393 没有 EN 脚，LDO 上升期间输出未定 → **固件上电后前 100ms 丢弃灰度**；
自检阶段读全黑应得 `0x00`、跨 8 路压白线应得 `0xFF`，不对就蜂鸣报警。

**ITR9909 手册已核实（v1.5，亿光/兼容型号规格书）**

| 参数 | 值 | 对本次设计的直接结论 |
|---|---|---|
| IC(ON) | ≥200µA @ VCE=5V、**IF=20mA、反光面距离 6mm** | ① **离地高度定 6mm±1**（不是"3~8mm 随便"）② IF 必须给到 20mA → 3.3V 轨下 R1=82Ω |
| tr / tf | **15µs** @ VCE=5V、IC=1mA、RL=1kΩ | ★ **一拍内 1µs 间隔的突发过采样对这颗管完全无意义** → 子采样间隔要 **≥50µs**，否则放弃这条路。这也解释了 A 车"OS 恒为 0"的悬案 |
| VF | 1.2V typ / 1.5V max @20mA | R1 按 1.4V 算 → 3.3V 轨下 82Ω（v1.6）|
| VCE(sat) | ≤0.4V @ IC=2mA | 白色时节点最低 ≈0.4V，不会到 0 |
| ICEO | ≤100nA | 在 10k 上只产生 1mV，忽略 |
| 极限值 | IF 50mA / IC 50mA / LED PD 75mW | 20mA 时 LED 耗 26mW ✅ |
| 封装 | DIP-4 **通孔**，8.7×4.5×5.9mm，视角 60° | 子板要留通孔；6mm 高度处光斑 ≈7mm → **间距 ≥10mm 才不串光** |

**对比度核算（v1.6：20k/20k 钳位、IF=23mA、6mm）**：
白线 IC≥200µA × 等效 10k = 2.0V > 1.45V → **深度饱和 → 节点 ≈ 0.2V**；
黑布按 10~20% 反射（估算值）→ IC 20~40µA → 节点 = 1.65 − 0.2~0.4 = **1.25~1.45V**。
摆幅 **1.1~1.25V**（比双轨的 1.7V 小，但对数字比较器绰绰有余），且**全段在 0~1.8V 共模窗内** ✅。
→ 上板只量两个数就能定：① **白线时节点拉不到 0.4V 以下** → R1 降到 68Ω；再不行就是光学问题（离地高度/遮光/黑布反光），不是电阻问题。
② **黑线时节点顶到 1.7V 以上**（共模边）→ R2b 由 20k 改 15k，把 V_th 降到 1.34V。

⚠ **单轨真正付的账**：发射管 184mA 与 MCU/IMU 共一轨。轨跌 0.3V 时 LED 电流掉≈17%（双轨时只 8%），
所以① 子板入口必装 10µF；② 3.3V 走线要粗/短；③ 电机扰动大时先量 3.3V 再调阈值。

⚠ **一个没解决的冲突（要你定）**：8 路 @ **20mm** 间距 = 首尾中心距 **140mm**，而底板轮距 75~85mm、总长 ≤130mm → **装不下**。
建议 **间距 12.5~13mm → 总宽 87.5~91mm**（现成 8 路模块也是这个量级），25mm 白线上仍有 2~3 路压线，差比和分辨率反而更好。
→ 需要一个数：**车头允许的最大宽度是多少？**

**脚序（30 秒验，别信我也别信博主）**：按 ITR 系列惯例 1=A、2=K、3=E、4=C，**与你图上一致**；但这是同系列惯例、不是这颗的 datasheet。
验法：4 脚串 **20k** 到 3.3V、3 脚接地，白纸凑近 6mm，量 4 脚应从 ≈3.3V 掉到 <0.5V（200µA×20k=4V → 必饱和）；几乎不变 → 3/4 接反。

### 2.5 PCB 分区（布局规则）

```
① 接插件全部走板边（车架装配要伸手，换线不用拆板）
   XT30入口 / 电机×2 / 风机 / 灰度子板**10P**(`8DO+3V3+GND`，v1.6 已删 5V 那一针，见 §2.4) / IMU **8P** / SWD 4P / UART 4P / 按键 / 蜂鸣
② 功率区（板的一端）：AT8236 + 大电容；走线 ≥1.2mm@1oz 每安培，铺铜+开窗加锡
```

## 3. 软件框架（决定 PCB 要留什么口）

```
周期与中断
  TIM1  20kHz      电机 PWM（四输入：方向靠电平、大小靠占空比）
  TIM2/TIM3        编码器硬件正交计数，不开中断
  SysTick 10ms     ★唯一控制周期：读灰度→里程→误差→特征判据→三环→限幅→写PWM
  USART1  TX DMA   遥测，绝不阻塞控制

分层
  drivers/      ir8.c  encoder.c  motor.c  imu.c  uart_dbg.c  buzzer.c  key.c
  middleware/   line_err.c(差比和/加权)  odom.c(里程)  ring.c(圆环5态)
                cross.c(十字)  finish.c(斑马线终点)
  control/      speed_pid.c  angle_pd.c  gyro_damp.c  slowsafe.c(弯道减速)
  app/          fsm.c  param.c(EEPROM/串口调参)  selftest.c

每 10ms 数据流
  ir8_read → line_err.compute → {ring|cross|finish} 判据 → 目标速度(按曲率查表)
    → speed_pid → angle_pd(+gyro_damp) → 限幅 → motor_set

上电自检（蜂鸣 + 串口打印，5 秒内完成）
  ① 8 路灰度逐路读：全黑/全白 → 立刻叫（遮光是黑底白线方案第一翻车点）
  ② 手转两轮验编码器方向（反了在 param.c 里改符号，不改接线）
  ③ IMU WHO_AM_I + 静止零偏 200 次平均
```

**判据纪律（校赛"简单版本"就靠这几条不变成屎山）**

- **每种赛道元素只允许一套判据**，多余的做成默认关闭的编译开关（A 车两套出口触发打出过竞态）。
- **禁止 `while(1){ motor_stop(); }` 死循环停车**，失线一律走状态机超时。
- 里程换算：编码器装**轮轴** → `mm/count = π·D / 4096`（D 用卡尺量，见 §1.3）
  → **减速比彻底不需要知道**，只需一个轮径常数，存 EEPROM 可调。
- 弯道减速：R200 物理上限 1.1~1.4m/s，按 |误差| 或角速度衰减目标速度，**收益大于调 PID**。

### 5.1 IMU 已核实：逐飞 IMU660RC（LSM6DSV16X）—— 风险解除，不用切任何东西

**已查官方资料**（逐飞 Gitee `IMU660RX_Product` README + 逐飞 TC264 开源库 `zf_device_imu660ra.c/h`，本地就有）：

| 核实项 | 结论 |
|---|---|
| 通信方式 | **只支持 I2C 和 SPI，模块根本没有 UART** → v1.1 里"出厂默认 UART、要切 SPI"的担心**是错的，已撤销** |
| 接口怎么选 | 由**接线**决定，不是配置决定：排针上 `SCL/SPC`、`SDA/SDI`、`SA0/SDO`、`CS`，接哪几根就是哪种 |
| 逐飞例程默认 | `IMU660RA_USE_SOFT_IIC = 0` → **官方默认就是硬件 SPI**，注释原话"默认使用硬件 SPI 方式连接" |
| SPI 速率 | 模块标称硬件 SPI 可达 10M；LSM6DSV16X 芯片 SPI 上限 10MHz |
| 供电 | 3.3~5V（模块自带 LDO）→ 我们给 **3.3V**，逻辑电平天然匹配 |
| 量程 | ±16g / ±125~4000dps（**±4000dps 仅 RC 支持**）、重 1.6g |
| 四元数 | RC 支持片内 SFLP 直出四元数，**逐飞例程自带四元数→欧拉角转换代码** |

所以对本项目：

```
✅ SPI2 走 PB12 CS / PB13 SCK / PB14 MISO / PB15 MOSI，遥测独占 USART1(PB6/PB7) → 零冲突
   F103 的 SPI2 挂在 APB1（36MHz），分频 /4 → **9MHz**，正好卡在芯片 10MHz 上限下，别用 /2
⚠ 一个真坑：`SDO` 与 `SA0` 是同一根脚（I2C 模式下选地址、SPI 模式下是 MISO）
   → SPI 接法时这根必须回 MCU，**严禁接地或接 3.3V**（只有 I2C 才需要固定电平）
★ 建议多留两根：INT1 → PB8、INT2 → PB9（都是 FT、目前空闲）
   用 INT1 做 DRDY 外部中断 → 采样时刻由芯片给，陀螺积分抖动远小于软件轮询
```

→ 关于四元数，精确说法：**融合算法在芯片里（SFLP），但四元数→yaw 角的转换公式还是得自己写**——
  好消息是逐飞例程已经给了，抄过来就行。循迹真正要的只有 **Z 轴角速度 + 航向角**，
  `imu.c` 只读这两项，别把六轴全量都拉进 10ms 周期里。

## 6. 负压：留退路，不装（因为现在它几乎免费）

情况变了：**风机是学长的（0 元）+ 扇叶/支架打印 0 元** → 负压的边际成本只剩
1 颗 4 元芯片 + 0.6A 电流 + 半天调试。

- **底板（你已确认）**：**现在就开圆孔 + 留好 4 个螺丝孔**，扇叶和支架已有 → 结构侧零成本。
  压边处留平（密封圈+纳米胶），别开完孔又拿砂纸打磨变形。
- **板上**：第 3 颗 AT8236 **留焊盘不贴件**，PB1/PB2 引到排针。
- **装车时机**：第一次实测圈速出来再定。
  若弯道打滑是瓶颈 → 上负压（开源作者实测 7W → 1.2kgf 吸力，对 350g 的车相当于正压力 ×4.4，
  理论弯速 ×2）；若直道就够快 → 别碰，它是全车最大震动源，作者自己都提醒"螺丝共振→陀螺仪漂"。
- **校赛前夜绝对不装负压**（改重心 + 改震动谱 = 现场翻车经典配方）。

## 7. 电机结论（N30 强磁超高速，学长件）

| 参数 | 值 | 军师判断 |
|---|---|---|
| 额定 11.1V / 空载 33000rpm | — | **必须减速箱**，直驱不可能 |
| 堵转力矩 200gf·cm = 19.6mN·m | — | 经 1:30 后轮上 0.44N·m → 牵引 27.6N；而 350g 车打滑极限只有 2.1N → **扭矩过剩 13 倍** |
| 空载电流 230mA | — | 双电机怠速 0.46A，正常循迹 0.5~1.2A/个 |
| 堵转"<15A" | — | 超芯片峰值 → **必须设限流**（§2.3 约束 2） |

→ **结论：别再找"扭矩大的电机"了，N30 扭矩严重过剩。真正的瓶颈是 ①减速比选错导致转速不够 ②胎皮打滑 ③震动断电。**
花钱优先级：**胎皮 > 电池 > 别的都别买**（抓地是唯一买得到的物理上限）。

### 7.1 编码器装轮轴后的频率更正（推翻 v1 里那条 563kHz 警告）

v1 曾算过：装电机轴时 33000rpm → 563kHz、**16 位定时器 29ms 溢出**。
现确认装在**轮轴** → 最高约 12~25kHz（规格里取 v=1.5m/s、D=32mm 保守估）→
**溢出周期 1.3s 以上，彻底不是问题**。仍保留 10ms 控制周期，但理由换成响应性而非溢出。
→ 详见 §1.3。硬件不变（仍是 PA15/PB3 + PB4/PB5 硬件正交计数）。
