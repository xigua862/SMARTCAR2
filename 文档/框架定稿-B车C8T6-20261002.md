## 0. 一句话框架

**主板（控制+驱动一体）＋ 灰度子板（可单独换）＋ 现成陀螺仪模块立装**；
电机 12V 直给、逻辑走你那个 12V→4.7V→3.3V；
软件 10ms 一个控制周期，**每种赛道元素只允许一套判据**。

---

## 1. ⚠️ 先纠正一件事：顺序反了会多改一次板

你说"先画 PCB、最后设计车架"。但车架既然打算拿牛爷爷开源件，那么
**安装孔位、板框尺寸、接插件朝向、灰度板离地高度全由车架决定**。

正确顺序（省 3~5 天）：

```
① 定车架（选开源件 → 抄下它的安装孔距、板槽长宽、电机中心高）
② 定主板板框 + 接插件位置（对着车架来，别反过来）
③ 画主板
④ 灰度子板最后画（要实测离地 3~8mm 和遮光，会改好几版）
```

**你现在唯一的前置动作**：把牛爷爷那套开源车架的安装孔距/板槽尺寸量出来（或截图给我），
其余我全部能定。

## 2. 硬件框架（画板的直接输入）

### 2.1 分板策略（为什么不做成一块板）

| 板 | 内容 | 为什么分开 |
|---|---|---|
| **主板** | C8T6 + 2×AT8236（+1 预留）+ LDO + 全部接插件 | 撞坏概率低，但改一版代价高 |
| **灰度子板** | 8×TCRT5000 + 2×LM393 + 10P 排针 | **离地高度/遮光/阈值要反复调**，分板 = 迭代最便宜；撞了只换子板 |
| 陀螺仪 | 现成模块，排针立装 | 可拆 + 加减震柱 |

### 2.2 电源树

```
3S 锂电 11.1~12.6V
 └ XT30 ─ 船型开关(≥10A) ─ 保险/PTC 10A
    ├─【功率轨 VM = 12.6V 直给】→ AT8236 ×2(+1) → 电机 / 风机
    │     就近：470µF/25V ×1 + 0.1µF ×3；OUT→端子间 100nF + 磁珠
    └─【逻辑轨】→ 你现成的 12V→4.7V 降压模块 → AMS1117-3.3（或 ME6211 ≥600mA）→ 3.3V
          ├ C8T6 + 晶振 + SWD
          ├ 灰度子板 8 路　　≈150~200mA　★严禁 5V，见 §2.3
          ├ 陀螺仪模块（模块自带 LDO 就给 5V，否则 3.3V）
          └ 蜂鸣 / LED / 上拉
   地：功率地与逻辑地单点相连（0Ω 或磁珠）；灰度子板地走独立回线，不穿过功率区
```

**三条硬约束（违反必翻车）**

1. **3.3V 轨预算 = 红外 200 + MCU/IMU 60 + 杂 30 ≈ 290mA → LDO 必须 ≥500mA**。
   `RT9013 只有 250mA`，红外一亮全亮就压垮 → 复位/跑飞。用 **AMS1117-3.3 或 ME6211C33**。
2. **N30 堵转标称"<15A"，超 AT8236 峰值 6A** → 每颗 AT8236 **必须按手册算采样电阻把限流设到 3A**。
   这一条同时是你那类"卡死烧板/震动断电"的保险丝。
3. **严禁 4S**（逻辑轨模块与 AT8236 都够，但灰度/LDO 压热余量没算过，不值得赌）。

### 2.3 信号框架（引脚分配，锁死 5V 容忍）

| 功能 | 引脚 | 方向 | 5V 容忍 | 备注 |
|---|---|---|---|---|
| **灰度 8 路** | **PA0~PA7** | IN | ❌ **非 FT** | 子板必须 3.3V 供电；一次读 `GPIOA->IDR & 0xFF`；**这 8 个脚同时是 ADC1_IN0~IN7**，将来升级"模拟差比和"不用改板 |
| 电机 左 IN1/IN2 | PA8 / PA9 | OUT | ✅ | TIM1_CH1/CH2，四路独立 PWM |
| 电机 右 IN3/IN4 | PA10 / PA11 | OUT | ✅ | TIM1_CH3/CH4 |
| 风机(预留) | PB1 / PB2 | OUT | — | **留焊盘不贴件**，见 §6 |
| 左编码器 A/B | **PA15 + PB3** | IN | ✅ | TIM2 **部分重映射** CH1/CH2 |
| 右编码器 A/B | **PB4 + PB5** | IN | ✅ | TIM3 **部分重映射** CH1/CH2 |
| 陀螺仪 SPI2 | PB13 SCK / PB14 MISO / PB15 MOSI / PB12 CS | — | ✅ | **不用 I2C**：会抢唯一遥测串口，且震动易掉线 |
| 遥测 USART1 | PB6 TX / PB7 RX | — | ✅ | 115200，上位机波形 + 串口调参 |
| 蜂鸣 | PB10 | OUT | ✅ | 上电自检发声（遮光没做好立刻知道） |
| 按键 ×2 | PB0 / PC13 | IN | PB0 非 FT | 按键接 GND + 内部上拉 → 安全 |
| 状态 LED | PC14 | OUT | — | |
| **SWD** | PA13 / PA14 | — | — | **必须留 4P 座**（A 车吃过没座的亏） |
| BOOT0 | 10k 下拉 + 跳线 | — | — | 想走串口下载时用 |

**三个必踩的软件坑，先写在这，画板时不用管但固件必须做：**

1. `PA15 / PB3 / PB4` 默认是 JTAG 脚 → 固件初始化第一件事**禁 JTAG 保留 SWD**
   （`AFIO->MAPR` 的 SWJ_CFG=100），否则两个编码器直接没读数。
2. **TIM1 是高级定时器，必须手动开 MOE**（`__HAL_TIM_MOE_ENABLE`）→ 忘了就是"程序在跑、电机不转"，
   这种问题能白耗半天。
3. 编码器 1024 P/R 装在电机轴上：33000rpm → **563kHz、4 倍频 2.25Mcps**，
   16 位定时器 **29ms 就溢出** → **速度环周期定死 10ms**，不许放宽。

### 2.4 PCB 分区（布局规则）

```
① 接插件全部走板边（车架装配要伸手，换线不用拆板）
   XT30入口 / 电机×2 / 风机 / 灰度子板10P / IMU 4P / SWD 4P / UART 4P / 按键 / 蜂鸣
② 功率区（板的一端）：AT8236 + 大电容；走线 ≥1.2mm@1oz 每安培，铺铜+开窗加锡
③ 逻辑区（另一端，离电机最远）：MCU、晶振（贴 MCU、下方包地、禁走信号线）、LDO
④ IMU 区：离风机 ≥40mm、四角减震柱、排针立装可拆
⑤ 星形接地点：功率地/逻辑地/子板地 在输出电容负极处汇一点
⑥ 安装孔：★跟着车架（§1）
⑦ 板边留 4 个 2.54mm 测试盘：3.3V / VM / GND / 一个空闲 ADC（排查断电问题救命用）
```

## 3. 软件框架（决定 PCB 要留什么口）

```
周期与中断
  TIM1  20kHz      电机 PWM（四输入：方向靠电平、大小靠占空比）
  TIM2/TIM3        编码器硬件正交计数，不开中断
  SysTick 10ms     ★唯一控制周期：读灰度→里程→误差→特征判据→三环→限幅→写PWM
  USART1  TX DMA   遥测，绝不阻塞控制

分层
  drivers/      ir8.c  encoder.c  motor.c  imu.c  uart_dbg.c  buzzer.c  key.c
  middleware/   line_err.c(差比和/加权)  odom.c(里程)  ring.c(圆环5态)
                cross.c(十字)  finish.c(斑马线终点)
  control/      speed_pid.c  angle_pd.c  gyro_damp.c  slowsafe.c(弯道减速)
  app/          fsm.c  param.c(EEPROM/串口调参)  selftest.c

每 10ms 数据流
  ir8_read → line_err.compute → {ring|cross|finish} 判据 → 目标速度(按曲率查表)
    → speed_pid → angle_pd(+gyro_damp) → 限幅 → motor_set

上电自检（蜂鸣 + 串口打印，5 秒内完成）
  ① 8 路灰度逐路读：全黑/全白 → 立刻叫（遮光是黑底白线方案第一翻车点）
  ② 手转两轮验编码器方向（反了在 param.c 里改符号，不改接线）
  ③ IMU WHO_AM_I + 静止零偏 200 次平均
```

**判据纪律（校赛"简单版本"就靠这几条不变成屎山）**

- **每种赛道元素只允许一套判据**，多余的做成默认关闭的编译开关（A 车两套出口触发打出过竞态）。
- **禁止 `while(1){ motor_stop(); }` 死循环停车**，失线一律走状态机超时。
- 里程换算用**标定出来的 mm/pulse**（推车 1 米数脉冲，存 EEPROM）→
  **减速比不知道也完全不影响画板和写代码**，这是 §5 的第一项标定。
- 弯道减速：R200 物理上限 1.1~1.4m/s，按 |误差| 或角速度衰减目标速度，**收益大于调 PID**。

## 5. 待实测清单（**全部不阻塞画板**，板回来再做）

| # | 测什么 | 怎么测 | 影响 |
|---|---|---|---|
| 1 | **每米脉冲数**（代替减速比） | 推车走 1.00m，串口打印脉冲数 | 里程判据、速度环标度 |
| 2 | 轮径 | 卡尺量 | 同上换算 |
| 3 | **N30 实际 DCR** | 万用表电阻档（标称"<15A"无意义） | AT8236 限流阈值 = 12.6/DCR 的 60% |
| 4 | 编码器装在哪根轴 | 看学长件实物（电机尾 or 轮轴） | 决定脉冲标度，不改硬件 |
| 5 | 4.7V 模块纹波 | 示波器，或先并 220µF | 直接进陀螺仪 → Z 零偏漂移 |
| 6 | 灰度阈值/遮光效果 | 子板回来放赛道上逐路看 | 调 LM393 电位器 |
| 7 | **震动断电定位** | 万用表夹 3.3V 轨，手抖车架/按车头看掉压 | ★先做这个，否则新板新电机照样断 |

## 6. 负压：留退路，不装（因为现在它几乎免费）

情况变了：**风机是学长的（0 元）+ 扇叶/支架打印 0 元** → 负压的边际成本只剩
1 颗 4 元芯片 + 0.6A 电流 + 半天调试。

- **板上**：第 3 颗 AT8236 **留焊盘不贴件**，PB1/PB2 引到排针。
- **结构**：扇叶和负压支架**现在就打印**（免费、不占关键路径）。
- **装车时机**：第一次实测圈速出来再定。
  若弯道打滑是瓶颈 → 上负压（开源作者实测 7W → 1.2kgf 吸力，对 350g 的车相当于正压力 ×4.4，
  理论弯速 ×2）；若直道就够快 → 别碰，它是全车最大震动源，作者自己都提醒"螺丝共振→陀螺仪漂"。
- **校赛前夜绝对不装负压**（改重心 + 改震动谱 = 现场翻车经典配方）。

## 7. 电机结论（N30 强磁超高速，学长件）

| 参数 | 值 | 军师判断 |
|---|---|---|
| 额定 11.1V / 空载 33000rpm | — | **必须减速箱**，直驱不可能 |
| 堵转力矩 200gf·cm = 19.6mN·m | — | 经 1:30 后轮上 0.44N·m → 牵引 27.6N；而 350g 车打滑极限只有 2.1N → **扭矩过剩 13 倍** |
| 空载电流 230mA | — | 双电机怠速 0.46A，正常循迹 0.5~1.2A/个 |
| 堵转"<15A" | — | 超芯片峰值 → **必须设限流**（§2.3 约束 2） |

→ **结论：别再找"扭矩大的电机"了，N30 扭矩严重过剩。真正的瓶颈是 ①减速比选错导致转速不够 ②胎皮打滑 ③震动断电。**
花钱优先级：**胎皮 > 电池 > 别的都别买**（抓地是唯一买得到的物理上限）。
