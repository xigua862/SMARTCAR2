## 0. 一句话框架

**结构底板（纯结构 PCB，不装元件）＋ 上方电路板（核心 + 电源 + 传感接口，驱动可分可合）；
3S 直给驱动、逻辑走 12V→5V→3.3V；软件 5ms 一个控制周期，每 10ms 兼容；
循迹用外购 8 路模拟量灰度模块，前瞻可调 35~55mm；**惯导为主线、光电为辅**；每种赛道元素只允许一套判据。**

### 1.3 ★编码器与标定（本版重大更正）

**v1.7 说"编码器已确认装在轮轴"→ `mm/count = πD/4096`、减速比不用知道。实测推翻：编码器带一个 5mm 齿轮，是齿轮驱动的。**

```
编码器 1024 P/R × 4(正交) = 4096 count / 编码器转
若编码器 5mm 齿轮咬轮上 22mm 齿轮 → k = 编码器转数/轮转数 = 22/5 = 4.4
  ⇒ 每轮转 = 4096 × 4.4 = 18022 count  ⇒ mm/count = 72.26/18022 = 0.00401 mm
  ⇒ 1.2 m/s 时计数率 = 299 kHz；3 m/s 时 = 748 kHz
若 k = 1（真的在轮轴上）⇒ mm/count = 0.01764；1.2 m/s 时 68 kHz
```

**处理（不要推导，直接标定）：**
1. **把"推车 1m 数脉冲"从"校验"升为"主标定"**：`mm/count = 1000 / 推1m的计数`。这样 k 和 D 都不必知道，齿轮咬错也算对。
2. 仍需**量轮径 D**（软尺绕胎一圈 ÷ π，绕 3 次取平均）——用于牵引力换算与交叉检查。
3. ⚠ **必测**：推车 1m 时顺便看**实际计数率**。**>200 kHz 就要换方案**（TIM 编码器接口可能吃不下；k=4.4 时 1.2m/s 就 299kHz）。
4. ⚠ 轮轴/齿轮编码器的固有代价：**打滑时里程虚高** → 圆环/终点判据必须叠**陀螺角度积分**兜底。

## 2. 硬件框架（画板的直接输入）

### 2.1 分板策略 + 材料结论

| 板 | 内容 | 为什么 |
|---|---|---|
| **结构底板** | **2.0mm PCB，双面铺铜，哑黑阻焊，不装任何元件** | 承力 + 前伸舌板 + 遮光；不装元件 ⇒ 可以做得又低又薄，"下板贴地"的问题自动消失 |
| **电路板（上方）** | 核心（C8T6+晶振+SWD+丝印+IMU+灰度接口）+ 电源；**驱动可分可合** | 挂侧框架上排孔 |

**驱动要不要单独一块板？**（**唯一未拍板项**）先按**一块板**画（严格分区），只有满足以下任一条才拆成两块：
- 布局布不下；② 电机噪声串进 ADC（灰度读数抖）；③ 温升超（手摸烫）。

若拆：**功率级（VM/AT8236/大电容/降压模块）留在驱动板**，过板只走 `5V + GND + 4 路 PWM`
（≈0.3A）→ 用一个 **2×6 或 2×5** 带锁扣排针，**地针 ≥3 根**，PWM 串 22~47Ω，排线不并行电机线束。

**★材料结论（推翻 v1.7 的 3D 打印底板）：**
- **结构件用 PCB，不用碳板、不用 3D 打印。**
- 依据①（开源原文，`开源工程/微缩车模型-Micro_car/README.md` §8）：**"能用碳板用碳板，不要用 3d 打印……不想花钱直接打 pcb 替代碳板"**——作者反对的是 3D 打印，PCB 是他并列推荐项；
- 依据②：**碳纤维导电**，旁边就是模拟线/5V/传感器，摩擦即短路，且要全程绝缘；
- 依据③：**碳板唯一的优势是比刚度（轻），而校赛不称重不罚时 ⇒ 该优势等于零**；
- 依据④：PCB 可顺手做哑黑阻焊（遮光）、丝印、开窗，且打样免费。
- **3D 打印只做它不可替代的部分**：遮光围裙、法兰、螺纹座（黑色 PETG/尼龙，壁厚 ≥2mm）。

### 2.2 电源树

```
3S 锂电 11.1~12.6V（已有 2000mAh，63×18×15）
 └ XT30 ─ PTC 自恢复保险（贴片 SMD0805-050-16）─ TVS
    ├─【功率轨 VM = 12.6V 直给】→ AT8236 ×2(+1 预留) → 电机 / 风机
    │     就近：470µF/25V ×1 + 0.1µF ×3；OUT→端子间 100nF + 磁珠
    └─【逻辑轨】→ 12V→【5V，必须 5V 不是 4.7V】降压模块
          ├ 灰度模块 VCC（≈170mA） ← 走 5V：不占 LDO，且发射管更亮
          │     └ AO(5V) ── 1k ──┬── PA3(ADC1_IN3)；1.5k + 100nF 到 GND
          └ ME6211C33M5G-N（3.3V）→ C8T6 + IMU + 编码器 + 上拉/蜂鸣 ≈120mA
   地：功率地与逻辑地单点相连（0Ω 或磁珠）
```

**五条硬约束**
1. **5V 预算 ≈290mA**（灰度模块 ≈170 + LDO 输入 ≈120）→ **降压模块要能连续 ≥400mA**。⚠ 买 **5V 不买 4.7V**。
2. **3.3V ≈120mA**（MCU/IMU/编码器/上拉/蜂鸣）→ **ME6211C33M5G-N** 即可；LDO 耗 (5−3.3)×0.12 = **0.2W** ✅。⚠ 严禁 RT9013（250mA，余量不足）
3. **严禁 LDO 直吃 12.6V**：`(12.6−3.3)×0.12 = 1.1W` → SOT-223 热保护。**降压那一级不能省。**
4. **严禁 4S**（入口 TVS 16V，4S 满电 16.8V 会长期导通）。每颗 AT8236 **按手册公式 `ITRIP = VREF/(10·R_ISEN)` 把限流设到 3A** → **AT8236N（内部 VREF 3.3V）+ R_ISEN 0.11Ω/≥1W(2512)**；⚠ 手册给 ISEN 的**绝对最大只有 0.5V ⇒ R ≤ 0.167Ω**。详见 `文档/AT8236-照这个画-20261003.md`
5. **开关别朝下、别串在板上**：优先**取消**，用"发车时插 XT30"当总开关（少一个插件件+少两个朝下针+少一个振动松动点）。

### 2.3 引脚分配（48 脚，锁死）

| 功能 | 引脚 | 5V 容忍 | 备注 |
|---|---|---|---|
| **灰度：AD0/AD1/AD2** | **PA0 / PA1 / PA2** | ❌ 非 FT | ★同口**连续 3 位** → 一次 `GPIOA->BSRR` 写就切地址。**这是 MCU 输出的控制线 → 直连即可，不需要分压** |
| **灰度：模拟量 IN** | **PA3**（ADC1_IN3） | ❌ 非 FT | ⚠ **模块供 5V ⇒ AO 是 5V 电平 ⇒ 必须分压**：`AO ── 1k ──┬── PA3`，`1.5k ── GND`，`100nF ── GND`（5V 满量程 → 3.0V；源阻抗 600Ω，ADC 够用）。龙邱 8 路模拟量 = **1 ADC + 3 GPIO** |
| 电机 左 IN1/IN2 | PA8 / PA9 | ✅ | TIM1_CH1/CH2，四路独立 PWM |
| 电机 右 IN3/IN4 | PA10 / PA11 | ✅ | TIM1_CH3/CH4 |
| 风机（预留） | PB1 / PB2 | ⚠ **PB1 非 FT** | 留焊盘不贴件，见 §6 |
| 左编码器 A/B | **PA15 + PB3** | ✅ | TIM2 **部分重映射** CH1/CH2 |
| 右编码器 A/B | **PB4 + PB5** | ✅ | TIM3 **部分重映射** CH1/CH2 |
| 陀螺仪 SPI2 | PB13 SCK / PB14 MISO / PB15 MOSI / PB12 CS | ✅ | **不用 I2C**（会抢唯一遥测串口） |
| 陀螺 DRDY/中断 | PB8 INT1 / PB9 INT2 | ✅ | INT1 做 DRDY 外部中断（降积分抖动） |
| 遥测 USART1 | **PB6 TX / PB7 RX（必须重映射）** | ✅ | 115200；TX 走 DMA |
| 蜂鸣 | PB10 | ✅ | 上电自检发声 |
| 按键 ×2 | PB0 / PC13 | PB0 非 FT | 接 GND + 内部上拉 |
| 状态 LED | PC14 | — | |
| **SWD** | PA13 / PA14 | — | **必须留 4P 座** |
| BOOT0 | 10k 下拉 + 跳线 | — | 串口下载用 |
| 空闲 | PA4~PA7 / PA12 / PC15 | — | 备用（模拟抽头、扩展） |

**★IMU 座 8P 针序 —— 照实物丝印排，别自己排**（照片实测）：
```
VCC / GND / SCL-SPC / SDA-SDI / SA0-SDO / CS / INT1 / INT2
⚠ SA0/SDO 在 SPI 模式下是 MISO，严禁接地或接 3V3
```

**★必踩的四个软件坑（画板不管，固件必须做）**
1. `PA15 / PB3 / PB4` 默认是 JTAG 脚 → 初始化第一件事**禁 JTAG 保留 SWD**（`AFIO->MAPR` SWJ_CFG=100），否则两个编码器没读数。
2. **TIM1 是高级定时器，必须手动开 MOE**（`__HAL_TIM_MOE_ENABLE`）→ 忘了就是"程序在跑、电机不转"。
3. **USART1 用 PB6/PB7 必须重映射**（`AFIO->MAPR` 的 USART1_REMAP），否则遥测是空的。
4. 编码器标度**用推车 1m 标定**（§1.3），不要写死 `πD/4096`。

### 2.4 灰度：外购模块的采购与验收（**原自画子板彻底作废**）

> 原 8×ITR9909 + 4×LM393 + 逐路电位器的子板方案**作废**，原理图**留档不打样**（沉没成本不是继续的理由）。
> ⚠ 但**主板必须自画**——规则第 3 条：主控/电机驱动/传感器三者至少其一必须自主开发并印丝印。

**采购（龙邱 8 路模拟量款，用户 10-03 拍板）**，买前问客服 8 条 + 验收阈值：

| 项 | 通过 | 边界 | 否 |
|---|---|---|---|
| **最小检测高度** | ≤6mm 可用 | 6~10mm（要重算几何） | >10mm → 与 6mm 地基正面冲突，方案级 |
| **地址切换 settling** | **≤20µs** | 20~100µs（1.2m/s 走 0.19~0.96mm） | **≥500µs 直接否** |
| 档距 | 10~12mm（首选 11） | 12.6mm | <10 串光；≥25 踩"中心对 > 线宽" |
| 输出电平 | — | **5V 供电（我们的方案）→ AO 经 1k/1.5k 分压**进 PA3 | 若模块自带 3.3V 稳压则可免分压 |
| 路数 | 8（模拟量最佳） | 8 路数字选通 | 4 路 → 定位精度不够 |

**8 问话术**：路数 / 档距（要板框图与标尺）/ **最小检测高度** / 输出电平 / 波长 / **地址切换 settling** / 板框尺寸 / 供电范围与总电流。

**买回来后必做的三件事**
1. 量**安装耳平面 → 探头面**的高度（倒推结构底板的分层高度）；
2. **喷绘布对比度实测**（最高优先级，见 §5）：按实际供电 **5V**，在布上分别压白线与黑底，量 **AO** 输出差值（分压后在 PA3 侧读）；
3. 上电自检：黑底应全 0、跨白线应满量程，不对就蜂鸣。

**判据体系随之升级**（方案级）：从"数字 0/1 + Σ(w·s)/Σs" → **每通道归一化后加权求位置**
```
p_i = (v_i − v_black) / (v_white − v_black)     ← 每通道滑窗极值自适应
err = Σ(w_i · p_i) / Σ p_i
```
轮询时间预算：每通道 50µs（settling + ADC ≈1µs）→ 8 通道 **400µs** → 1.2m/s 走 **0.48mm**（占 11mm 档 4.4%）✅ 可接受。

### 2.5 前瞻、安装与循迹几何

**★口径（两条都改了）**：约束是"**探头连线 → 前轴 = 45mm**"，不是"板前缘 → 驱动轴"。
理由：① 成品模块的探头**不在板前缘**（内缩几毫米）；② 转向中心是**轴距中点**（每侧两轮同速），不是驱动轴。

**转向中心 = 前轴后 13mm**（= 轴距 26 的一半）⇒ `d = L + 13`，稳态跟弧偏差 ≈ `d²/(2R)`：

| L（探头→前轴） | d | R200 偏差 | 1.4 m/s 预览 | 2.0 m/s | 2.5 m/s |
|---|---|---|---|---|---|
| **35（可调下限）** | 48 | 5.76mm | 34ms | 24ms | 19ms |
| 45（设计值） | 58 | 8.41mm | 41ms | 29ms | 23ms |
| **55（可调上限）** | 68 | 11.6mm | 49ms | **34ms ✓** | 27ms |
| 65（硬上限） | 78 | 15.2mm | 56ms | 39ms ✓ | 31ms |

参考线：国赛 **35ms** / 区赛 **43ms**。⇒ 55mm 覆盖到 **2.0 m/s**；65 覆盖到 2.4；**3 m/s 要 92mm，物理上做不到 ⇒ 高速那段交给软件前瞻**（探头权值表 + 曲率前馈）。

**调参板做法（6 条）**
1. **两条平行长槽**（不是三档圆孔）：行程 **20mm**（35↔55），可连续调；
2. 槽宽 **2.2~2.4mm**（φ2 孔配 M2 是零间隙，槽必须留公差）；
3. 端部**加宽成"桨叶"**（两侧各放宽 5~8mm）补偿开槽削弱；
4. **两颗 M2 都拧紧** + 弹簧垫圈 + **螺纹胶**（单螺丝会绕轴转）；
5. **丝印三样**：一条**"前轴线"** + 35/40/45/50/55 **刻线** + 安装方向箭头；
6. 每次改档**记下来**（L、速度、现象）——调参要可复现。

> ⚠ **更正**：v1.7 的排布方案（收腰 ±5/±15/±27.5/±40、板宽≈88、捕获 ±52.5）**整节作废**——那是对自画子板定的，现在模块是买来的，档距以实物为准。
> **"悬臂会下垂"也已更正**：按 2.0mm FR-4、伸 36mm、尖端挂 20g 算，**静态下垂 0.0026mm（占 6mm 地基 0.04%，可忽略）**，一阶弯曲共振 ≈700~800Hz（远高于齿轮激励 ~17Hz）。
> ⇒ **长度几乎不要钱，真正的敌人是"接头的夹紧刚度"和"模块自身固定"**。侧梁的真正价值是提高共振频率，不是抗静载。

**代码侧两条硬要求**
```c
/* 用真实位置加权（位置以实物档距为准），改板/换模块必须同步改这张表 */
err = Σ(IR_POS[i] * p_i) / Σ(p_i);       /* Σp == 0 → 丢线分支 */
```
1. 归一化后的加权中心，**不能再用 `(i-3.5)` 索引式**；
2. **符号标定**：板面印 `FRONT →`；首次上电把线放车体**右侧**，err 应为正，为负就翻 `IR_SIGN_FLIP`。装反/镜像安装是"越纠越偏"的头号来源。

## 3. 软件框架

```
周期与中断
  TIM1  20kHz     电机 PWM（四路：方向靠电平、大小靠占空比）
  TIM2/TIM3       编码器硬件正交计数，不开中断
  SysTick **5ms** ★唯一控制周期（10ms 为降级兼容）：读灰度→里程→误差→判据→三环→限幅→写PWM
  USART1 TX DMA   遥测，绝不阻塞控制

分层
  drivers/      ir8.c  encoder.c  motor.c  imu.c  uart_dbg.c  buzzer.c  key.c
  middleware/   line_pos.c(归一化加权)  odom.c(里程)  ring.c(圆环5态)
                cross.c(十字)  finish.c(斑马线终点)
  control/      speed_pid.c  angle_pd.c  gyro_damp.c  slowsafe.c(弯道减速)  profile.c(速度剖面)
  app/          fsm.c  param.c(EEPROM/串口调参)  selftest.c
```

**★架构主线：惯导为主、光电为辅**（用户 2026-10-03 原话）
- 元素识别（十字 / 圆环 / 终点 / 斑马线）以 **里程 + 航向 + 已知赛道几何（CAD）** 为主，光电做**位置修正 + 脱线保护**；
- ⇒ 灰度选型不追求亚档距精度；判据延迟的时间偏斜问题**降级**；
- **最大风险 = 漂移累积** → 必须设计**地标重置点**：过十字/斑马线时用光电重新对齐航向或里程；
- 标定升为主线：① 上电静止零偏 ② **积分必须用实测 dt**（禁假设固定节拍）③ 里程 = 推车标定 + 打滑修正；
- IMU 只读 **Z 轴角速度 + 航向角**，别把六轴全量拉进 5ms 周期。

**判据纪律**
- **每种赛道元素只允许一套判据**，多余做成默认关闭的编译开关；
- **禁止 `while(1){ motor_stop(); }` 死循环停车**，失线一律走状态机超时；
- **短暂跳变保持上一帧**（开源做法：60ms），丢线/元素**按里程判**而不是按帧数；
- **元素互斥**：所有元素入口都带 `&& 其它状态==0`（直接消掉一大类误判）；
- **过元素后强制低速一段**（开源做法：500 拍 ≈ 250 拍@5ms）——这是"提速后不失控"的关键保护。

**加速与压缩圈速（规则允许，但按顺序来）**
- 成绩**按行驶距离积分**、时间只作同分加赛 ⇒ **先保不脱线跑完全程，再谈圈速**；
- 速度剖面 = ① 按曲率取 `v_曲率=√(μ·g·R)` ② **反向传减速** ③ **正向传加速**（开源依据：国赛把逐点速度烘进 `nav_path.h`，96 段，a+=3000 / a−=5000 cm/s²）；
- ⚠ 那套 a+≈30 m/s² 是**负压**（正压力×4.4）撑出来的；无负压时 `a ≤ μ·g ≈ 6~10 m/s²`；
- **加速会让车抬头 → 传感器离地变 → 阈值漂** ⇒ 重心靠后靠低 + **加速度限幅（软启动）** + 阈值留余量。

**上电自检（蜂鸣 + 串口，5 秒内）**
① 灰度逐路：黑/白极值是否可分 → 不对立刻叫；② 手转两轮验编码器方向；③ IMU WHO_AM_I + 静止零偏 200 次平均。
