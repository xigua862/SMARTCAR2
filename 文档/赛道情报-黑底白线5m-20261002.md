## 2. 由 R200 推出来的硬约束：必须做弯道减速

过弯不打滑的极限 \(v_{max}=\sqrt{\mu g R}\)，取 \(g=9.8\)、\(R=0.2\,\text{m}\)：

| 胎面摩擦 μ | R200 允许速度 | R300（E 环） | R500 |
|---|---|---|---|
| 0.6（轻车+硬塑料面） | **1.08 m/s** | 1.32 | 1.71 |
| 0.8（硅胶胎/橡胶） | **1.25 m/s** | 1.53 | 1.98 |
| 1.0 | 1.40 m/s | 1.71 | 2.21 |

> 他们国一车直道 3.8 m/s，但 **R200 处物理上限只有 1.1~1.4 m/s**。100g 的车惯量小、抓地绝对值也小 → **不做弯道减速必甩出线**。
> **做法（最省事，不用状态机）**：用 \(|ERR|\) 或角速度积分做速度衰减：
> `car_speed_now = car_speed * (1 - k*min(|ERR|,ERR_MAX)/ERR_MAX)`，进弯自动慢、出弯自动快；比"分段定速"少一半工作量。

**单圈长度粗估 12~18m → 两圈 24~36m → 均速 1.3 m/s 约 18~28 秒/场。**

## 3. 红外传感规格（黑底白线，8 路）

| 项 | 建议值 | 理由 |
|---|---|---|
| 路数 | **8 路数字输出**（自带比较器，进 GPIO 不占 ADC） | 源码 `P1` 整口一次读，改 16 路反而麻烦 |
| 管间距 | **18~20mm**（≈线宽 ×1.2） | 覆盖 ±70mm 横向偏差，够 R200 用 |
| 离地高度 | **3~8mm，固定死**（支架+螺丝，不许悬空叠装） | 高度一漂阈值全废 |
| **遮光** | 每只管**套黑色热缩管/加黑卡纸围边**，整条压一层遮光罩 | 日光灯/阳光含红外，裸管在赛场强光下会**漂到不可用**（黑底白线方案最常见的翻车点） |
| 供电 | **3.3V**（板上 RT9013 那路） | STC32G GPIO 不耐 5V；8 路常亮约 **150~200mA** |
| 发射方式 | 先做**常亮**（最省事），有余力再改脉冲选通 | 常亮多耗 ~0.15A，换代码简单，值 |
| 输出逻辑 | 代码留 `#define IR_WHITE_IS 1`，**上电标定** | 模块不同极性相反，现场改一行 |
| 上电自检 | 放线上读一次 + 放空白读一次，蜂鸣提示 | 用现成的 `BUZZER_PIN P67`，30 秒排掉一半现场故障 |
| 串阻 | 每路 100Ω~1kΩ | 错插/热插拔保护 |

## 4. ★ 圆环状态机**不能删**（纠正上一份文档）

E 区那 **4 个相切 R300 圆**就是"圆环"元素 → 源码 `adc.c` 里的 `ring_judge()`（5 态：NONE→ENTER→INSIDE→EXIT→LEAVE）**是经过国赛验证的现成环逻辑，正好对得上**：

| 源码做法 | 我们改成红外版 |
|---|---|
| 入环触发：`adc_x_l+adc_x_r ≥ 1300` 且 `adc_y_l+adc_y_r ≥ 400` | 换成 **编码器里程到点**（`in_ring_dis_x=5000`/`in_ring_dis_d=8000` 本来就是干这个的）**或**"连续 N 拍 ERR 同向饱和" |
| 环内：`angle_integral_Z > 60°` 判出环、`> 340°` 判到位 | **原样照搬**（陀螺仪积分与传感方式无关） |
| 环内强制 `ERR = ±r_offset(35/50)` | **原样照搬**（绕环就是给固定偏置贴着圆走） |
| 环编号 2/6/10 小环、3/7/11 大环 | 按这张图重排：**E 区 4 个环** + C 区 R390 → 只有 4~5 个环位，编号表要改短 |
| `ring_tim ≥ out_ring_tim(500)` 复位 | 照搬 |

**飞坡状态机 `flyboard()`**：图上**看不到任何坡道/跷跷板/墙面**（纯平面 5×5 板）→ **待你确认；平面赛道就直接删掉这块**。

**十字（C 区交叉）**：源码**没有十字逻辑** → 要自己加，标准做法很短：
> 里程窗口内 + `|ERR|` 连续多拍反复过零 → 判定十字 → **该窗口内忽略转向、只保持车速**，冲过去即恢复。

**起点线（S/G 那组横短线）**：可用"8 路同时压白"检测过线 → **圈数计数 + 两圈到点停车**（正好替掉源码里那个 `while(1)` 死循环停车的写法）。

## 5. 电机：✅ **身份已搞清（上一节搞错了，更正）**

> **你发的图 = 负压风机（不是驱动电机）**；驱动电机 = **微缩组标配、逐飞车模自带那种（030 级有刷）**。
> 风机万用表量到 **5Ω、两根线** → **它就是普通有刷电机** → **板上那条无感换向链（EG2134 + Q1~Q6 + 第 2 片 STC32G）当场删除**。
> 堵转电流 = 12.6 / 5 = **2.5 A** ✓ 和我原来给的“风机启动 2~3A”预算完全吻合。
> ⚠️ **不要求重量**（普通省赛，只要快）→ 本文 §6 的减重结论**作废**，电池改选 **3S 450~600mAh ≥20C**（压降小、续航长、更便宜）。最终下单项见 **`下单清单-今天就能拍板-20261002.md`**。

### ① 现在就能测（万用表 30 秒）
**量两根线之间的直流电阻 DCR** → 堵转电流 ≈ `12.6V ÷ DCR`
| 量到 DCR | 堵转电流 | 结论 |
|---|---|---|
| 3Ω | 4.2 A | 峰值预算要上调，电池要 ≥30C |
| 6Ω | 2.1 A | 和我给的 6~8A 总峰值预算吻合 ✓ |
| 12Ω | 1.05 A | 电池可以更小倍率 |
| <1Ω 或 >50Ω | — | 不是普通小马达，另查 |

再测两项（有可调电源+电流表最好，没有就先只测 DCR）：**空载电流@11.1V**、**顶住轮子不让转时手摸外壳多久发烫**（5 秒内烫手 = 别长时间堵转）。

### ② 一个必须注意的电压问题
电机标称上限 **12V**，而 **3S 满电 = 12.6V** →
**软件里给 PWM 占空比加 90% 上限**（`12.6 × 0.9 ≈ 11.3V`），零成本保护电机和风机。改一处：`motor.c` 的 `MOTOR_PWM_MAX` 从 10000 改 **9000**。

### ③ 这个电机**没有编码器**
源码要 **两路带方向正交编码器**（`P34+P35`、`P04+P53`）→ 必须确认：**学长车上有没有编码器？** 没有的话走 `开源工程/微缩车模型-Micro_car/README.md` 里的**磁编码方案**（F682 轴承 + 径向磁铁 + 磁编码器芯片），那是唯一来得及的路（机械要一起设计）。

### ④ 别买 L298N / TB6612FNG
你贴的那段建议是通用科普。我们的板子已经是 **DRV8701E + TPN2R703NL（20~30A 级）**，比那两个模块强一个数量级 —— **不需要任何额外驱动模块**，直接接板上 H 桥输出。
