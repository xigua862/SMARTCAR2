4. **底盘结构板** — 3 组 8P 驱动模块座 + `BAT` + `ON` 开关 + 中央大圆孔 + 一圈编号安装孔（26~43）→ **模块插接式**布局。

## 3. 必须改什么 / 是坑

1. **平台不通吃**：TC264 用 AURIX/TASKING 工具链（`.cproject`/Lcf_Tasking_Tricore_Tc.lsl），**不是 Keil**，A 车的 C8T6 固件、串口工具、调参脚本**不能直接烧**；引脚也不兼容（P21_3/P33_6 这类端口命名）。
2. **Micro_car 作者原话：「我没下过地跑过」**，且"仅供参考，觉得不行就当看个乐" → 只当**结构参考**，不是已验证方案；负压部分他自己说"随便画的"。
3. **重量/功耗未知**：README 说 7W 负压吸 1.2kg、单层铝底板 20g —— 微缩组限制是多少**规则没找到前不订任何定制件**（交接 §2 的硬约束）。
4. **编码器磁干扰**：磁铁离电机太近会受影响 → 布局拉开，买磁铁认准 **"径向!!!!!!"**；芯片建议 TLE5012(E1000 默认正交) 或 MT6835。
5. **负压震动**：扇叶动平衡差 → 负压支架改**弹簧/柔性解耦**（他看到国外鼠车不直连），陀螺仪加减震柱，否则螺丝松动 + 陀螺仪漂。
6. **底板变形/轮子外八**：开负压后车架变形 → 加支撑（可用板子当支撑），底板从 1.5mm 铝基改 **1mm 或 PCB 当结构板**减重。
7. **裙边材质**：铁氟龙偏硬易变形 → 用**大棚膜**；贴膜纳米胶铺宽不留缝（漏气就白搭）。
8. **齿轮 54 齿是"加起来"**：40+14 只是他给的配比，轮径/减速比要按 B 车速度和电机扭力重算。
9. **epro2 归属未确认**：丝印是别的学校/队名，**先问清楚是谁画的、有没有实物和立创订单**，再决定"改"还是"重画"。
