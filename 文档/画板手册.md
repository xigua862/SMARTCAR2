# test16 循迹小车 · 画板手册（引脚 + 接入顺序）

> 用途：**画板子 / 焊板子 / 接线**时对着看，一根线一根线讲清楚。
> 数据来源：`test16.ioc` + `Core/Src/main.c` + `循迹小车使用手册.md`（三者已核对一致）。
> 芯片：STM32F103C8T6，**LQFP48 封装**。

---

## 0. 总览（先记住这 3 条规则）

```
   圆口适配器 (9~12V, 内正外负)
        │
        ▼
┌── 多路电源模块 V3.1 (LM2596×4) ──┐
│ 红色 5V 通道    ──► 循迹×5 + 霍尔×2 │
│ 蓝色 3.3V 通道   ──► STM32F103C8T6  │
│ 黄色 VADJ 通道   ──► 电机驱动板 VM  │
└────────┬───────────────────────────┘
         │ (输出端 GND 全部共地)
         ▼
  板子只需 4 个电源焊盘：5V / 3.3V / VM / GND
```

**规则 1（共地）**：模块输出 GND 已全部连通；板子上把 5V、3.3V、VM 三条回路的 GND **汇到同一个地**（星形接地）。
**规则 2（供电分开）**：循迹/霍尔用**红色 5V 通道**，单片机用**蓝色 3.3V 通道**，电机驱动用**黄色可调通道（先调到≈7.4V）**。**板子上不再需要任何稳压芯片**（不用 AMS1117）。
**规则 3（只接 FT 脚）**：模块输出的 5V 信号**只能**接到下表列出的 FT（5V 容忍）引脚；**禁止**接到 PA0~PA7、PB0/PB1，会烧单片机。

## 1. 接入顺序（画板/接线就按这个编号走，1→10 不会漏）

| 步 | 接什么 | 怎么接 | 共几根线 |
|----|--------|--------|----------|
| ① | 电源输入 | 圆口适配器（9~12V，**内正外负**）→ 电源模块圆口座 | 1 |
| ② | 电源模块出线 | 红色5V通道→板子**5V**；蓝色3.3V通道→板子**3.3V**；黄色VADJ通道（**先调到≈7.4V再接线**）→电机驱动**VM**；各通道GND→板子**GND** | 6~8 |
| ③ | 单片机最小系统 | 8MHz 晶振→PD0/PD1、复位电路→NRST、BOOT0 下拉、VBAT→3.3V | 见 §2 |
| ④ | 下载口 | SWD 排针：3.3V、GND、SWDIO(PA13)、SWCLK(PA14)、(RST) | 4~5 |
| ⑤ | 电机驱动板 | 见 §3.1：2 根 PWM + 4 根方向 + **VM 取黄色 VADJ 通道** + 电机输出 | 8~10 |
| ⑥ | 循迹模块 ×5 | 每个模块 3 根：VCC(5V)、GND、DO → 对应引脚（§3.2） | 15 |
| ⑦ | 霍尔模块 ×2 | 每个模块 3 根：VCC(5V)、GND、OUT → PA11 / PA12（§3.3） | 6 |
| ⑧ | 串口调试口 | USB转TTL 4 根：TX/RX/GND/(5V)（§3.4，顺序见下） | 3~4 |
| ⑨ | 可选 | 32.768kHz 晶振→PC14/PC15（程序没用 LSE，**可不焊**） | 2 |
| ⑩ | 上电前自查 | 对照 §5 清单过一遍再插电 | — |

> **串口（调试口）的接入顺序**，一根一根来：
> 1. 先接 **GND ↔ GND**（不共地串口必乱码）；
> 2. USB转TTL 的 **RXD** ← 接 STM32 **PA9 (USART1_TX)**；
> 3. USB转TTL 的 **TXD** → 接 STM32 **PA10 (USART1_RX)**；
> 4. USB转TTL 的 **5V**（可选）：板子自己供电时**不要接**，只有要用 USB 供电才接。

## 2. STM32 引脚总表（LQFP48 脚位号，画封装/netlist 用）

### 2.1 电源 / 系统脚（必须画，不能省）

| 脚位 | 引脚 | 接到哪 |
|------|------|--------|
| 1 | VBAT | 3.3V（没有 RTC 电池就直连 3.3V） |
| 7 | NRST | 10kΩ 上拉到 3.3V + 0.1µF 到地（复位键可选） |
| 8 | VSSA | GND |
| 9 | VDDA | 3.3V，加磁珠 + 1µF/0.1µF 滤波 |
| 23/35/46 | VSS_1/2/3 | 全部接 GND，每个 VSS 就近打孔 |
| 24/36/47 | VDD_1/2/3 | 全部接 3.3V，**每个 VDD 旁边放一个 0.1µF 退耦电容** |
| 48 | BOOT0 | 10kΩ 下拉到 GND（想用串口下载时再留跳线） |
| 5/6 | PD0 / PD1 | 8MHz 晶振（HSE），各接 20pF 负载电容到地，晶振**紧贴这两个脚** |
| 3/4 | PC14 / PC15 | 32.768kHz 晶振（**可选，程序没用到 LSE，不焊也行**） |
| 2 | PC13 | 空（可引出做指示灯） |

| 13 | PA3 | TIM2_CH4 = 电机2 PWM | 驱动板 PWMB / ENB |
| 14 | PA4 | DIR1 | 驱动板 AIN1 / IN1 |
| 15 | PA5 | DIR2 | 驱动板 AIN2 / IN2 |
| 39 | PB3 | DIR3 | 驱动板 BIN1 / IN3 |
| 40 | PB4 | DIR4 | 驱动板 BIN2 / IN4 |
| 29 | PA8 | IR_L（最左传感器） | 循迹模块①DO |
| 38 | PA15 | IR_LM（左二） | 循迹模块②DO |
| 41 | PB5 | IR_C（中间） | 循迹模块③DO |
| 42 | PB6 | IR_RM（右二） | 循迹模块④DO |
| 43 | PB7 | IR_R（最右） | 循迹模块⑤DO |
| 32 | PA11 | HALL1（电机1霍尔） | 霍尔模块①OUT |

## 3. 各模块接口定义（画连接器/排针时对照）

### 3.1 电机驱动板

**若用 TB6612FNG**（江协科技教程同款蓝色小板，推荐，3.3V 逻辑可直接驱动）：

| 驱动板引脚 | 接到 STM32 / 电源 |
|------------|-------------------|
| PWMA | PA2 |
| AIN1 / AIN2 | PA4 / PA5 |
| PWMB | PA3 |
| BIN1 / BIN2 | PB3 / PB4 |
| VM | 电源模块**黄色 VADJ 通道**（调到 ≈7.4V，TB6612 最高 15V，余量很大） |
| VCC | **3.3V**（⚠️ 别接 5V：TB6612 逻辑高电平阈值≈0.7×VCC，VCC=5V 时阈值 3.5V > STM32 的 3.3V，会偶发不转） |
| STBY | **接 3.3V**（必须拉高，悬空 = 输出关闭，电机不转） |
| GND | 共地 |
| AO1/AO2、BO1/BO2 | 电机1 / 电机2 两根线 |

**若用 L298N**（注意：逻辑输入 3.3V 可能驱动不足，建议加电平转换或确认板子兼容）：

| 驱动板引脚 | 接到 STM32 / 电源 |
|------------|-------------------|
| ENA | PA2（PWM） |
| IN1 / IN2 | PA4 / PA5 |
| ENB | PA3（PWM） |
| IN3 / IN4 | PB3 / PB4 |
| 12V / VMS | 电源模块**黄色 VADJ 通道**（L298N 建议调到 9~12V） |
| 5V / VSS | 3.3V 或 5V（板上稳压输出） |
| GND | 共地 |
| OUT1~OUT4 | 电机1 / 电机2 |

### 3.2 循迹模块 ×5（TCRT5000 常见 4pin：VCC GND DO AO）

| 模块引脚 | 接到哪 |
|----------|--------|
| VCC | **5V**（不要接 3.3V） |
| GND | 共地 |
| DO（数字输出） | 按 §2.2 接 PA8 / PA15 / PB5 / PB6 / PB7 |
| AO（模拟输出） | 悬空不接 |

> 若你的模块只有 3pin（VCC GND OUT），OUT 就是 DO，照接。
> 丝印上给 5 路循迹排针标号：①=左 ②=左二 ③=中 ④=右二 ⑤=右。

### 3.3 霍尔测速模块 ×2（如 3144 + LM393 比较器板）

| 模块引脚 | 接到哪 |
|----------|--------|
| VCC | **5V** |
| GND | 共地 |
| OUT | 电机1 → PA11；电机2 → PA12 |

### 3.4 USB 转 TTL（串口调试）

| USB转TTL 引脚 | 接到哪 |
|---------------|--------|
| RXD | ← PA9（STM32 TX） |
| TXD | → PA10（STM32 RX） |
| GND | 共地（**必接**） |
| 5V | 可选：仅当用 USB 供电时接 |

### 3.5 ST-Link（SWD 下载口）

| ST-Link 引脚 | 接到哪 |
|--------------|--------|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | 共地 |
| 3.3V | 可选（调试时供电） |
| RST | 可选 → NRST |

## 4. 画板要点（立创EDA / AD 通用）

1. **电源线加粗**：VM/5V/GND 走线 ≥ 40mil（VM 走电机电流，能粗则粗），**3.3V 总线 30mil（最低 20mil）**，信号线 ≥ 10mil。3.3V 只带 STM32(~80mA峰值)+TB6612 VCC+预留OLED，电流很小，宽度不是电流决定的，30mil 是为余量和机械强度；**瓶颈在排针接触电阻**——左侧排针 3、4 两针都接 3.3V、1、2 两针都接 GND（并联减半），并从 3.3V 汇流条**星形分支**给 TB6612 VCC / SWD / OLED，不串联。
2. **退耦电容**：每个 VDD 脚旁放 0.1µF，紧贴芯片；VDDA 走磁珠（或 10Ω 电阻）+ 1µF。
3. **晶振**：8MHz 晶振**紧贴 PD0/PD1**，两脚各 20pF 到地，晶振下方**不要走信号线**，电机 PWM 线远离晶振。
4. **接插件放板边**：电机排针、5 路循迹排针、霍尔排针、USB-TTL 排针分开放，丝印写清楚标签（IR_L、IR_C、HALL1、TX、RX…）。
5. **星形共地**：所有模块 GND 尽量汇到电源地一点，避免地环路导致循迹误触发。
6. **循迹 5 路排针顺序按车头从左到右**：1 2 3 4 5，和 §2.2 一一对应，接反了车乱摆。
7. **电机线**：PWM/方向线远离晶振和霍尔信号线（电机电流大，干扰大）。
8. **BOOT0 一定要下拉 10kΩ**，不然上电可能进不了程序。
9. **预留**：板边留 2.54mm 排针测试点（TX、RX、5V、GND、3.3V），调试救急用。

## 5. 上电前自查清单（每项打勾再插电）

- [ ] 5V、3.3V、GND 不短路（万用表蜂鸣档量一遍）
- [ ] 黄色可调通道输出电压已调到 ≈7.4V（不超电机驱动最高电压）再接线
- [ ] 圆口极性：内正外负（用万用表量一下适配器输出，插错会烧模块）
- [ ] BOOT0 已下拉到地
- [ ] 8MHz 晶振装好，负载电容 20pF ×2
- [ ] 三个 VDD 都有 0.1µF 退耦；VDDA 有滤波
- [ ] 电机 PWM/方向 6 根线对照 §3.1 接对（驱动板型号不同引脚名不同，先查自己板子）
- [ ] 循迹 5 路 DO 顺序：左→右 = PA8→PA15→PB5→PB6→PB7
- [ ] 霍尔 OUT → PA11(电机1) / PA12(电机2)
- [ ] USB-TTL：RXD←PA9、TXD→PA10、GND 已共地
- [ ] 所有模块 GND 共地
- [ ] 所有 5V 信号线只接到 FT 引脚（PA8/PA15/PB3~PB7/PA11/PA12/PA9/PA10），没碰 PA0~PA7、PB0/PB1
- [ ] 先只烧程序（ST-Link 下载），串口看到 `IR:xxxxx RPM1=0 RPM2=0` 再上电机

## 7. 底板（载板）设计——江协开发板怎么放

> **架构已更新**：主控不再是自己画最小系统，而是把**买来的江协 STM32F103C8T6 开发板**直接插在底板上。底板负责：电源焊盘（5V/3.3V/VM/GND）+ TB6612 + 各模块排针。

### 7.1 关键尺寸（实测）

| 尺寸 | 数值 | 说明 |
|------|------|------|
| **两排排针中心距** | **15mm**（≈1.5cm） | 底板两排排母的中心距就设这个值 |
| 单排内引脚间距 | 2.54mm | 标准排针，不用量 |
| 每排针数 | 待确认（`接线对照表.html` 暂按每排 **20 针**编号，以实物为准） | 数一下，排母长度 = 针数 × 2.54mm |

> ⚠️ **量法核对**：中心距 = 左排第 1 根针 → 右排第 1 根针（同一侧边沿对齐量）。如果你当时量的是两排的**内侧边沿**，实际中心距 ≈ 15 + 0.6 ≈ 15.6mm；是**外侧边沿**则 ≈ 14.4mm。差 ±0.6mm 排母也能插上，问题不大；但别差一个 2.54mm。

### 7.2 底板做法（立创EDA）

1. 放两排 **2.54mm 排母**（搜"排母 2.54"），排数 = 开发板每排针数；
2. 两排排母 **中心距设 15mm**（选中一排，Y 坐标比另一排多/少 15mm）；
3. 开发板插上后，**5V/3.3V/GND 和 PA2~PA12 等信号从排母引出**，就近走线到 TB6612、循迹排针、霍尔排针、USB-TTL 排针；
4. 四角加 **3mm 铜柱孔**（φ3.2mm 过孔）把开发板和底板锁在一起，防松；
5. **预留 4pin 扩展排针**（VCC/GND/PB8/PB9）：现在**不焊 OLED**，留作以后扩展（见 §7.4），成本只是板上多 4 个孔位。

### 7.3 引脚对应（完整对照表——画底板拉线就按这张）

> 以下针位编号 = 开发板排针**从下往上数**（1=最下面一根）。左右两侧各两排（内/外），信号完全一样，任选一排接线即可。

| 5 | RES | 复位键（可选）或悬空 |
| **12** | **PA5** | → P2-7 (AIN2) / DIR2 |
| **13** | **PA4** | → P2-6 (AIN1) / DIR1 |
| **14** | **PA3** | → P2-2 (PWMB) / 电机2 PWM |
| **15** | **PA2** | → P2-8 (PWMA) / 电机1 PWM |
| 20 | PC13 | 可引出做 LED 指示灯 |

#### 右侧排针（U2/U3）——循迹 + 霍尔 + 串口 + 电机方向 + OLED预留

| 针位 | 信号 | 底板接到哪 |
|------|------|-----------|
| **5** | **PA8** | 循迹排针① IR_L（最左）DO |
| **6** | **PA9** | USB-TTL 排针 RXD |
| **7** | **PA10** | USB-TTL 排针 TXD |
| **8** | **PA11** | 霍尔模块① OUT（HALL1） |
| **9** | **PA12** | 霍尔模块② OUT（HALL2） |
| **10** | **PA15** | 循迹排针② IR_LM（左二）DO |
| **11** | **PB4** | → P2-3 (BIN2) / DIR4 |
| **12** | **PB3** | → P2-4 (BIN1) / DIR3 |
| **13** | **PB5** | 循迹排针③ IR_C（中间）DO |
| **14** | **PB6** | 循迹排针④ IR_RM（右二）DO |
| **15** | **PB7** | 循迹排针⑤ IR_R（最右）DO |
| **16** | **PB8** | 🔒 扩展排针 SCL（OLED 预留） |

#### TB6612 专用接口（P1 电源/输出 + P2 控制）

**P1（8pin）— 电源与电机输出**：
| 针 | 接法 |
|----|------|
| 1 VM | 电源模块黄色 VADJ ≈7.4V |
| 2 VCC | 3.3V |
| 3 GND | 共地 |
| 4 AO1 | 电机1 线A |
| 5 AO2 | 电机1 线B |
| 6 BO2 | 电机2 线A |
| 7 BO1 | 电机2 线B |
| 8 GND | 共地 |

**P2（8pin）— 控制信号（从开发板排针拉过来）**：
| 针 | 信号 | 来自开发板哪根针 |
|----|------|------------------|
| 1 | GND | 共地 |
| 2 | PWMB | 左侧 **针14 (PA3)** |
| 3 | BIN2 | 右侧 **针11 (PB4)** |
| 4 | BIN1 | 右侧 **针12 (PB3)** |
| 5 | STBY | **→ 3.3V**（必须拉高！） |
| 6 | AIN1 | 左侧 **针13 (PA4)** |
| 7 | AIN2 | 左侧 **针12 (PA5)** |
| 8 | PWMA | 左侧 **针15 (PA2)** |

#### ⚠️ 注意

- **SWD 下载口（PA13/SWDIO、PA14/SWCLK）不在这 40 根排针里**——江协开发板有独立的 SWD 插座（通常是 4pin 或 5pin），底板上要单独留 SWD 排母位置，或者直接用杜邦线连开发板自带的 SWD 口。
- **左侧 PA0~PA7、PB0~PB1 是非 FT 脚**——别把 5V 传感器信号接这些位置。
- 循迹 5 路 DO 的**物理顺序**在右侧排针上就是：针5(PA8) → 针10(PA15) → 针13(PB5) → 针14(PB6) → 针15(PB7)，**和车上从左到右一一对应**。

### 7.4 OLED（暂时不用，留扩展位）

- **现阶段不加**：调试数据（IR + RPM）串口全有，OLED 只在"车脱离电脑跑"时才有价值；
- **引脚原因**：F103C8 硬件 I2C1 是 PB6/PB7，已被循迹占用 → 以后若加 OLED 用**软件 I2C 走 PB8/PB9**（预留排针就是这两个脚）；
- 想加时：插 0.96 寸 I2C OLED + 复用江协教程的 OLED 驱动代码即可，不用重新打板。
