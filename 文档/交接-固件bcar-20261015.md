## 2. 本次（10-15）干了什么

### 2.1 修掉 5 个"一上板就现形"的 bug（commit `cfe5f3f`）

| # | 位置 | 后果 | 根因 |
|---|---|---|---|
| 1 | `uart_dbg.c` `fmt_core` | 上电第一行就 **HardFault** | 不支持 `%08X`/`%4u`/`%02u` 宽度符 ⇒ 不消耗 va_arg ⇒ 后面参数全错位 ⇒ `%s` 把数字当指针 |
| 2 | `uart_dbg.c` 波特率 | 串口**全乱码** | 写成 `(pclk2*25)/(4*baud)`=3906；正确 `pclk2/baud`=625（实际跑成 18432 波特） |
| 3 | `main.c` | 敲 `IMU` **整机假死** | **`imu660_init()` 从没被调用** ⇒ SPI2 没使能 ⇒ 死在 `spi2_xfer` 等 RXNE（`heading_init()` 也漏了，死区没设） |
| 4 | `encoder.c` | **左编码器永不计数** | 置了 `AFIO_MAPR_TIM2_REMAP_1`（位[9:8]=10=**全重映射** PA0/PA1）；应为 `TIM2_REMAP_0`（01=部分重映射 PA15/PB3） |
| 5 | `stm32f1xx_it.c` | 配好 IMU 就**卡死在中断** | **`EXTI9_5_IRQHandler` 根本没写**，DRDY 中断没人接 → 掉进启动文件 `Default_Handler` 死循环（#3 修好后才暴露） |

**★定位手法（可复用）**：SWD 读 `xPSR`（异常号 3=HardFault、0=线程模式卡死）、`CFSR`/`HFSR`/`BFAR`，**MSP 处栈帧的第 7 个字 = 出错 PC**；再用 `MDK-ARM/bcar/bcar.map` 的符号表把地址映回函数名。

### 2.2 审查聊天频道 Agent 的阶段 7 改动（commit `1acd659` → 我补 `a61ad81`）

它加了 `src/control/{angle_pd,mixer,control}.c` + `Tools/test_control.c` + `PD/BASE/GAIN` 命令（+596/−1，**纯新增，没碰上面 5 处修复**）。设计本身合理（第一拍不做微分防 D 冲击/超量程按比例缩放保差速比/丢线先直行 200ms 再刹）。

**❌ 但它有个致命问题：`control_enter_run()` / `control_exit_run()` 定义了却没人调用** ⇒ `s_running` 恒为 0 ⇒ `control_step()` 第一行就 return ⇒ **"闭环"是死的**（按发车键车也不会动），而且进出 RUN 不会清 PD 历史/不会刹车。

⇒ 我在 `main.c` 里**按状态机边沿接上**（进 RUN 接管、出 RUN 交还并刹车），顺手改了 HELP 里 `PD` 那行错文字。**commit `a61ad81`，已烧进板子验证**（`[CTRL] 进入 RUN：转向环接管（BASE=350）` 能打出来）。

## 4. ★用户 2026-10-15 提的「按键 + 发车流程」需求（**还没实现，下一步做这个**）

原话整理，按这个实现：

**上电** → 进**待机模式**，**蜂鸣器响 1 声**。

**① PB0（KEY1 / 测试开始键）** → 进**测试模式**：
- **蜂鸣 2 声**
- 之后**等串口指令**。用户原话："指令部分算是一个**拓展库**，根据需求添加操作函数"
- **★我们之前写的"自动 AI 调试迭代脚本"（调参器）就在这个模式下跑** ⇒ 这个模式的串口必须能承受调参器的 `SET/GET/RUN` + 每圈 `LAP` 行（见 `待并入v1.9-清单`）

**② PC13（KEY2 / 正式发车键）** → **正式发车**：
- **长按 200ms** 才触发（短按不响应）
- 触发后 **倒数 3 秒**，这 3 秒内**蜂鸣三声，节奏 = 短 2 声 + 长 1 声**
- 然后**正式开始循迹**
- 发车位置：**在正式发车点**（= 赛道图上我给的那个**小蓝框**，即 `nav_map` 的 s=0，坐标 (2772, 203) mm）
- **车头朝 S** → 沿途跑，**过 S 时触发一次「斑马线」判定**
- **照地图跑完一圈后，到 G 点再触发一次「斑马线」→ 此时停车**
- ⚠ 用户原话："**停车代码暂时不急，最后来搞定**"

**术语对齐（重要）**：地图上 **S 与 G 都是横跨赛道顶直线的两条斑马线**（S 在左 x≈2546mm、G 在右 x≈2998mm，净空 400mm）。跑向是 **−X（朝左）**，所以从发车点出发**先过 S**，绕一圈回到顶直线后**先遇到 G** ⇒ "过 S 起步、过 G 停车" 与几何自洽。
