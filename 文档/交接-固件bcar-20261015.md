### 2.1 修掉 5 个"一上板就现形"的 bug（commit `cfe5f3f`）

| # | 位置 | 后果 | 根因 |
|---|---|---|---|
| 1 | `uart_dbg.c` `fmt_core` | 上电第一行就 **HardFault** | 不支持 `%08X`/`%4u`/`%02u` 宽度符 ⇒ 不消耗 va_arg ⇒ 后面参数全错位 ⇒ `%s` 把数字当指针 |

| 3 | `main.c` | 敲 `IMU` **整机假死** | **`imu660_init()` 从没被调用** ⇒ SPI2 没使能 ⇒ 死在 `spi2_xfer` 等 RXNE（`heading_init()` 也漏了，死区没设） |

### 2.3 ★本轮：发车流程落地（commit `2da800f`）—— 逐条对照你的需求

| 你要的 | 实现 | 在哪 |
|---|---|---|

| **PC13 = 发车键**，**长按 200ms** 才触发，**短按不响应** | 新增长按/短按事件：`BCAR_KEY_LONG_MS = 200`；短按只在串口提示一句"要长按" | `key.c/.h` |

| 发车位置 = 发车点（小蓝框 = `nav_map` s=0），**车头朝 S** | 进 RUN 那一刻把**编码器/位姿/航向清零**当锚点：之后 `odom.s` 就是"从发车点跑出多远"、航向 0 = 发车方向 | `main.c` RUN 边沿 |

**取消发车**：读秒中按 **PB0** = 取消（回测试模式，车不动）。
**台上不碰按键也能试读秒**：串口敲 `MODE COUNTDOWN` —— ⚠ **3 秒后它会真的进 RUN 起步**，先把轮子架空再做。

**⚠ 地图口径待定**：发车锚定用的是"发车点 = 里程原点、航向 0 = 发车方向"，**没有**把 odom 直接摆到 `nav_map` 的 (2772, 203)。等地图进固件时要做一次换算，里面有个符号坑必须先实测定死：**地图的 yaw 是"0°=+X、顺时针为正"（图是 Y 向下的图像坐标），而陀螺积分出来的 yaw 是逆时针为正** —— 两者差一个镜像，不实测就写死，只在赛道上现形。

### 3.1 ✅ 已验过（真机）

- **灰度链路通**：8 路 raw 随表面变化（架空全黑 100~300）
- `ENC` 可读 · `STATUS` 报 `MOTOR dir=2(BRAKE) mag=0` · `MODE RUN` → 控制环接管、丢线分支（直行 200ms → 刹车）行为正确
- **（本轮只用串口读到的）**：板子当时在跑**上一版固件**、状态 `IDLE`；`PING/PONG`·`STATUS`·`GAIN`·`IR`·`ODOM` 都答、回包完整 —— 说明串口链路和板子供电都正常，新固件只差烧进去

### 3.2 ★★本轮实测：陀螺零偏 0.4 dps ⇒ 航向 0.4°/s 漂（会静默毁掉惯导）

**测法**：板子放台上**不动**，串口隔 20 秒敲一次 `HEAD`，用返回的 `samples`（5ms 一拍）算真实经过时间。
**数据**：45.2 秒里 yaw 从 120.3° → 138.6° = **+18.3°** ⇒ **0.405°/s**；同时 `bias_z = 0.0`（说明这一上电周期没做过零偏标定，测到的是芯片原始零偏）。
**为什么致命**：跑一圈约 40 秒 ⇒ 航向漂 **≈16°**。惯导为主的设计靠航向推位置，这个量级直接让它瘫；而且**不报错、不抖动**，表现出来只是"怎么调都跑不直、拐弯全错"。
**已经做的应对**：发车读秒那 3 秒改成"标零偏的窗口"（车本来就刹着不动）；采集期间若车被碰/在转（极差 > 1.0 dps）就**放弃标定、沿用原零偏**并串口说明。开关 = `BCAR_GYRO_AUTOCAL_ON_LAUNCH`（改 0 = 只认手敲 `GYROZERO`）。
**还要复核（下一轮台上）**：① 标定后静止 60 秒再看漂移（目标 <0.05°/s，即 1 分钟 <3°）；② 摸一下芯片、等它热起来再测一遍（零偏随温度漂是第二个坑）；③ 若标完仍 >0.1°/s，就得把死区 `BCAR_GYRO_DEAD_ZONE_DPS`（现在 0.3）和零偏稳定性一起重新整定。

## 4. 发车流程 · 台上验收清单（照这个验，一条一条打勾）

1. 上电 → 串口三行发车流程说明 + **1 声**蜂鸣 + 三灯亮一下；`STATUS` 里 `STATE = IDLE`
2. 敲 `KEY`，然后按住 PC13 再敲一次 → `held=` 跟着涨：**这是验"长按 200ms"最省事的办法**
3. **PB0 按一下** → **2 声**蜂鸣 + 串口 `[KEY] PB0 → 测试模式` + `STATE = TEST`
4. **PC13 短按** → 只有串口一句 `短按忽略`，**不该有蜂鸣、不该进 RUN**（这是"短按不响应"的判据）
5. **PC13 长按 ≥0.2 秒** → 串口 `[LAUNCH] 开始读秒` + `[GYRO] 读秒期间自动标零偏`
   - 约 1 秒后应出现 `[GYRO] 自动标定完成，零偏 z=…`（车别动）
   - 3 秒内应听到 **短 短 长** 三声
   - 到点 → `[LAUNCH] 读秒结束 → RUN` + `[CTRL] 进入 RUN`，**车开始走**
6. 读秒里按 PB0 → `[LAUNCH] 读秒被取消`，车不动
7. 试 `MODE COUNTDOWN`（轮子架空）→ 与第 5 条同样的读秒 + 自动标定，到点进 RUN
