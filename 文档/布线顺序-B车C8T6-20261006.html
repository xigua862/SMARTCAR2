布线顺序与注意事项 · B 车 C8T6 主板

2026-10-06 · 单面装件（元件全在顶层）· 2 层板 · 手焊 · 66×88（实际做 87）
本页是 10-04~10-06 讨论后的当前口径；与旧文档冲突时以本页为准（旧文档改不改等你点头）。
大电流走铺铜  ·  模拟线走顶层  ·  换层旁边配一个地孔

一、布线顺序（照这个来，别跳）

第 0 步：先在脑子里把三块分区定死（一条线都别画之前）
  • 功率区 = 车尾一侧：AT8236 ×3、VM 铺铜、那颗共享大电容、降压模块的输入电解、XT30、电机端子 ×3。
  • 模拟区 = 车头一侧：灰度 10P、8 组分压阵列、陀螺仪。
  • 逻辑区 = 中间：MCU + 晶振 + 降压模块 / LDO + 按键 / LED / 蜂鸣器。
三块一旦定了就别来回搬——搬一件，周围十根线要重画。
1先布"必须走顶层"的关键信号
  • 8 根分压后的模拟线（每个 1k/1.5k 交点 → PA0~PA7）：成组、尽量短、平行一致、底下要有完整地平面。
  • 晶振两根：贴 MCU，下方包地，绝对不下底层、不走信号线穿过。
  • SPI 三根 + IMU 的 CS/DRDY：尽量顶层，远离功率区。
  • ISEN → 采样电阻（0.11Ω 那段）：极短、贴着芯片、不下底层。
  • PWM 四根（PA8~PA11）：从 MCU 到 AT8236，走线别和模拟线并行、别绕着功率区兜圈。
2再布电源：全走铺铜，不走线
  • VM（6A）：大块铺铜 + 开窗加锡。算术：1oz 铜按 1.2mm/A，6A 要 7.2mm 宽——走线不现实。
  • GND：双面铺铜（顶层铺地、底层铺地）。
  • 5V / 3.3V：电流小（320mA / 120mA），可以走线，但要够宽（≥1mm）。
  • 大电流换层处 → 一簇 8~12 个过孔（电池入口、AT8236 的 VM 与散热焊盘、电机端子、大电容地端）。
3剩下"糙"的信号：这些才可以走底层
  • 按键 ×2、LED ×3、蜂鸣器、nFAULT、编码器 A/B（20kHz 以下、不急）。
  • 每在这里换一次层，就在过孔旁 1~2mm 内补一个 GND 过孔（伴侣过孔）。
4收尾：铺铜 → 过孔 → DRC → 丝印
  • 铺铜完成后打 缝合过孔（见第三节表）。
  • 跑 DRC，只应剩"器件属性与供应商编号不匹配"那条提示。
  • 检查底层地是不是 一整块连通（有没有孤岛 / 死铜）。
  • 丝印：板名 + 队伍名 + 2026 机器车循迹。
这块板子不要用自动布线（你以前的习惯）。自动布线会把 8 根模拟线塞到驱动底下、把地皮切碎，而且它完全不懂"返回电流"。
最多把第 3 类糙信号交给它；第 1、2 类必须手布——也就几十根线。

二、六条硬规矩（破了要重画）

规矩为什么 / 怎么写
① 大电流走铺铜，不走线 6A 按 1.2mm/A@1oz 要 7.2mm 宽。VM 与功率地全程铺铜，关键处开窗加锡。换层用一簇过孔。
② 8 根模拟线（PA0~PA7）走顶层 全板最敏感的信号：12 位 ADC、1 个码 ≈ 0.8mV、满量程 3.0V。
成组走、短、底下有完整地；不许和 PWM / SPI / 降压模块开关节点 / 电机线束并行；不许穿功率区。
③ 晶振贴 MCU、下方包地 两根线极短，晶振正下方铺地、不放任何走线、不下底层。
④ ISEN 那段极短 从芯片 ISEN 脚到 0.11Ω 电阻这一段上面就是被测电流，贴芯片走、别下底层、别和大电流汇流。
⑤ 换层就配"伴侣地孔" 换层本身不坏信号（你这频率，过孔电感可忽略）。坏的是返回电流跟不过去。
措施：每个信号过孔旁 1~2mm 内放一个 GND 过孔。
⑥ 底层先是"地"，才是"走线层" 底层每加一根线，就在地皮上划一道缝。底层走线要短、稀；画完确认地皮还是一整块。

三、过孔怎么打

缝合过孔：没有元件要插，也照样打孔，纯粹为了让顶/底两层的地连在一起。
尺寸工艺和普通过孔一样（用同一档，别单独设小孔），立创打样不额外收费。

四、摆位（画线之前先摆对）

  • 8 组分压贴灰度 10P 接口，不是贴 MCU（每路：1k 串 + 1.5k 到地 + 100nF）。
  • 陀螺仪：车头中间、Y 轴朝 FRONT（8P 座跟着转 90°）、四角减震柱（独立减震，别和整板垫柱共用）。
  • 陀螺仪离风机孔 ≥40mm 做不到（现在 25mm）——用减震来补，别为此把陀螺仪搬到车底板（底板振得更厉害、引线更不可靠、热熔胶会松）。
  • 降压模块：输入电解 + 输出电解都贴模块引脚，各自再配一颗陶瓷（100nF/1µF）。输入那颗耐压 ≥25V。它的开关节点和电感要远离 8 组分压阵列与陀螺仪。
  • 灰度 10P 的 5V 脚旁留一颗 100µF 低 ESR + 10µF 陶瓷的位（先留、先不贴；实测有纹波再贴）。
  • AT8236 裸焊盘 → 大块铜皮 + 散热过孔；那颗共享的 25V/100µF 聚合物贴在 VM 进板点。
  • 接插件全部走板边；电机端子丝印标 左 / 右 / 风机。

五、三个"只在赛道上现形"的坑

1. 电机 6A 的回流，不许从 MCU、晶振、陀螺仪、8 组分压的底下过。
量化：1oz 铜 1mm 宽 10mm 长 ≈ 5mΩ ⇒ 6A 走 10mm 就是 30mV 地压差 ⇒ 落到 12 位 ADC 上约 36 个码，而且跟着 PWM 在抖。这就是"灰度读数抖"的机理。
2. 灰度模拟线不许穿功率区、不许和 VM 铺铜并行。走车头那一侧。
3. 陀螺仪符号自检（上电必做）：绕 Z 轴按 FRONT 方向转，角速度符号必须为正。
反了 = 车全程往反方向修。这条要单独加进上电自检（现有自检里只有"手转两轮验编码器"）。
