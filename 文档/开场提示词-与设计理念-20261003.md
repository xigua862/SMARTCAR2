# 设计理念（按优先级排列；冲突时上面的赢）
1. 【先活下来，再谈快】成绩按行驶距离积分，时间只是同分加赛。
   ⇒ 完赛 > 不脱线 > 提速。任何"为快而牺牲稳定"的改动一律往后排。
2. 【确定性优先于精巧】不推导、直接标定（编码器齿比未知 → 推车 1m 标定，k 和 D 都不用知道）。
   用实测数，不用别人的数（开源包只抄算法判据，绝不抄机械尺寸）。每个数都要说得出出处。
3. 【有一个地基不能动：离地 6mm】灰度探头面离地 6mm 决定整套阈值、串光、前伸力矩。
   所有结构选择（材料/悬臂/分层/开槽）都以"不破坏 6mm"为红线。
4. 【零悬臂 / 能锁死就锁死】伸出段不是"尽量短"，而是用夹层梁把悬臂变成非悬臂：
   结构底板 + 上方电路板 + 铜柱 = 一个箱体，不是两块板。
5. 【分区即设计】功率在下、逻辑在上、模拟靠前；物理隔开比同板小心布线可靠。
   星形单点地；模拟回线不穿功率区；接插件宁少不多、走板边；下表面零元件零引脚。
6. 【材料服从目的，不服从"高级"】碳板唯一的优势是比刚度（轻），而本校赛不称重 ⇒ 该优势等于零；
   且碳纤维导电。⇒ 结构件用 PCB（免费、绝缘、能遮光、能丝印）；3D 打印只做遮光围裙/法兰/螺纹座。
7. 【惯导为主、光电为辅】元素识别（十字/圆环/终点/斑马线）以 里程 + 航向 + 已知赛道几何 为主，
   光电做位置修正 + 脱线保护。最大风险是漂移累积 ⇒ 必须设计地标重置点。
8. 【留退路，但不在赛前动刀】负压留焊盘不贴件；自画子板原理图留档不打样。
   "校赛前夜绝不装负压"——改重心 + 改震动谱 = 现场翻车经典配方。
9. 【能回退 > 一切】改一步 commit 一次；正式文档一次成型（v1.8），不做 1.8a/1.8b 反复摩擦。
   数据没实测完，正文一个数字都不改。
10.【错了公开撤销】不许悄悄改数；每次撤销都写进修订记录。

## 2. 这十条理念，为什么是这些

| # | 理念 | 它是从哪次教训来的 |
|---|---|---|
| 1 | 先活下来再谈快 | 规则原文：**按行驶距离积分**，时间只作同分加赛。为快牺牲完赛是亏本买卖 |
| 2 | 确定性优先于精巧 | 编码器带 5mm 齿轮（真因未知）→ 与其推导齿比，不如推车 1m 标定；开源包的机械尺寸抄过来直接装不下 |
| 3 | 6mm 地基 | 阈值/串光/前伸力矩全建在它上面；0.5mm 漂移 = 8% 偏差 |
| 4 | 零悬臂 | 算过：2mm FR-4 伸 36mm 挂 20g，**静下垂只有 0.0026mm** ⇒ 长度不要钱，**真问题是接头夹紧刚度** ⇒ 所以用夹层梁而不是一味缩短 |
| 5 | 分区即设计 | A 车"震动断电"、学长"底下裹电工胶带"都是在同一块板上硬凑的代价 |
| 6 | 材料服从目的 | 不称重 ⇒ 碳板的"轻"值零；碳纤维**导电**，旁边就是模拟线 |
| 7 | 惯导为主 | 用户 10-03 定的主线；光电只做修正/保护，因为成品模块的精度与响应都不足以支撑控制环 |
| 8 | 留退路不动刀 | 负压是全车最大震动源（开源作者原话）；赛前夜改结构 = 现场翻车 |
| 9 | 能回退 > 一切 | A 车血泪纪律第一条；正式文档反复摩擦会把"哪份是真的"搞烂（才有 `交接3` 那份判定规则） |
| 10 | 错了公开撤销 | 已执行过三次：4 路→8 路选通、"板宽 88 是限宽"、模块供 3.3V→供 5V |
