🟡 前瞻口径与可调舌板（v1.8 两条口径都改了）

★ 约束 = "探头连线 → 前轴 = 45mm"，不是"板前缘 → 驱动轴"。
　① 买的成品模块，探头不在板前缘（内缩几毫米）；② 转向中心是轴距中点（每侧两轮同速），不是驱动轴。
★ 转向中心 = 前轴后 13mm（轴距 26 的一半）⇒ d = L + 13，稳态跟弧偏差 ≈ d²/(2R)：
　L=35 → d=48 → 5.76mm；L=45 → d=58 → 8.41mm；L=55 → d=68 → 11.6mm；L=65 → d=78 → 15.2mm
　预览时间（R200 限速 1.1~1.4 m/s 时）：L=45 → 41~53ms（国赛参考 35ms、区赛 43ms）⇒ 45mm 已偏宽裕
★ 调参板做法：两条平行长槽（不是三档圆孔）· 行程 20mm（35↔55） · 槽宽 2.2~2.4mm · 端部加宽成"桨叶" · 两颗 M2 都拧紧 + 弹簧垫圈 + 螺纹胶 · 丝印画前轴线 + 35/40/45/50/55 刻线 + FRONT→
★ 更正：v1.7 说"悬臂会下垂"——按 2.0mm FR-4、伸 36mm、尖端 20g 算，静态下垂仅 0.0026mm（占 6mm 地基 0.04%），一阶弯曲共振 ≈700~800Hz。长度几乎不要钱，真正的敌人是接头夹紧刚度。
★ 舌板 ≠ 单独一块：最好与上方电路板做成同一块 PCB（"舌头"），模拟信号全程板内走线、零连接器；且舌板远端要用铜柱与上方板锁一次 → 悬臂变夹层梁。
