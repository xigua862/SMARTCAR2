⑥ 电源与地
VM+12.6V 功率轨——XT30 → 开关 → 保险10A → AT8236 VM电机/风机直给 12V，绝不允许走逻辑轨（转速砍一半）
VIN+5V 中间轨——12V→5V 降压模块v1.7：这一轨既进 LDO，也上子板（发射管 + LM393 的 VCC）。⚠ 不能是 4.7V：4.7V 时 LM393 共模上限 3.2V，而黑态节点就是 3.3V → 超限 0.1V，表现为阈值拧到上半段没反应。确认输入耐压覆盖 12.6V；输出并 220µF 降纹波；连续 ≥400mA
5V+5V → 子板——排针第 11 针（最外端）只给发射管（8×180Ω）与 4 片 LM393 的 VCC，合计 ≈171mA。⚠ 严禁接到任何 MCU 引脚，PA0~PA7 非 FT
3V3+3.3V——AMS1117-3.3 ← 5V⚠ 严禁 RT9013（250mA）。v1.7 双轨重算：发射管已搬去 5V → MCU/IMU 60 + 上拉与杂 30~50 ≈ 90~120mA → 选 ≥300mA 即可；LDO 耗 (5−3.3)×0.12 = 0.2W ✅。
⚠ 严禁让 LDO 直吃 12.6V（1.1W → 热保护），所以 5V 那一级不能省
GND星形单点地——功率地/逻辑地/子板地 在输出电容负极汇一点灰度子板地走独立回线，不穿功率区

子板每路：ITR9909（v1.5 定型号，DIP-4 通孔 8.7×4.5×5.9mm，要留通孔封装）+ LM393 + 电位器调阈值。⚠ LM393 是双路 → 8 路要 4 片（想用 2 片就换 LM339 四路），每片 VCC-GND 就近 100nF。
★ v1.7：子板恢复 5V + 3.3V 双轨（原理图已定稿，已开画 PCB）。发射管与 4 片 LM393 的 VCC 走 5V； 接收管上拉、阈值电位器、输出上拉、指示灯全走 3.3V。LM393 是开集电极，把输出拉到低于 VCC 的任意电压合法。
为什么必须双轨：LM393 输入共模上限 = VCC−1.5V → 5V 供电时 3.5V，而黑态节点就是 3.3V，余量 0.2V ✅； 若 LM393 也用 3.3V 供电，上限只 1.8V → 信号出范围，表现为“阈值怎么拧都没反应”。⚠ 4.7V 也不行（上限 3.2V，超限 0.1V）。
★ 单路元件值（v1.7 定稿，详见框架定稿 §2.4）：R1 180Ω/0805(5V→发射管，≈21mA；⚠ 0603 不行，自耗 76mW) · R2 10k(3V3→集电极) · R3 10k 电位器逐路 8 只，上端 3V3、下端串 10k 到 GND · R4 4.7k(3V3→OUT) · R5 470Ω(3V3→指示灯→OUT) · 每片 100nF（已画 U13~U16，PCB 上必须贴脚 <2mm）· 输出严禁挂 100nF。
★ 迟滞（R6 470k，OUT↔集电极）本版未画 → PCB 上每路留一个空 0603 焊盘不焊；弧上侧倾会把离地从 6mm 拉到 5~8mm、阈值跟着漂，实测抖再焊。节点 100pF 定为不需要（10k×100p=1µs，对 15µs 的管子无意义）。
★ 过采样要改口径：ITR9909 的 tr=tf = 15µs → 一拍内 1µs 间隔的突发采样对这颗管无意义，子采样间隔要 ≥50µs。
★ 极性：白线 → 集电极低 → OUT 高 ⇒ 白 = 1、黑 = 0（IR_WHITE_IS=1），指示灯黑底时亮。
★ 信号摆幅（v1.7）：白线节点按手册下限算 ≤1.3V（实际深度饱和 0.2~0.4V）；黑布节点 3.1~3.3V； 电位器行程 1.65~3.3V → 整段全有效（这就是 R1 从 330Ω 改 180Ω 换来的，330Ω 时只有 56% 行程有用）。调阈值拧到 2.2~2.6V 那一带，别用端点。
★ 双轨付的账：5V 上多了 165mA 发射管 → 降压模块要 ≥400mA，且必须 5V 输出（不是一只电阻能解决的，是整只模块）。好处：发射管与 MCU/IMU 不共轨。
★ 排针 11P 与主板同序同缺角：5V 放最外端 → 错位一格是短路（PTC 跳），不是把 5V 灌进 3.3V 网络。
★ 子板坐标定稿（轻度收腰，v1.7）：从左到右 -40 / -27.5 / -15 / -5 / +5 / +15 / +27.5 / +40 mm（总宽 80 → 板宽 ≈88）。 间距档 12.5/12.5/10/10/10/12.5/12.5。⚠ 中心一对必须明显小于 25mm 线宽 —— 若放 ±13mm（间距 26mm），正压线中心时两管全在线外 → 8 位全 0 → 误判丢线。 非均匀 → 代码必须用 IR_POS[] 查表加权，不能用 (i-3.5) 索引式。
★ 布局三条硬规定：封装 8.7mm 那一边朝车头-车尾、4.5mm 朝横向（反了 10mm 档不成立，且线边缘落在两管之间时会骑阈值抖 4mm）； 灰度排装在驱动轴前 45mm（取上限），装在轴后必读“已经转过去的线”；管子贴板顶装 → 板顶面离地 6mm，DIP 引脚穿出板底约 3mm 要焊完剪平。
遮光是黑底白线方案的第一翻车点：每颗管加隔光墙 + 热缩管，侧面漏光必误判。
子板单独打样、单独换 —— 撞了不心疼，主板才心疼。

🔵 电源树（一张图看懂哪根线走多粗）

3S 锂电 11.1~12.6V → XT30 → 船型开关(≥10A) → 保险/PTC 10A
├─ 功率轨 VM 12.6V → AT8236 ×2(+1预留) → 电机 / 风机　走线 ≥1.2mm@1oz、铺铜开窗加锡、就近 470µF/25V + 0.1µF×3、OUT→端子 100nF+磁珠、电机线 ≤10cm 双绞 18AWG
└─ 逻辑轨 → 12V→5V 降压模块（⚠ 不能是 4.7V）→ 一路直接上子板（发射管 + LM393 VCC），另一路 → AMS1117-3.3（≥300mA）→ 3.3V = MCU / IMU / 子板信号侧 / 蜂鸣
5V 预算：发射管 8×21 = 165 + LM393 4 片 6 + LDO 输入 120 ≈ 290mA → 模块要连续 ≥400mA；3.3V 预算 ≈ 90~120mA，LDO 耗 (5−3.3)×0.12 = 0.2W ✅

★ 严禁 4S。★ 严禁让 LDO 直吃 12.6V（(12.6−3.3)×0.12 = 1.1W → SOT-223 热保护）—— 降压那一级必须有。★ 每颗 AT8236 必须设 3A 限流。
⚠️ 画板前必读（v1.7）：
① 底板你自己设计，一次做完三步：底板（含负压圆孔+4 个螺丝孔）→ 主板板框与接插件位置→ 灰度子板最后画。
　　关键尺寸：轮距 75~85mm、灰度排→驱动轴 45mm（取上限，轴后必读“已经转过去的线”）、驱动轴→车尾 ≤50mm、总长 ≤130mm；子板板宽 ≈88mm（比轮距略宽，先量车壳最大宽度）
② IMU 已核实无需切接口（逐飞 IMU660RC 只有 I2C/SPI，没 UART）→ SPI2 @ 9MHz，IMU 座留 8P：3V3/GND/CS/SCK/MISO/MOSI/INT1/INT2。
　　⚠ 唯一要盯的：模块上 SDO 与 SA0 是同一根脚，SPI 接法下它是 MISO，严禁接地。
③ 主板上留 4 个板边测试盘（3.3V/VM/GND/空闲）——你说过"电机会因为震动突然断电"，查这个必须能夹表笔。
④ 主板用铜柱架在底板上方：既当加强梁防"开负压后底板变形、轮子外八"，又当负压腔上盖支撑。
⑤ 子板双轨（v1.7 定稿）：发射管与 4 片 LM393 的 VCC 接 5V；接收管上拉 10k、阈值电位器、输出上拉 4.7k、指示灯 470Ω 全接 3V3；排针 11P = 8DO / GND / 3V3 / 5V（5V 最外端防插错）。⚠ 模块必须 5V，4.7V 会让共模上限只到 3.2V 而黑态节点是 3.3V。单路元件值与子板坐标见框架定稿 §2.4 / §2.5。
