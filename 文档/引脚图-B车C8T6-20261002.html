子板每路：ITR9909（v1.5 定型号，DIP-4 通孔 8.7×4.5×5.9mm，要留通孔封装）+ LM393 + 电位器调阈值。⚠ LM393 是双路 → 8 路要 4 片（想用 2 片就换 LM339 四路），每片 VCC-GND 就近 100nF。
★ v1.6：子板上只出现 3.3V 一个电压（取消双轨）。发射管、LM393 的 VCC、上拉、阈值、指示灯 —— 全部 3V3，不送 5V 上子板。
障碍与解法：LM393 输入共模上限 = VCC−1.5V → 3.3V 供电时只到 1.8V，而接收管节点原本要摆到 3.3V。
→ 把上拉电阻一分为二：3V3 → 20k → 集电极 → 20k → GND，节点被钳在 1.65V，黑/白全落在 1.8V 窗内。每路只多一只电阻，不换比较器。
★ 单路元件值（v1.6 定稿，详见框架定稿 §2.4）：R1 82Ω/0805(3V3→发射管，≈23mA) · R2a 20k(3V3→集电极) + R2b 20k(集电极→GND) · R3 10k 电位器跨在 1.65V 中点上（全板共用 2×20k 分出，下端直接 GND）· R4 4.7k(3V3→OUT) · R5 470Ω(3V3→指示灯→OUT) · R6 470k~1M(OUT↔集电极，迟滞) · 节点 100pF，输出严禁挂 100nF。
★ 过采样要改口径：ITR9909 的 tr=tf = 15µs → 一拍内 1µs 间隔的突发采样对这颗管无意义，子采样间隔要 ≥50µs。
★ 极性：白线 → 集电极低 → OUT 高 ⇒ 白 = 1、黑 = 0（IR_WHITE_IS=1），指示灯黑线时亮。
★ 信号摆幅（v1.6）：白线→接收管深度饱和→节点 ≈0.2V；黑布→节点 1.25~1.45V；可用阈值区 0.2~1.4V，电位器行程 0~1.65V 全有效。
★ 单轨付的账：发射管 184mA 与 MCU/IMU 共轨 → 轨跌 0.3V 时 LED 电流掉≈17% → 子板入口必装 10µF、3.3V 走线要粗短、电机扰动大时先量 3.3V 再调阈值。
★ 为何不留 5V：子板单电压 → 排针 11P→10P，物理上不可能出现"把 5V 灌进 3.3V 网络 / 烧 PA0~PA7"。
遮光是黑底白线方案的第一翻车点：每颗管加隔光墙 + 热缩管，侧面漏光必误判。
子板单独打样、单独换 —— 撞了不心疼，主板才心疼。

🔵 电源树（一张图看懂哪根线走多粗）

3S 锂电 11.1~12.6V → XT30 → 船型开关(≥10A) → 保险/PTC 10A
├─ 功率轨 VM 12.6V → AT8236 ×2(+1预留) → 电机 / 风机　走线 ≥1.2mm@1oz、铺铜开窗加锡、就近 470µF/25V + 0.1µF×3、OUT→端子 100nF+磁珠、电机线 ≤10cm 双绞 18AWG
└─ 逻辑轨 → 12V→4.7V 降压模块（学长那只直接用）→ AMS1117-3.3（≥500mA）→ 3.3V = MCU / IMU / 灰度子板全部 / 蜂鸣，全车唯一逻辑电压
3.3V 预算：MCU/IMU 60 + 发射管 8×23=184 + 杂 30 ≈ 270mA；LDO 耗 (4.7−3.3)×0.27 = 0.38W ✅

★ 严禁 4S。★ 严禁让 LDO 直吃 12.6V（(12.6−3.3)×0.27 = 2.5W → SOT-223 热保护）——“不用 5V”不等于“少一级”，降压那一级仍必须有，只是它不上子板。★ 每颗 AT8236 必须设 3A 限流。
⚠️ 画板前必读（v1.6）：
① 底板你自己设计，一次做完三步：底板（含负压圆孔+4 个螺丝孔）→ 主板板框与接插件位置→ 灰度子板最后画。
　　关键尺寸：轮距 75~85mm、灰度前缘→驱动轴 ≤45mm、驱动轴→车尾 ≤50mm、总长 ≤130mm（R200 偏移 d²/(2R) 推出来）
② IMU 已核实无需切接口（逐飞 IMU660RC 只有 I2C/SPI，没 UART）→ SPI2 @ 9MHz，IMU 座留 8P：3V3/GND/CS/SCK/MISO/MOSI/INT1/INT2。
　　⚠ 唯一要盯的：模块上 SDO 与 SA0 是同一根脚，SPI 接法下它是 MISO，严禁接地。
③ 主板上留 4 个板边测试盘（3.3V/VM/GND/空闲）——你说过"电机会因为震动突然断电"，查这个必须能夹表笔。
④ 主板用铜柱架在底板上方：既当加强梁防"开负压后底板变形、轮子外八"，又当负压腔上盖支撑。
⑤ 子板单 3.3V（v1.6）：发射管、LM393 VCC、上拉、阈值、指示灯全接 3V3；接收管上拉一分为二（20k+20k）把节点钳到 1.65V；排针 10P = 8DO / 3V3 / GND，子板上没得选电压，所以不可能接错。单路元件值见框架定稿 §2.4。
