④ 陀螺仪 —— 逐飞 IMU660R（LSM6DSV16X）· 现成模块排针立装 + 减震柱
PB13SPI2_SCKOUT✅ FTIMU SCK★ 必须跑 SPI，⚠ 逐飞模块出厂默认往往是 UART → 画板前先查怎么切 SPI（上位机或上电拉脚）
为何不能用 UART：LQFP48 只有 USART1+USART2（无 UART4/5），而 USART2=PA2/PA3 与灰度直接撞车
　→ 实在切不了：IMU 占 USART1(PA9/PA10)，遥测退 USART2(PA2/PA3)，灰度重排为 PA0,PA1,PA4~PA7+PB0,PB1
模块直出四元数 → 姿态解算不用自己写；imu.c 只读陀螺 Z + 四元数 yaw 就够
IMU 区离风机 ≥40mm、四角减震柱、板面印方向箭头（方向错 = 角度符号反）

⑥ 电源与地
VM+12.6V 功率轨——XT30 → 开关 → 保险10A → AT8236 VM电机/风机直给 12V，绝不允许走 4.7V 逻辑轨（转速砍一半）
VIN4.7V 逻辑进——你现成的 12V→4.7V 模块确认输入耐压覆盖 12.6V；输出并 220µF 降纹波（纹波直进陀螺仪 = Z 零偏漂）
3V3+3.3V——AMS1117-3.3 / ME6211 ← 4.7V⚠ 严禁 RT9013（250mA）。预算：红外 200 + MCU/IMU 60 + 杂 30 ≈ 290mA → 必须 ≥500mA
GND星形单点地——功率地/逻辑地/子板地 在输出电容负极汇一点灰度子板地走独立回线，不穿功率区

遮光是黑底白线方案的第一翻车点：每颗管加隔光墙 + 热缩管，侧面漏光必误判。

🔵 电源树（一张图看懂哪根线走多粗）

3S 锂电 11.1~12.6V → XT30 → 船型开关(≥10A) → 保险/PTC 10A
├─ 功率轨 VM 12.6V → AT8236 ×2(+1预留) → 电机 / 风机　走线 ≥1.2mm@1oz、铺铜开窗加锡、就近 470µF/25V + 0.1µF×3、OUT→端子 100nF+磁珠、电机线 ≤10cm 双绞 18AWG
└─ 逻辑轨 → 现成 12V→4.7V 模块 → AMS1117-3.3 → 3.3V（MCU / 灰度子板 / IMU / 蜂鸣）

★ 严禁 4S。★ 灰度子板严禁 5V（PA0~PA7 非 5V 容忍）。★ 每颗 AT8236 必须设 3A 限流。
⚠️ 画板前必读（v1.1）：
① 底板你自己设计，一次做完三步：底板（含负压圆孔+4 个螺丝孔）→ 主板板框与接插件位置→ 灰度子板最后画。
　　关键尺寸：轮距 75~85mm、灰度前缘→驱动轴 ≤45mm、驱动轴→车尾 ≤50mm、总长 ≤130mm（R200 偏移 d²/(2R) 推出来）
② IMU660R 能否切 SPI —— 画板前 5 分钟查清楚，否则串口不够用（详见 §④ 表注）。
③ 主板上留 4 个板边测试盘（3.3V/VM/GND/空闲）——你说过"电机会因为震动突然断电"，查这个必须能夹表笔。
④ 主板用铜柱架在底板上方：既当加强梁防"开负压后底板变形、轮子外八"，又当负压腔上盖支撑。
