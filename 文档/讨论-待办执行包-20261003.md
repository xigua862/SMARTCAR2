## 1. 6 个数怎么量（可直接照抄）

**统一基准：侧框架的轴承孔中心**（轴承孔 = 车轮轴心，天然是这台车的几何原点）。

| # | 量什么 | 怎么量 | 自检 / 易错点 |
|---|---|---|---|
| 1 | **轮径 D** | 软尺**绕胎面一圈** ÷ π；绕 3 次取平均 | 散差 >0.3mm → 胎皮不圆/压扁，先换胎再量。**别用卡尺量直径**（胎皮软、会压变形）。用途：`mm/count = πD/4096` |
| 2 | **同侧两轮中心距**（轴距） | 同一侧两个轴承孔中心距 | **这个数决定转向中心位置** → 前瞻基准（§5）。旧文档里的 25.50 是**参考图的数，不是本车**，别抄 |
| 3 | **左右轮中心距**（轮距，复核 110） | 左右轴承孔中心的**横向**距离；**在同一根轴上量** | 前后轴各量一次：两次数差 >1mm → 前后轴不平行（车架歪）。差速比 1.76 就靠它 |
| 4 | **单轮宽**（复核 22） | 卡尺量胎皮最宽处 | 顺带**说明参考图上那个"7"指什么**（胎宽？轮辋宽？齿数？）——它一直没对上 |
| 5 | **齿轮齿数**：电机齿轮 ?T / 轮毂齿轮 ?T | 数齿（拍照放大数最稳） | 决定齿比 → 决定"提速旋钮往哪拧"；也用来判断编码器口径（§2） |
| 6 | **电机+齿轮箱外形包络**（长×宽×高，含输出轴）+ 横放/纵放 | 卡尺三向 | 底板布局的**硬约束**；顺带记电机引出线**几根线**（2 or 3） |

### ★几何自检（量完必做，1 分钟）

四个轴承孔理论上构成矩形 → **两条对角线应相等**：

```
对角线 = √(轴距² + 轮距²)               例：轴距 60、轮距 110 → √(3600+12100) = 125.3mm
判定：两次量出的对角线相差 > 1mm  →  侧框架变形 或 某个数量错，先查清楚再画底盘
```

> 拍照要求：**卡尺夹住轴承孔、读数同框**；俯拍 + 侧拍各一张；IMU 模块正反面各一张（见 §2）。

## 2. 顺便要确认的 3 件事（拍照时一起看）

### 2.1 ★IMU 模块：是 RA 还是 RC

| 看哪里 | 期望值 | 不是这样怎么办 |
|---|---|---|
| 模块**丝印** | `IMU660RC` + 逐飞 logo | 若写 `IMU660RA` → **芯片不同**（RC 才是 LSM6DSV16X），§5.1 里"片内 SFLP 直出四元数、±4000dps"**不成立**，驱动与假设要重定 |
| 排针丝印 | 一组 `SCL/SPC`、`SDA/SDI`、`SA0/SDO`、`CS` | 这是逐飞 IMU660 系列的标志 |
| 引脚数 | **8P**（含 INT1/INT2） | 4P 就没有 DRDY 中断，采样时刻靠软件轮询，陀螺积分抖动变大 |
| 芯片本体丝印 | `LSM6DSV16X` | 是 `ICM-42688-P` → 那是**作废的 2000 元板**与开源参考件的芯片，**不是这件**；是 `MPU6500/6050` → 那是 **A 车**的陀螺，别搞混 |

> **真正的门不在型号，在零偏**：无论哪颗，第一道验收都是 **静止 10s 航向漂移 <1°**。不过 → "惯导为主线"当场降级，方案要退回"光电为主"。这个测试 5 分钟能做完，越早做越好。

### 2.2 编码器装在哪（决定要不要齿比）

`购物车清单` §1 写"已确认装在**轮轴**"，`待并入v1.8-清单` §一.1 写"编码器每侧一个、**与齿轮平齐**"。两者可能不矛盾（磁铁在轮轴、编码器板与齿轮同高），但**结论差别很大**：

- 磁铁在**轮轴** → `mm/count = π·D/4096`，齿比完全不需要 ✅（现有方案的前提）
- 读的是**电机/齿轮轴** → 必须再乘齿比，`π·D/4096` 作废，且标定要多一个未知量

→ 拍照时要能看清：**编码器感应的是轮轴上的径向磁铁，还是齿轮/电机轴**。

### 2.3 同侧两轮是不是真的刚性同速

"每侧一个 N30 带同侧两个轮、同速"是 10-02 夜口述确认的。**它决定了转向中心在两轴中点**（§5 全部算术的基础）。若实际是同侧两轮**共轴一根**（一根轴穿两个轮）→ 结论不变；若是**两个独立电机** → 完全推翻，要重来。顺带看一眼即可。

## 5. ★待并入 v1.8 的两条更正（算术）

### 5.1 前瞻基准点：驱动轴 → **两轴中点**

已确认**每侧两轮同速** ⇒ 车等价于"每侧一个大接触面的差速车"，**转向中心在两轴中点**。
于是传感器到转向中心的纵向距离

```
d = (灰度板前缘 → 前轴) + 轴距/2
稳态跟弧偏差 ≈ d² / (2R)
```

| 情形 | d | R200 时偏差 | 占 11mm 档 |
|---|---|---|---|
| 旧口径（按 d=45，即量到驱动轴） | 45 | **5.06mm** | 0.46 档 |
| 轴距 60 → d = 45+30 | 75 | **14.06mm** | 1.28 档 |
| 轴距 80 → d = 45+40 | 85 | **18.06mm** | 1.64 档 |

→ **轴距一量出来，前瞻和"轴到车尾 ≤50mm"两条都要重算**。"前伸越多提前量越大"这个收益现在**被放大**（d² 增长），但稳态偏差也同步放大 —— 二者要重新平衡。

### 5.2 灰度占哪 4 个 GPIO（选型定了就能定）

龙邱 8 路模拟量款 = **1 ADC + 3 GPIO**（地址选通）。旧写法 `GPIOA->IDR & 0xFF`（PA0~PA7 整口读）**作废**。

**提案**（待你点头；好处是把地址切换压成一条指令）：

```
AD0 / AD1 / AD2  =  PA0 / PA1 / PA2      ← 同一端口连续 3 位 → 一次 BSRR 写就切地址
模拟量 IN        =  PA3（ADC1_IN3）      ← 模块供 3.3V → 输出 3.3V 域 → 非 FT 脚可直连
省下：PA4~PA7 全空，可留给"模拟抽头/AO 备用"或别的用途
```

> 轮询时间预算（8 通道）：settling + ADC 转换（12bit ≈1µs）——每通道 50µs → 总 **400µs** → 1.2m/s 下走 **0.48mm**（占 11mm 档 **4.4%**）✅ 可接受；**前提仍是 settling ≤20µs**。
