## 1. 三处错位（核心判断：先解决这个，再谈实现）

1. **阶段错位**：v1.8 §3 列了 `app/param.c(EEPROM/串口调参)`，但固件未开写。调参器的实车契约**没有对端** → 现在只能验证"策略"，不能接实车。
2. **架构错位（最要命）**：调参器原始参数表抄自 惯导矫正仿真 的"**建图圈 → 路表 → 跟表 + 直道航向矫正环**（`corr_kp/ki/kd`、`straight_min`、`corner_margin`）"模型；而 **v1.8 §3 主线是"里程 + 航向 + 已知 CAD 几何"为主、光电做位置修正 + 脱线保护、地标重置点**。两者不是一回事：
   - v1.8 **没有"学出来的路表"**；前瞻是**物理探头位 35~55mm + 软件权值表/曲率前馈**（§2.5），不是仿真的 `look_mm` 路表前瞻。
   - ⇒ `corr_*`、`straight_min`、`corner_margin`、`look_mm` 在 v1.8 里**没有一一对应物**，硬塞进契约会和固件真实参数表对不上。
   - ⇒ **串口 SET/GET 的键名必须 = 固件 `param.c` 的参数表**，不能 = 仿真键名。
3. **误差口径错位**：遥测的"线偏差 / 惯导横向偏差"在仿真是"相对路表投影"；在 v1.8 应映射为 **`line_pos` 归一化加权质心 err（§2.5 公式）** 与 **`odom` 相对已知 CAD 中心线的横向偏差**。口径不统一，RMS/P95 不可比。

## 2. 现在能做 vs 被阻塞

- ✅ **能做（不依赖固件）**：三阶段策略（A 诊断 / B 压偏差单参坐标下降 / C 加速）+ 安全阀 + 合成数据离线自证（不追噪声 / 能回退 / 能停止）。已跑出可用结果（§5）。
- ⛔ **阻塞（依赖固件开写）**：串口协议对端、每圈 LAP 结算与打印、AUTORUN、参数落 EEPROM、上电自检联动。→ 要等 **PCB 打样 → 焊接 → 固件里程碑启动**，且先在 v1.8 §3 把 `param.c` 的**参数表 + 协议定死**。

## 3. 对齐后的调参器设计（把原任务翻译到 v1.8 口径）

**参数契约**：以 v1.8 §3 的 `control/` 模块为准重落键名（提案，待签字 D3）：

| 原（仿真）键 | v1.8 对应模块 | 处置 |
|---|---|---|
| `kp_steer` `kd_steer` | `control/angle_pd` | 保留 |
| `k_gyro` | `control/gyro_damp` | 保留 |
| `kp_speed` `ki_speed` `kd_speed` | `control/speed_pid` | 保留 |
| `vmax` `vmin` `a_acc` `a_brake` | `control/profile` + `slowsafe` | 保留 |
| `look_mm` | 软件前瞻（权值表/曲率前馈，§2.5） | 保留，但**语义改为软件前瞻量**，非物理探头位 |
| `corr_kp/ki/kd` `straight_min` `corner_margin` `corr_on` | ⚠ v1.8 原无直道矫正环 | **保留（D2 已签字）**：固件新建 `control/ins_corr.c`（光电修正 / 地标重置环）承接这组键；`look_mm` 归软件前瞻 |
| `autorun` | `app/fsm` | 保留（上电跑几圈） |

**遥测契约（LAP 行）**：字段与顺序不变，但口径改 v1.8——线偏差 = `line_pos` err；惯导横向偏差 = `odom` vs CAD 中心线；补偿角 = 地标重置/修正环输出（若该环不建，此列填 0 并标注）。

**三阶段策略 + 安全阀**：**不变**（纯上层迭代逻辑，与架构无关）。

**硬约束**：C 阶段 `vmax_ceiling` **不是调参器能拍的**——受 v1.8 §7 物理上限约束（R200 → 1.1~1.4 m/s；齿比总比 >28 连 1.4 都到不了）⇒ 上限值来自**齿比/推车实测**，写进 JSON 时标注出处。

**白名单**：只允许 SET 上表控制键；**电机方向 / 限流(R_ISEN) / 引脚映射 一律禁改**（v1.8 §0.3 侧框架翻转要"电机方向翻一次"——那是**固件常量**，绝不进调参器白名单）。
