## 二、判定：**不采用**（三条硬伤，逐条给依据）

### 硬伤 1：**只有 4 路数字输出 → 定位精度不够，而且可能直接踩死"中心对 < 线宽"这条规矩**

- 我们的判据体系（差比和加权、切点/弧/十字识别）需要 **≥7~8 路**才能给出连续的位置估计；4 路数字量最多只能给出 **5 个量化台阶**，做不了差比和。
- 4 路**位置/档距未标**（图上 16 / 42 是**安装孔距**，不是传感器档距）。两种可能：
  - 若 4 路摊开在 91mm 上（档距 ≥20mm）→ **档距 > 线宽 25mm 的一半**，正压线中心时会出现"两管全在线外 → 8 位全 0 → 误判丢线"（§4.5 第 1 条，**"能不能用"级别**）；
  - 若 4 路挤在中间 30mm 内（档距 ~10mm）→ 几何勉强能用，但只有 4 路 → 定位精度不足。
- ⇒ **结论：4 路不满足"精准循迹 + 元素判据"，问清档距也只是决定"判死得快还是慢"**。

### 硬伤 2：**检测高度 10~30mm（白光）/ 14~22mm（RGB）与"离地 6mm"地基正面冲突**

- 我们的整套阈值/串光/前伸力矩都建立在 **离地 6mm**（ITR9909 手册测试条件，§2.4）。
- 模块要求在 **≥10mm** 才认线 → 被迫抬高到 10mm+ ⇒ 连带两件事：
  1. 10mm 处光斑更大 → **串光更严重** → 档距只能做得更大 → 与硬伤 1 恶性叠加；
  2. 安装高度翻倍 → **前倾/侧倾对离地高度的影响放大**（阈值漂移更严重）、前伸悬臂更长。
- 另外：检测高度范围这么宽，通常靠"大功率发射 + 高增益接收"实现 → 在 6mm 处很可能**饱和**，反而不能用。
- ⇒ 这条是**方案级**的冲突，不是调参能补的。

### 硬伤 3：宽度 91.1mm **超出车板宽 88mm**（超 3.1mm）

- ⚠ 更正（2026-10-03）：**88 是"你的车板宽度"，不是规则限宽**（规则见清单·规则依据：垂直投影宽 ≤300mm）。
- 超出即变**悬臂板** → 前缘下垂毁 6mm 地基。3.1mm 量级**可忍**（配 2mm 厚板/加强），但仍是减分项。

### 待问（不构成硬伤）

- **输出电平**未标：5V 供电 + 数字量 ⇒ 极可能 5V 输出 → 进 PA0~PA7（**非 FT**）必须 **1k/2.2k 分压**（§2.2 硬指标①）。
- 5V / 85mA（4 路）→ 8 路约 170mA，与 §2.2 的 165mA 预算吻合 ✅（这条是加分的，说明 5V 轨预算没白算）。

## 三、那该买什么样的（7 条指标，含从这张图新学到的 2 条）

| # | 指标 | 为什么 |
|---|---|---|
| 1 | **≥8 路并行数字输出**（7/8/12 路款；如立创开源那套工程同时有七/八/十二路版本） | 差比和与元素判据的底线 |
| 2 | **必须在 6mm 附近可用**（要客服给"最小检测高度"或"高度-输出"曲线） | 6mm 是全套几何与阈值的地基 |
| 3 | 档距 **10~12mm（首选 11）**，向客服要**板框 + 档距标尺** | 中心对必须 < 25mm 线宽；11mm 错开 25/12.5 的整数比 |
| 4 | 供电 3.3~5V 宽压，或 5V + 我们分压；**输出电平随供电** | PA0~PA7 非 FT（上限 3.6V） |
| 5 | **横向尽量 ≤88mm**（车板宽 → 零悬臂）；规则上限 300mm（见清单"规则依据"），**但 >88 即变悬臂** → 需 2mm 厚板 + 前缘定高支撑 | 零悬臂 = 保住"离地 6mm"地基 |
| 6 | 每路**独立电位器**或一键校准+断电记忆，每路**状态 LED** | 8 颗 LED 是 30 秒验极性/验场地/验遮光的工具 |
| 7 | **波长可选**（买 940nm 与红/白光各一块） | 喷绘布 = 白 PVC + 黑墨，940nm 可能穿透（最高优先级风险） |

## 四、第二轮更新（同日，用户补发"引脚输出真值表"页）

**⚠ 撤销上表"硬伤 1：只有 4 路"** —— 真值表页说明：**X1~X8 = 8 路传感器**，对外 4 个口 = **AD0/AD1/AD2（写 3 位地址）+ OUT（读选中通道的数字量）**，即 **8 通道地址选通（轮询）式**（000→通道1 … 110→通道7，另有一档对通道8）。接口为 **XH2.54**，引脚序 `5V / AD2 / AD1 / AD0 / OUT / GND`。

**新增加分项**：定制遮光罩（聚光 LED）✓、防反接保护 ✓、每路状态 LED ✓。
**档距**：8 路摊在 91.1mm 上 → **≈11~12.6mm** ✓ 命中我们想要的 11mm（且满足"中心对 < 25mm 线宽"）。

### 新问题 1（★最关键）：地址选通 → 通道间**时间偏斜**

原设计是 **8 路同时整口读**（`GPIOA->IDR & 0xFF`，零偏斜）；选通式必须逐通道切地址 → 8 个通道**不是同一时刻采的**。1.2m/s 时 1ms 走 1.2mm：

| 每通道 settling | 8 通道总耗时 | 期间车走 | 占 11mm 档距 | 判定 |
|---|---|---|---|---|
| 20µs | 160µs | 0.19mm | 1.7% | ✅ 可接受 |
| 100µs | 800µs | 0.96mm | 8.7% | ⚠ 边界 |
| 500µs | 4ms | 4.8mm | 44% | ❌ 位图失真 |

→ **必须向客服确认"地址切换后 OUT 稳定时间"**；买回来用示波器实测（教学模块常带板载滤波/去抖，会更慢）。
→ 选通式只占 **4 个 GPIO（3 出 + 1 入）**，但 PA0~PA7 本来就空着，**省脚不加分**；且 **§2.3 表里"PA0~PA7 整口读"的写法要作废**（改用哪 4 个脚等选型定了再定）。

### 新问题 2（沿用上一轮硬伤②）：检测高度 10~30mm（白）/14~22mm（RGB） vs 我们 **6mm** 地基

仍是方案级冲突；要么抬到 10mm+ 接受几何重算，要么找"低高度"款。

### 本轮结论（修正）

- **优先找"8 路并行输出"款**（同时采样、零偏斜，最配高速循迹）
- 这块**地址选通款列为候选**：**仅当 settling ≤20µs 才可接受** → 用客服数据 + 示波器实测决定，**不再"直接否"**

### 追加给客服的问题（接第三节 5 条）

6. 地址切换后 OUT 多久稳定（或推荐采样频率）？
7. 最小检测高度多少（6mm 能否认线）？
8. OUT 高电平是 3.3V 还是 5V？

## 五、第三候选（★目前最优）：龙邱 8 路 **模拟量** 灰度循迹模块

来源：淘宝（**龙邱**＝智能车常用品牌；页面挂"全国大学生电子设计竞赛"字样）。用户 2026-10-03 补发。

**页面关键信息**

- 供电 **3.3V ~ 5V 宽压**；"注意三个 IO 口的电平状态…以选择所需通道" ⇒ **同为地址选通式**
- **占用资源**：**8 路 = 1 个 ADC 口 + 3 个 GPIO**（16 路 = 1 ADC + 4 GPIO）
- 卖点原话："**ADC 采集相对 GPIO 口精度更高，识别范围大，兼容性更好**"
- 板载 8 组 LED/光敏对管 + **白色遮光罩（透镜）**，两端安装耳 + 长槽

**与上一块（亚博 YB-MVX05）对比**

| 维度 | 亚博 YB-MVX05（数字选通） | **龙邱 8 路（模拟量选通）** |
|---|---|---|
| 输出 | 数字量（每通道 0/1） | **模拟量（0 ~ VCC）** |
| 供电 | 5V 单值 | **3.3 ~ 5V 宽压** |
| 接 PA0~PA7（非 FT） | 必须 16 只分压电阻 | **给 3.3V 供电即可直连** ✅ |
| 抗"喷绘布低对比度" | ✗ 数字阈值一崩全崩 | ✅ **可动态归一化（滑窗 min/max）** |
| 精度 | 量化台阶＝路数 | **亚档距精度**（ADC 12bit） |
| 同样要问 | settling / 档距 / 最小高度 / 尺寸 / 波长 | 同 |

**三条关键优势（为什么它更对路）**

1. **模拟量 + 归一化 = 直接对症 #1 风险**：喷绘布 940nm 穿透 → 黑白对比度下降；数字方案直接失能，模拟方案靠每通道滑窗极值自适应仍能定位
2. **3.3V 供电 → 输出即 3.3V 域 → PA0~PA7（非 FT）可直连**，省掉 16 只 0603 分压
3. 占用 **1 ADC + 3 GPIO**（PA0 = ADC1_IN0，另 3 个做地址选通）→ 引脚表按此改，比"8 路并行"还省 4 个脚

**连带影响（★方案级：须用户拍板后才动正文）**

- 判据体系从"比较器数字 0/1 + `Σ(w·s)/Σs`"升级为"**每通道归一化 → 加权求位置**"：
  `p_i = (v_i − v_black) / (v_white − v_black)`（每通道滑窗极值自适应）→ `err = Σ(w_i·p_i) / Σp_i`
  → 收益：**亚档距精度 + 自动适应对比度/环境光**；代价：8 通道 ADC 轮询占时间
- **轮询时间预算**：settling + ADC 转换（12bit @12MHz ≈ 1µs）——每通道 50µs → 总 400µs → 车走 **0.48mm**（占 11mm 档 **4.4%**）✅ 可接受；**仍须实测 settling**
- **16 路款不建议**：16 路 @≥10mm 档距 = **≥150mm 总宽** → 比车板宽 88 多出 62mm，即**每侧 31mm 悬臂** → 机械不可接受（规则上限 300mm，合规但机械不通）
- 自画子板的"比较器 + 电位器"整套前端**彻底作废**（本来已决定采购）
