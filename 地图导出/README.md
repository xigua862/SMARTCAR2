# 地图导出 —— 赛道中心线（惯导用）

> 由 `文档/赛道图-5000x5000-黑底白线.png`（原件，已在仓库里）自动提取。
> 生成脚本：`脚本/赛道图转惯导地图.py`（只用 numpy + PIL）。重跑：`python 脚本/赛道图转惯导地图.py`

| 文件 | 说明 |
|---|---|
| `赛道中心线-预览.png` | 提取结果叠在原件上（红线=中心线，绿短线=方向）——**先看这张核验** |
| `赛道中心线-mm.json` | 10mm 等弧长路点，含 s / x / y / yaw / R（全精度） |
| `nav_map.h` | 直接 `#include` 的 C 表：50mm 间隔、869 点、≈17KB Flash |

**标定**：场地外框 862px = 5000mm ⇒ **5.8005 mm/px**（再用 E 区 R300 圆 109px=625mm 交叉验证）。
**单圈** 43.43 m，**闭环**。

**坐标系**：原点 = 场地左上角；X 向右；Y 向下（与赛道图同向）；yaw 0°=+X、顺时针为正；R 为曲率半径（直线填 1e9）。
若惯导用 Y 向上/逆时针为正：y 取负、yaw 取负。

**必须自己定的两件事**：① s=0 现在在"场地左上角最靠上的点"，不是 S 发车线；② 行进方向是二者之一，反跑就倒序整表。

**限制**：从 CAD 截图提取，弯道中心线有 ±2~3mm 抖动，别当毫米级基准；实跑靠十字/斑马线地标重置吸收铺装误差。
